# EXP10：GNSS竞争跳变联合视觉判别与训练形态参考实验

备份标签`backup/pre-exp10-sdr-paper-20261015-4495ff0`；EXP06完整原运行备份仍保留。

## 目标和假设

检验视觉模型能否在GNSS永久阶跃、暂态和持续运动共存时，为相同数值定位增加独立收益。
原SDR-VLM只允许把尚未配对的阶跃改为暂态，且同时给多个类似局部图；
EXP09反复判断没有明显优于单次均值，两个分歧均属于竞争配对关系。
本轮主候选RGC-VLM（reference_graph）用统一上下文标注跳变和所有近邻配对，
以训练站形态示例支持视觉在整体水平变化图上选择一组相容的类别解释。

## 固定方法

数值训练、尖峰、PELT跳变、活动拟合完全保持EXP06，不用真值生成待测候选。
所有数值跳变两两间距≤120日形成备选返回对，图中仅标跳变索引/候选ID，不给真实类型。
有备选对才请求。原始NEU与原慢轨迹扣除辅助图统一放在一个连续上下文；
视觉可选择保留数值，或重分配水平事件为返回对/单独阶跃，也可拒绝假跳变。
尖峰和活动不由本轮视觉更改；不从导数扩展活动，不改缺测掩码。
输出候选ID，边界由已有跳变索引确定，不搜索日期容差或毫米阈值。

训练参考仅从96训练站选4个：按station_id顺序的首个纯阶跃、纯暂态、纯活动、
首个永久阶跃严格位于暂态内部的混合站；无此混合站则首个混合站。
展示观测原始位移及训练标签，不使用隐藏无噪曲线；参考窗口由训练标签±45日决定。
查询上下文由数值跳变的首末位置±45日决定，不读取验证/测试真值。
幅值仅按本站正常历史MAD归一化作视觉缩放，不设跨站共享物理判据。

主方法固定为带参考联合图，zero_graph去参考，text_graph删除全部图像保留同样说明/ID。
原SDR-VLM、同一无视觉segment_numeric同站对照；不从消融中事后挑主方法。
模型qwen3.8-flash、temperature=0、单请求，无重试。ID未知/冲突的响应记录失败，保留数值路径。
先按观测触发站id排序首6站小批，确认调用状态后扩至剩余站；不按分数挑站。

## 数据、指标、接受条件

新种子2026101501，96训练/24验证；测试分区不用于开发。
四类跨站TP/FP/FN汇总后的等权日F1仍为主，不做point adjustment。
补充阶跃/暂态日与事件F1、通用F1、误报、实际token和请求数。
预先指定混合场景为辅助分层，用于检查共存机制，不能替换全体主指标。

开发reference_graph必须比原SDR-VLM至少+0.02，比相同数值无视觉至少+0.03，
且任一类相对原版不下降超过0.05才进入两个全新种子的正式复核。
若通过，在正式生成前冻结主方法，合并48站仍满足以上两条件、两个种子视觉增量均正才采纳。
图像/参考消融如实报告，不能将数值改善冒充视觉收益。
未通过则记录负结果；根据开发案例形成的新方案必须重新登记，禁止覆盖原运行或改写正式结果。
