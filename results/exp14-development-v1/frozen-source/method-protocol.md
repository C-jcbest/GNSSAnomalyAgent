# EXP14：GNSS局部跳变形态对齐与视觉返回配对（JFP-VLM）

2026-10-15，在本候选任何调用前登记。EXP10—13负结果全部保留。
开发诊断复用已见2026101501验证24站，明确不是新测试。主模型qwen3-vl-plus。

唯一主候选fingerprint：只对数值结果中仍为独立step的两个候选边缘提出返回配对。
沿用原120日最大配对跨度，不修改跳变位置、数值拟合、RF、活动或数值已采纳暂态。
模型输出候选pair ID，选中则移除恰好两个step并加入该暂态；其他事件原样保留。
没有可配自由边缘的站不请求；失败或空选择不修复，不重试。不可共享端点。

输入为完整原始NEU图及局部对齐图：每个候选跳变一列，NEU为三行；横轴为相对
跳变日±14日，本站历史MAD归一化，每列减去[-12,-4]日观测中位数用于展示，
同一分量各列使用共同纵轴；原始观测灰线，3日中位数蓝线，缺测仍留空。
相邻候选边缘以额外虚线显示，避免把短间隔内部step算作返回。
不减全局慢运动拟合，不提供数值活动判决或任何验证真值。
模型比较三分量局部跳变量的反向形态，不要求全局绝对位移回到起点；
持续活动、内部独立step允许共存。窗口、归一化和中位数均为图像适配参数，
不是跨站位移/速度告警阈值；全部固定，不扫描。

context_only消融仅给完整原始图、删除局部对齐图；text删除全部图。
同组qwen原SDR、flash原SDR、无视觉数值为对照；不从消融挑主方法。
先前2个可请求站小批，后所有余站；该批若只有2站符合，则小批已包含全部请求站。
四类等权日F1为主，四类、事件、通用F1全部报告，不做point adjustment。
开发相对同模型原SDR及无视觉均至少+0.015且无类型下降超过0.03，才另登记
两个全新正式测试种子。正式合并至少+0.015、两批方向均正，才采纳。
这不是严格纠正开发多次尝试后的显著性检验，bootstrap仅描述不确定性。

文献依据：VisualTimeAnomaly的任务粒度与多变量图组织；TAMA§3局部放大让模型
获取新增视觉信息；AnomLLM§4.2输入形式与模型差异。本方法不是三篇完整复现。
