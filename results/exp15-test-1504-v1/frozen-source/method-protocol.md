# EXP15：GNSS局部跳变向量可视化核验（VEC-VLM）

2026-10-15，调用前登记。EXP14仍失败：模型将局部图中相反的U方向解释成同向。
额外4次简单上/下阶跃图输入检查，两模型均2/2正确，仅证明能读简单图，不能外推GNSS性能。
本轮测试降低读图负担是否有效，复用已见2026101501作开发诊断，不伪称新测试。

唯一主候选vector_visual，qwen3-vl-plus。数值定位、RF、活动、已配暂态全部保持。
候选为EXP14相同未配阶跃的≤120日边缘对；视觉只能选择pair ID进行修复。
输入原始全图和新局部跳变向量图：每个边缘取最多前7日及后7日（含边缘），
各侧被相邻候选截断；按分量取观测中位数差，并除本站历史MAD。
图中每列一个分量、每行一个边缘，正负条形和数值显示局部变化，缺测不插补。
这是原始位移的局部统计表示，不是模型预测、人工标签或物理阈值；窗口7固定不扫描。
相比EXP14这属于新的图像表示试验，不修改或覆盖其失败响应。

vector_text消融：将完全相同向量作为JSON数字，无图；这才检验图像相对数值文字的贡献。
vector_no_evidence消融：仅有候选ID/日期，无图也无向量；同模型原SDR、无视觉数值分列。
另有vector_nearest数值规则：对反向（点积<0）的候选，用两向量和的范数除以
两范数之和排序，按不共享边缘贪心配对。0是方向几何定义，不是调参告警阈值。
必须披露视觉是否优于这项简易规则，不能把表示本身的数值收益归为VLM独有。

小批为首2个可请求站，再剩余全部站。主指标四类等权日F1，四类、事件、通用F1全报。
先保留开发：相对原SDR/无视觉≥0.015，且相对vector_text或vector_nearest至少有
一项正增量；若无后者则仅说明局部统计有效，不采纳视觉创新。无类型下降>0.03。
通过后另冻结两个全新种子的正式测试再决定生产采纳。不得把开发最好消融换成主方法。
