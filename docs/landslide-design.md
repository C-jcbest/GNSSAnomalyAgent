# 持续形变与阶段规则

本分支保留原项目的位移优先约束，简化生成器和实验流程。数据与评价见[实验协议](experiment-protocol.md)。旧分支的复杂模拟和结果不是本分支的验证证据；[历史来源笔记](landslide-source-notes.md)保留来源边界，其中旧实现的建议不代表本分支内容。

1. 先查看原始N/E/U确认持续累积及离开局部平台的活动范围。短暂噪声、单一永久阶跃和导数峰不能单独确立持续活动。
2. 确认活动后只在内部细分加速、稳定速率、减速。起止待定或弱漂移标uncertain并禁止确定阶段；活动确认但阶段不足允许phases为空。
3. 居中统计只作离线辅助，提前响应不能扩大活动。累计位移平台不因总位移仍大而继续赋活动。
4. 同一最终逐日标签控制PNG着色和CSV。原始缺测日两层留空，禁止补零或给插补值确定标签。
5. 形变、尖峰、阶跃、暂态可共存；形态不自动等于仪器故障或失稳。

机制仿真真值不是专家观测边界或现场预警标准。
