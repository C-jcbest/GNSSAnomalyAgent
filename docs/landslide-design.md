## 目标与数据性质

生成一批多年、日尺度的 N/E/U 位移，供长期形态浏览和后续阶段检测开发。重点是在**同一条记录内**定位何时起变、缓慢累积、加速、减速、停滞和再活动，而不只是给整条记录分类。异常可在中途开始或结束，也可在观测开始前已经发生、在观测结束时尚未结束；平台期保留累计位移，但不延长活动标签。

本批是**文献机制启发的仿真数据，不是现场实测数据**。目前没有用户提供的监测站、设备误差、降雨/库水位或真实位移记录，不能声称生成分布经过现场标定。随机过程仍需参数；这里通过过程和样本差异减少机械重复，而不是取消参数或让噪声任意变大。

新模式与 `synthetic-v1` 一年四类配对基准是不同实验对象。原基准仍用于已登记的检测研究；新数据不套入其 365 日、单轴单事件和固定区间真值契约，也不直接调用原检测评价流程。

## 批次构成

默认 24 例，每例 1095 天（约三年），起始日 2022-01-01，末日 2024-12-30；包含闰日。支持 730–2192 天、1–120 例。每 6 例保留 1 例静稳对照，其余为复合阶段记录，顺序经 seed 打乱；默认批次为 20 条复合记录与 4 条对照。这是覆盖设计，不代表真实发生比例。首轮单形态批次保留作开发参照，不覆盖或补写历史真值。

复合记录按活动片段与停滞段连续组合。片段可能只有低速活动、较快进入加速、缓慢起变后加速，或一次活动中连续两轮增速；较高速持续段不一定出现。不同片段时长和幅度不同，叠加季节响应和相关速度波动。记录按观测窗口截取，允许只看到某阶段的一部分。

| 生成阶段 | 潜在运动行为 | 观测识别的限制 |
| --- | --- | --- |
| `stable` 静稳 | 首次活动前或全程对照，潜在速度为零 | 噪声起伏和仪器跳变不属于坡体活动 |
| `creep` 缓慢形变 | 低速累积、渐进起变，含不规则波动 | 可与测量漂动混淆；本身也可能接近匀速 |
| `acceleration` 加速 | 某次活动中速度总体增加 | 不要求每个瞬时加速度都为正，不等于必然失稳 |
| `steady_slip` 持续滑移 | 速度维持在本次活动的相对高位 | 与蠕变并非天然互斥物理类型，不设通用分级阈值 |
| `deceleration` 减速 | 速度逐步下降，仍有累计位移 | 不能将累计位移未下降理解为未减速 |
| `dormant` 停滞 | 已发生活动后速度归零，位移保持平台 | 与静稳的区别依赖活动历史，仅局部图可能无法区分 |

这六类是生成器的完整互斥分段，不是通用滑坡分类法。生成阶段覆盖整个记录，首尾截断写入阶段说明；异常活动段与静稳/停滞段分开，缺测不改写潜在状态。仪器干扰仍保存在单独分量中。

## 生成过程

1. **非重复水文强迫**：每年独立抽取湿季中心、宽度、降雨概率和强度；日降雨由随机雨日和 Gamma 雨量组成，用衰减记忆得到湿度代理。它只是合成环境驱动，不能解释为真实降雨或孔压预测。
2. **潜在速度**：先抽取早期、中段、较晚或观测前起变，再组合可跳过、可重复的活动阶段。阶段间保持速度连续，停滞期速度为零；共同的季节响应和长短相关扰动只调节活动速度，不凭空使静稳期运动。形变速度按日积分，避免直接拼接导致累计位移跳回零。
3. **三维形变**：抽取坡向和倾角，坡向缓慢变化，将速度投影到 N/E/U 后积分。三个分量来自同一坡体运动，U 为逐渐下沉；不是逐轴独立注入异常。潜在首日作为零参考，测量误差不参与物理运动积分。
4. **观测误差**：叠加独立白噪声、频谱构造的近似闪烁噪声（功率约随 1/f 变化）和短程相关误差。闪烁噪声生成双倍长度再裁取，避免强制首尾相接。雨日误差幅度可增加。所有这些仍是误差代理，不是完整 GNSS 解算器。
5. **质量干扰**：添加稀疏异常观测，部分案例含永久仪器偏移，另有零散缺测与多日中断。质量干扰独立随机流生成，不能作为滑坡活动真值。缺测在输入中为 `null`，不补零、不插值。

不会按曲线好看程度重新抽样，也不会把总位移统一拉伸至固定幅度。相同 seed、请求和实现可复现；相同 seed 重复生成不构成独立实验样本。

## 参数是设计假设

以下范围用于生成不同可观察形态，**不是由文献拟合出的总体分布，也不是预警阈值**。

| 项目 | 实现范围/规则 |
| --- | --- |
| 起变位置 | 早期为记录的 2%–12%，中段 18%–35%，较晚 45%–62%；左截断时第一片段从记录前 25–139 日开始 |
| 低速形变 | 速度尺度 0.025–0.12 mm/日，起变段 35–149 日 |
| 加速与持续 | 第一轮加速 22–114 日、目标速度 0.20–1.15 mm/日；可有 20–99 日较高速段，或追加 18–74 日第二轮增速 |
| 减速与停滞 | 减速 25–119 日；停滞 55–219 日，潜在速度为零；随后可开始下一片段 |
| 片段形态 | 低速片段、较快增速、多轮增速、渐进起变随机选择；记录结束会截断尚未结束的阶段 |
| 速度扰动 | 两个 AR(1) 时间尺度叠加后取指数，速度保持非负且不固定每日单调增速 |
| 坡向/倾角 | 方位 0–360°、倾角 8–38°，叠加缓慢方向变化；不模拟旋转型复杂滑体 |
| 白噪声尺度 | N/E 各 0.5–1.3 mm，U 1.1–2.7 mm，另叠加相关噪声；不是总观测标准差 |
| 零散异常观测 | 每例抽取 0.1%–0.4% 的日发生概率，幅度按该例测量尺度扰动 |
| 仪器偏移 | 每例 25% 概率，有则出现在记录中部并保留；仅作观测质量干扰 |
| 缺测 | 0.5%–2.5% 的零散日概率，另有 1–3 段、每段 4–17 日中断；概率不等于实际缺测比例 |

`truth.json` 记录实际抽取的主要参数、种子、完整潜在形变、每日速度、合成雨量、误差与缺测位置。阶段区间表示生成机制的活动范围，边缘是平滑过渡，不能把它们冒充经专家判定的精确异常边界。

## 观测派生辅助图

默认用 61 日居中窗口，对 N/E/U **观测位移本身**做 Huber 迭代加权局部二次拟合：`位移 = b0 + b1 × 日差 + b2 × 日差²`。速度为 `b1`，加速度为 `2 × b2`，代码中先归一化时间、输出时还原日单位。它不会连续两次差分原始噪声；也不读真值、场景或雨量。

- 可选择 31、61、91 日窗口。窗口越大越能压低噪声，也更容易钝化短阶段；多窗口一致性只是敏感性检查，不是精确边界或置信区间。
- 使用完整居中窗口；两端半窗口内不估计。原始缺测日、有效样本少于 75%、左右任一侧少于 60% 有效日，或窗口中连续空缺超过 7 日时，输出 `null` 并断线，不跨长空档补值。
- 三维速度模 `|v|` 在低速时有噪声正偏，不能把任何正值都当运动。加速度保留有符号 N/E/U 分量；切向加速度 `v·a/|v|` 可辅助区分增速与减速，但仅在速度超过局部拟合误差尺度的 3 倍时显示。该门槛是显示启发式，因误差相关而**不是经过标定的置信检验**。
- 仪器永久跳变可能扩散成速度/加速度峰，鲁棒拟合也可能压低短暂真实运动。必须回看原始位移，不能只按辅助图峰值自动定阶段。
- 居中拟合使用未来数据，属于离线回顾辅助，不是在线无泄漏训练特征。转换附近的提前响应、边界偏移不应当成真实提前预警。

网页同时显示位移与速度/加速度，时间缩放联动。PNG 下载包含原始位移、拟合趋势、速度、有符号加速度、切向加速度，以及窗口和观测哈希；不包含场景名称、生成阶段或潜在真值，供后续图像复核使用。

## 观测阶段标注与复核

最新批次 `landslide-v1-20261007-075217-7b9f8f2c` 的当前标注为修订2，产物位于 `artifacts/landslide-annotations-2026-10-07/revision-v2/`，网页为 `http://127.0.0.1:18766/revision-v2/`。24例保存48个保守确认位移区间及26,280条逐日两层标签。此前已浏览部分生成真值，因此这是开发集AI视觉复核，不是独立盲标或专家金标准。

用户指出旧版有位移仍平稳却标为加速等问题；本版不再对全记录直接赋运动特征。旧版文件和生成对照仅作历史保留，旧统计不适用于新版。具体字段和复核理由见当前产物的 `README.md`。必须沿用以下先后关系：

1. **先确定第一层位移活动范围**：查看原始N/E/U和持续累积、离开原平台的证据；可用非重叠观测块中位点辅助，不根据导数峰或生成阶段决定活动起点。只有短暂噪声、仪器阶跃或弱漂移时，保留待定。
2. **冻结活动区间后识别第二层特征**：仅在确认区间内部用原始位移斜率与31/61/91日速度、加速度复核缓慢位移、加速、较稳定速率滑移、减速。居中导数的提前响应不得向外扩展活动或特征。
3. **统一显示与导出掩码**：起止待定、未确认候选和活动区间外均无确定特征；缺测两层留空。有位移累积但导数支撑不足时允许第一层确认、第二层未定。图中着色和有效特征CSV必须来自相同最终逐日标签，不能只在CSV里排除边界。
4. **分别保留确认内部范围与可能边界**：保守确认起点不是精确物理起点；边界待定不等于静止。记录首尾不虚构窗外日期，弱运动不可辨不自动当成正常，亦不强行套统一速度阈值。
5. 后续需要生成机制对照时，只在保存观测判断后另存分歧，不为匹配生成器边界而重画标签。该批已用于开发浏览，不作为独立盲测效果证据。

## 网页读图

入口为“长期位移”，或 `/?view=landslides`。默认先看整批的曲线卡片，再选一个案例查看详细三轴观测。

- 淡线为原始观测，趋势线由**观测**的 31 日居中滚动中位数计算。它不是潜在真值，也不是实时/因果滤波；转折可能被平滑或向前扩散，不能直接用于在线预警评价。
- 默认纵轴包含零点和全部非缺测观测，最小跨度 60 mm，并在上下各留 25% 空白；可调整最小跨度和留白。这样稳定噪声不会因自动缩轴被放大为明显形变。极值不裁切。
- 可在“各例尺度”和“批次统一尺度”之间切换。前者便于辨认慢形变，后者适合比较幅度；卡片仍显示数值刻度，避免将相似曲线高度误认为相同位移。
- 缺测日期保持断线。只有点击真值开关后才请求潜在形变和阶段区间，并明确标注“仿真真值”。
- CSV/JSON 观测下载只包含日期、N/E/U 与必要坐标信息，不夹带场景、参数或潜在位移。

批次页显示场景名称，属于开发阅览界面，不是盲测输入。后续若开展检测研究，需要仅将观测文件提供给检测器，并独立设计长期标签、数据划分和指标。

## 生成、接口与复现

```powershell
uv run gnss-sim generate-landslides --seed 20261009 --count 24 --days 1095
npm --prefix web run build
uv run gnss-sim serve
```

批次保存在 `data/generated/landslide-v1-*/`，不会覆盖同目录的 `synthetic-v1-*`。每例有 `input.json` 与 `truth.json`；批次 manifest 保存请求、类型分布、状态、缺测计数、全批观测极值、NumPy 版本与生成源码 SHA-256，并保存一份 `generator.py` 源码快照。使用项目锁定环境复现；源码快照用于核对，不是独立可执行发布包。

API 的 `GET/POST /api/landslide-datasets` 列出/创建批次，`GET /api/landslide-datasets/{id}` 获取状态。案例路径为 `/api/landslide-datasets/{id}/cases/{case_id}`，`/truth` 单独提供真值，`/observations.csv` 提供保留缺测空字段的观测下载。生成失败会明确标记 `failed` 并保留已生成案例及错误信息。

案例路径下 `/diagnostics?window_days=61` 返回观测派生诊断；`/diagnostics.png?window_days=61` 下载无标签多面板图。窗口仅允许 31/61/91 日。诊断中的 `input_sha256` 是经输入模型规范序列化后的观测哈希，用于绑定观测内容，不是带缩进 JSON 文件的原始字节哈希。

## 验收与后续边界

功能验收核对：同请求逐值可复现；不同案例起止和阶段组合不同；完整互斥阶段覆盖、停滞平台和截断；三维位移增量与潜在速度一致；测量误差与物理位移可重构；缺测不补值；三种窗口均能恢复已知二次运动的导数，单点干扰鲁棒性、长缺口拒估、端点拒估和低速方向门槛有效；删除真值文件仍可取得辅助图。具体检查命令：

```powershell
uv run pytest tests/test_landslide.py tests/test_landslide_diagnostics.py tests/test_api.py -q
uv run ruff check .
npm --prefix web run build
```

这些验证能证明实现符合设计，不能证明“与真实滑坡统计一致”或任何检测方法有性能提升。当前尚未实现站网空间共模、库水位耦合、真实气象回放、接收机解算质量字段及专家标注。若后续取得真实长期 GNSS 序列，应再校核速度分布、频谱、季节活动持续期、缺测结构和形态覆盖，并保留未用于标定的现场样本。
