# 研究问题与实验路线

> 版本：2026-09-24 · 教学说明。**当前仅 P1 已实现。** 文中 P2～P9 是后续设计方向，不代表已有数据、算法、实验结果或冻结参数。

## 摘要

本实验构造可追溯的日尺度三轴坐标序列，逐步研究异常的生成、定位和评价。研究对象是 N（北）、E（东）、U（高）三个带符号的坐标分量。模拟器知道每个成分和事件的来源；未来检测器只看观测输入，报告可观察的形态、分量与日期区间。这样可以把“算法有没有找到信号”与“信号的物理成因是什么”分开讨论。

## 研究问题与边界

目标不是依据一条曲线判断滑坡或仪器故障，而是回答三个逐级问题：

1. 能否构造可复现、各成分可核对的正常序列？这是 P1。
2. 当一个窗口包含零个、一个或多个异常时，方法能否找全事件、分清分量和时间？这是 P2～P7 的待实施任务。
3. 数值与视觉方法是否呈现可信的互补性，值得设计额外的工具选择和复核？这是 P8 的分析问题；只有证据支持时才进入 P9 Agent。

第一版固定为每个案例 180 个连续日期，每天每轴一个模拟观测值，使用毫米。这里的“日数据”是生成器的采样网格，**不是**真实 GNSS 日解，也没有北京时间 15:00 的采样含义。数据完全合成，不读取旧项目的平台快照。

## 名词与可观察对象

| 名词 | 本实验的含义 | 易混淆处 |
| --- | --- | --- |
| 监测点 | 具有固定参考坐标的一个合成对象 | 不对应真实测站 |
| 案例 | 一个 180 日、三轴的模拟窗口 | 案例可包含多个事件 |
| 数据集 / 批次 | 同一请求一次生成的一组案例 | 批次创建时间不同不影响案例的确定性 |
| 参考坐标 $P_0$ | 创建案例时给定且始终不变的三轴坐标 | 不能用完整测试窗口重新估计 |
| 观测坐标 $X_t$ | 给未来检测器看的三轴数值 | 包含背景和测量噪声；后续可包含异常 |
| 无噪声坐标 $T_t$ | 模拟器计算的参考坐标加正常背景 | 不等于已证实的现场真实位置 |
| Ground Truth | 模拟器保存的成分、事件与状态 | P1 事件列表为空；未来只供评价和教学浏览 |
| 异常形态 | Spike、Step 等曲线结构 | 形态不自动证明物理成因 |

为避免把信号形态和注入来源混成一个标签，未来模拟器将分别保存真实位移贡献与观测伪差贡献。一个观测突变可以作为 Step 形态报告，但只看单站曲线不能自动断定它来自真实坡体运动。

## 分阶段实验流程

| 阶段 | 预期产物 | 当前状态 |
| --- | --- | --- |
| P1 | 正常日序列、固定参考坐标、分离的输入与真值、交互浏览 | 已实现 |
| P2 | 五种异常的独立生成与逐类真值测试 | 未实现 |
| P3 | 同窗多事件叠加、重叠与跨轴案例 | 未实现 |
| P4 | 多标签真值、300 例 Pilot、评价器的手工校验 | 未实现 |
| P5～P7 | 数值与视觉基线、固定组合、统一批量评价 | 未实现 |
| P8 | 方法互补性及失败案例分析 | 未实现 |
| P9 | 在证据支持下设计 Agent，并做独立测试 | 未实现 |

每阶段先验收数据与标签，再进入下一阶段。不能从 P1 的正常曲线推导检测能力，也不能把合成注入实验当成真实滑坡预警验证。

## 后续事件与检测思路

P2 计划的五种形态是 Spike（短时尖峰）、Step（突变后保持的偏移）、Slow Trend（有限时间内缓慢变化）、Acceleration（在已有运动上叠加加速变化）和 Transient Shift（有限时间偏移后恢复）。P3 将重点检查趋势中的尖峰、趋势中的加速、时间分离与跨轴组合。一个日期可以同时属于多个事件。

后续候选基线包括用于局部异常的 Hampel、用于变化点的 PELT 或同类方法、用于缓慢趋势的 Theil–Sen 滑动斜率、用于斜率变化的加速候选，以及固定数值组合和独立视觉方法。这是**研究路线**；当前仓库尚无上述检测器、阈值、提示词或运行结果。数值与视觉必须接收相同案例的观测输入，不能读取 `truth.json` 决定预测。

## 评价原则

未来检测输出以事件列表表达，每个预测包含形态、轴和起止日期。多事件评价需要同类型事件一对一匹配，不能让一个预测重复覆盖多个真值事件；单日事件的起点误差与区间事件的时间重叠应分别报告。正常案例的误报情况单列，不能因为没有阳性事件便把 F1 当成满分。匹配阈值、切分和最终指标仍需在 P4 前冻结，P1 不产生方法排名。

## 阅读路径

先阅读《P1 正常序列模型》理解每个数值怎样生成，再阅读《数据契约与可复现流程》核对文件、随机种子与前后端边界。最后阅读《后续异常、检测与评价方法》理解尚未实施的设计。网页图中的“生成成分”和“无噪声轨迹”是教学检查视图；未来正式检测只读取案例输入。
