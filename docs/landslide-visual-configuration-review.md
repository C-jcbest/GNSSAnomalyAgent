## 1. 结论

当前视觉方法有问题，但没有依据把问题统一归为“视觉不适合范围异常”。已确认的问题包括弱运动漏检、活动后平台合并、阶段混淆与区间契约失败。更可能需要优化的是任务粒度、每张图的有效信息密度、平台核验、参考样例和具体模型配置。

优先建议是“视觉粗定位＋全覆盖局部原图检查 → 持续位移证据确认／平台与边界复核 → 确认活动内阶段判别”。保留纯视觉对照，数值摘要或工具核验的收益分别检验，不把数值候选设为唯一入口。先保持已有阶段头不变，以活动质量判断视觉优化是否有用。

## 3. 为什么当前图片与任务可能难识别

### 弱趋势在全局图被压低，但局部图已经可见

case_0003 的开发参考弱段是第775–855日，共81个可评分日。取区间首尾各14日观测中位数，N变化约4.043mm，而全局N纵轴跨度约290.484mm，只占面板高度约1.39%；E、U的对应变化约−0.425mm、−1.758mm。这是观测显示几何诊断，不是物理真值或显著性检验。

该趋势在已经送模的第720–899日局部原图中可见，但局部定位仍只输出 `[[240,615]]`，未包含该弱段。说明单靠缩短窗口或减小纵轴跨度仍不足以解释全部失败；跨页注意、任务阈值、噪声与运动区分以及模型能力均待验证。

用户要求适当放宽纵轴以免噪声误导，这一目标应保留。建议总体阅览图继续用宽轴；分析图另有受噪声约束的局部尺度、完整单位和刻度。不能为了让模型“看见”而无限缩轴或裁掉极值。当前局部尺度已有 `max(局部原始范围,6×噪声代理,10mm)×1.5`，第一轮包装实验先保留该规则，避免一并调尺度。

### 平台已能看到，却没有被分开确认

模型已收到“活动后的高位平台不是活动”的文字，实际却仍合并平台。case_0003 的局部定位为 `[240,615]`，case_0006 为 `[400,895]`，两组全局／局部比较中部分平台误报保持不变。这说明继续追加同义否定句没有已知收益，需要把“是否仍在持续改变”作为独立核验步骤。

建议模型对候选的前部、中部、后部逐段查看原始位移，标出继续变化、平台和证据不足的片段；两个活动之间的平台不得因累计位置非零而桥接。覆盖候选周围上下文，不只看候选内部，也不把数值拟合导数峰当活动证据。

### 活动与阶段不是同一种视觉任务

提供参考活动范围后，视觉阶段 macro-F1仍为0.495，而规则／XGBoost为0.764／0.844，因此定位不是唯一瓶颈。开发参考并非金标准，数值工具与标注相关，不能据此判断真实阶段准确率，但足以表明当前阶段输出未稳定复现参考。

XGBoost使用本批训练组的监督阶段标签，当前视觉模型没有获得同等训练样例；这些成绩是实际配置比较，不能解释为只改变输入模态的公平对照。加入训练参考后，应同时报告参考来源、信息预算和零样本对照。

阶段提示写的是“increasing displacement rate”，没有完整说明三轴有正负方向时应判断运动速度的大小。U方向更负的斜率可对应速度增大，不能按纵轴数值下降就判减速。高速度也不等于加速。提示中已有相关提醒，但应具体规定速度大小、方向及持续变化的关系。

辅助图将有符号分量与3D速度放同一速度面板，低速处的速度模又有噪声正偏；分量加速度和切向加速度是不同对象。建议阶段图按固定活动片段给原始位移、速度大小和有支撑的切向加速度，保留必要分量核查，使用同一时间刻度。不要求所有轴同号变化，也不以某日加速度正负确定长期阶段。

### 输出契约错误与语义错误应分开

case_0023 的活动与不确定区间共享闭区间端点，导致整条定位未知。这是坐标／契约失败，不证明模型完全没找到活动。不能通过人工修补历史输出提高成绩。

新流程可以减少每次输出范围，并在支持时使用结构化schema约束字段和类型；JSON mode本身不能保证区间互斥。每窗结果独立校验，失败限于该窗；统一日期映射和缺测掩码。局部索引加固定窗口起点转换为原日历，是可以另行检验的契约设计，但不能压缩缺测日期或静默修正重叠。

## 5. 推荐优化优先级

| 优先级 | 改动 | 保持不变 | 需要观察 |
| --- | --- | --- | --- |
| P1 | 一次只判断一个目标窗口；单窗N/E/U三面板＋全局上下文 | 180日／90日网格、原始观测、已有局部尺度、模型及活动定义 | 弱活动、平台分离、边界／未知与契约失败；单窗增加调用成本 |
| P1 | 候选前／中／后持续变化证据与平台结束复核 | 固定候选和输入图、阶段头；先纯图核验 | 误报减少是否损失弱活动，不能只看平台FP下降 |
| P1 | 核对模型／视觉编码能力，固定较强视觉模型作对照 | 相同图、提示和输入信息 | 当前模型配置是否是瓶颈；真实返回版本、失败、成本与重复性 |
| P2 | 0参考 vs 3张训练来源正常参考；之后再试少量活动样例 | 相同待判图和任务；参考来源冻结 | 噪声、跳变、平台与弱活动区分；训练信息增加单独披露 |
| P2 | 为模型增加短可核查观察摘要，若支持再单独检验推理模式 | 不请求内部思维链；不同时改模型／图片／所有提示 | 原始位移依据是否对应输出；返回摘要不等于实际正确 |
| P2 | 统一原图／辅助图时间刻度，明确速度大小与方向语义 | 固定活动门控 | A/S/D混淆及未知；居中导数不扩大活动范围 |
| P3 | 短结构化数值摘要或独立工具核验 | 固定候选、图与阶段头，保留纯视觉 | 图＋数字是否净收益；不是独立传感证据 |
| 暂缓 | 温度网格、增加输出上限、大量辅助图或直接微调 | — | 当前没有截断；温度已有低随机设置；样本和独立验证更不足 |

模型对照应选可访问、可记录版本的视觉模型。优先对照论文中表现较好的模型家族，但旧版本是否仍可用未检查；后继版本不是原版复现。先用已知原图进行坐标／趋势读取诊断，再比较活动识别，不能靠宣传或模型名字判断视觉能力。

推理开关只能使用实际接口支持的参数，记录实际响应；不能以客户端写了开关就声称服务端执行。重复3次是开发建议，不是精确复刻Refining的5票机制；如果采用投票，未知如何投票及日级聚合规则必须在测试前固定。

## 6. 下一轮最小实验安排

不立即把全部改动合并成一个“优化版”。

1. **图片包装比较。** 固定每窗调用、窗口网格、提示、尺度与模型，A组给全局图＋包含目标窗的原图册，B组给相同全局图＋单窗图，两组都只判断指定目标窗。这样调用数相同，比较目标窗的有效呈现；其他窗口细节与视觉token有差异，仍需披露。不要拿旧整记录1次调用与新12次调用的分差直接归因于分辨率。
2. **平台复核。** 缓存相同候选，比较无复核、纯视觉分段复核；然后再单独比较视觉＋短数值摘要。所有候选统一处理，包含拒绝和失败，不只挑已知平台。
3. **模型／参考比较。** 图与提示先固定，再换一个版本可核查的较强视觉模型；训练正常参考另作0／3张对照。每个因素独立比较，预先规定重复数。
4. **阶段优化另做。** 活动流程选定后固定门控，先比规则／XGBoost；视觉阶段使用局部同轴辅助图及明确速度语义另评估，不将活动和阶段优化分数拼成已运行端到端方法。

图片包装的开发筛查可用已经查看的case_0003、0006、0015，覆盖其全部固定窗，而非只选择弱段／平台窗口。每例12窗、两组、一次重复，共72次请求；这是候选预算，不是已冻结或已执行方案。只有一个弱段，筛查仍不能证明弱运动泛化。进一步重复或正式评价在新训练／验证材料上安排，先冻结最大请求数和完整提示包，不事后挑最好一次。

评价同时看活动P/R/F1、弱段支持及召回、平台FP、端到端阶段macro-F1、未知覆盖、失败与调用／token成本。稳定对照必须完整检查，不能因局部缩轴提高弱段检出就忽略噪声误报。参考标签需独立复核，不能为适应新图或新提示重标当前成绩。

## 7. 可核查观察提示草案

以下是待比较设计，不是当前已发送提示，也不要求模型暴露内部思维链。判断基于图上的可见观测摘要；具体schema和所有分组提示在执行前冻结。

活动核验建议包含以下意思：

> 只判断目标窗口，并利用全局图了解前后活动历史。先比较目标窗口前部、中部、后部的原始N/E/U：是否存在跨多个观测块的持续累计变化？区分继续变化与移动停止后的高位平台。某轴减小可对应持续运动，不要求三个轴同号。孤立点、单次阶跃或导数峰不能独自确认活动；无法区分弱运动与漂移时输出未知。给出简短、可从图上检查的依据，再输出互斥的活动／未知区间；不能为了提高召回把所有缓慢起伏都判成活动。

阶段核验建议包含以下意思：

> 仅在已确认活动内判断速度大小是否持续增加、近似稳定或持续减少。位移分量的正负方向不是A/D类别；向负方向移动得更快也可以是加速。高速度不是加速，低速度不是匀速。先回看原始位移，再使用同一时间范围的速度大小及有支撑的切向加速度；不根据单日符号或居中导数的提前响应扩大活动。近边界、缺测或证据冲突时保留未知。

平台复核与阶段语义变更应分别消融，不能仅用一份更长提示与旧提示的分差证明所有新增说明有效。不要强制A→S→D固定循环。
