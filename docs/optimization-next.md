# GNSS视觉数值融合后续优化思路与论文调研

日期：2026-10-13。当前基础为已冻结的GNSS-VLM-EXP04-v1及26页结构优化稿。以下是下一轮候选方案，不是已完成的新实验；没有新增视觉模型请求或修改原成绩。目标是以较小工作量形成可解释的GNSS场景收益，支持工程应用论文继续完善。

## 1. 建议先做什么

优先组合是：**简化视觉输入，保留数值活动边界，改善阶跃日期定位**。另补一个可运行的近期作者方法对照。真实背景上的半实物注入适合增强领域证据，可作为下一阶段，不必现在自建复杂噪声模型或训练大模型。

| 优先级 | 候选 | 对应问题 | 主要收益假设 | 工作量判断 |
|---|---|---|---|---|
| P1 | 全局视觉＋固定数值活动边界的简化融合 | 8图输入和自由视觉边界没有稳定正增益 | 改善覆盖、降低输入负担 | 低，两个已有变体组合后仍须验证交互 |
| P1 | 视觉判断是否存在阶跃，数值确定日期 | 弱阶跃、日期不同意造成漏检 | 提高严格阶跃F1与召回 | 低到中，先诊断和局部数值拟合 |
| P2 | 原始位移分段拟合辅助活动边界 | 停止后误报与活动漏日取舍 | 在不标停止平台的前提下恢复弱活动日 | 中，需要验证原始位移活动语义 |
| P2 | 1幅全局图＋只保留阶跃证据局部图 | 多图消融的来源尚未分解 | 保留精细阶跃信息，减少无关视图 | 低到中，明确控制图片数量与内容 |
| P2 | 近期作者方法对照：VLM4TS、TimeRCD | 当前未完整运行这些近期方法 | 提高比较证据的可信度 | 中，环境、缺测、标签语义须适配 |
| P3 | 实测背景＋简单事件注入 | 白噪声及匹配背景的证据范围有限 | 以真实残差检验站点背景适应性 | 中，不需自建复杂噪声生成器 |

以上收益是假设，未预报提升幅度。现有四类等权日F1=0.5681已能支撑论文主张；新结果应作为独立后续实验，不能替换EXP04冻结主方法的身份。

## 2. 当前结果揭示的真正瓶颈

### 2.1 活动边界与图片输入

两个种子48站中，固定数值活动边界变体四类等权日F1=0.5816、通用日F1=0.7734，完整方法为0.5681、0.7095。主种子24站去局部图为0.5834，完整方法为0.4997。前者仍使用完整视觉输入，后者仍使用视觉活动边界，所以不能直接推断“去图＋固定边界”一定更好，值得在新验证站比较这一组合。

完整视觉边界把停止后假活动日从固定边界的202降至0，但活动漏日从628升至856。优化目标应是保留停止平台的识别，恢复真实活动覆盖；简单扩张所有区间会重新引入过标。

### 2.2 新增阶跃错误分解

对两正式批保存的候选、视觉结果、主方法结果和真值做离线描述性核查，没有重新推理：

| 检查 | 15个可观测真阶跃中的数量 |
|---|---:|
| 真日处于某个阶跃检查窗内 | 15 |
| 真日恰为排名候选中心 | 9 |
| 某候选中心距真日不超过3日 | 10 |
| 原视觉结果精确给出真阶跃日 | 5 |
| 最终主方法精确命中 | 4 |
| 漏检且没有同日排名中心 | 6 |
| 漏检但已有同日排名中心 | 5 |

因此，现有问题不等于“图窗完全没有覆盖事件”。六个漏检在当前同日交集规则下缺少必要的精确候选；另外五个还涉及视觉漏判或日期偏差。主批s0071的视觉结果给出真日467，却因候选中心是508和449而被排除；s0056与s0062候选中心正确，视觉日期分别差1日。其余漏判包括类型判断错误或未给出阶跃。

这支持下一轮把“检查窗内是否存在永久水平变化”与“精确变化日是哪一天”分开。这里的数据只用于解释已见测试，不用于证明新规则有效，也不以真日把预测吸附回正确日期。

证据：[逐事件诊断](../results/exp04-followup-diagnosis/step-candidate-diagnosis.json)；复算脚本：`scripts/analyze_exp04_steps.py`。原EXP04汇总与结果文件未改变。

## 4. 六个具体方向

### 方向A：最小输入的形态分工融合

保留数值尖峰、视觉阶跃确认和暂态语义，先把持续形变固定为数值边界；比较全局图、全局＋正常参考、全局＋阶跃局部图三个输入，不同时改分类器或候选排序。最终选择需要新验证站支持。该方案的动机主要来自本项目两项真实消融；VLM4TS和AnomLLM只是支持检查分工与输入方式的文献背景。

可贡献的是在GNSS任务中找到足够的视觉证据配置。评价同时包括四类F1、活动漏日/停止后假日、输入token与请求耗时。若图更少且结果不下降，效率也可成为工程优势，但本轮没有该组合的耗时或分数，不能预写提升比例。

### 方向B：阶跃的语义确认与日期估计分离

保留当前检查窗预算，让视觉回答“窗内是否存在持续水平变化”以及支持的大致范围；在已确认范围内，由前后两段拟合损失或通用变点库计算精确日期。候选的数值依据使用站点正常历史的残差尺度，避免统一毫米判据。尖峰、返回型暂态与阶跃必须分别建模，不能把一切差分峰归为阶跃。

先比较当前RF排序、前后水平变化排序、两者联合候选的候选召回；再决定是否改变视觉输入。数值定位允许新的日期来源，属于新融合规则，需要明确命名，不能悄悄把视觉日期吸附到真日。严格同日、±3日和候选覆盖率继续分别报告。固定预算控制检查成本，模型可以输出无阶跃。

VLM4TS的定位—核验组织、GNSS ChangePointCNN的数值候选—图像评价提供方法先例；具体的GNSS阶跃语义及数值日期规则是本项目待验证的设计。

### 方向C：原始位移拟合辅助活动边界

在视觉确认持续活动后，对原始NEU位移拟合“背景延续—连续位移变化—偏移后稳定”结构，以拟合证据决定起止；CPOP可作为分段斜率候选工具，不直接把每个斜率变点输出为异常。背景来自正常历史，不以速度大于某统一值判定活动。

先确认原始位移上的持续活动区间，再解释内部特征；导数只作辅助，停止后的累计偏移平台不算持续活动。弱活动或缺测使边界无法确认时保留不确定性。模型选择使用已声明的默认惩罚或训练/验证侧固定规则，BIC也是统计选择准则，不能包装为完全无参数。

主要对照是完整视觉边界、已有固定数值边界、新分段拟合边界。重点检验活动漏日是否减少且停止后假日是否可控；三个来源都必须共享相同形态确认，才能分离边界增量。CPOP作者实现为R，增加运行环境有成本；若先实现简单局部拟合，应称本项目方法，不冒充CPOP源码复现。

### 方向D：少量固定形态参考图

若新验证仍显示阶跃/暂态混淆，可以提供少量训练站的永久阶跃、偏移后返回、停止后平台示例，联合本站正常参考。只选训练资料，不从测试挑漂亮图，不使用大规模检索库。可按形态需求试1—2个固定例子，增加的token成本与少图方案单独比较。

TAMA和AnomLLM给出参考输入与少样本设计背景，但不保证异常示例在本任务有效。此方向优先级低于A/B，因为新增示例也可能重新造成多图负担。无需为这一试验引入RAG或复杂LangChain代理。

### 方向E：补近期作者源码对照

首选VLM4TS，因为视觉候选与全局复核最接近；第二选择TimeRCD的多变量预训练权重，因为已有NEU输入且无需本项目预训练。ChangePointCNN任务要求长记录并服务于速度估计，暂列领域近邻，不为追求近期对照而强塞进当前730日实验。

VLM4TS原版默认与更换为当前视觉服务、缺测处理、NEU组合后的版本分行，记录源码提交及每项适配。若只能执行适配版，明确原版未执行。TimeRCD输出通用分数，不能直接计算四类分类F1；在通用检测表比较，四类表留空并说明任务不提供类型。原版连续分数可评价AP/VUS-PR；若输出硬标签必须先确定作者默认判决是否存在，否则训练/验证侧固定判决属于适配，不是作者默认。

本项目融合当前只有二元结果，没有可比较的连续置信度。不能为了计算曲线指标伪造概率；分数方法与二元方法在对应指标表中清楚区分。TSB-AD适合复用评估及少量轻量基线，不需要一次跑完40种方法。

### 方向F：真实背景半实物验证

选公开GNSS片段，经站点日志或独立人工审阅排除明显事件，然后叠加现有简单尖峰、阶跃、暂态、活动机制。保留实测残差、季节变化和缺测，免去手工设计复杂噪声。按原始站点拆训练/验证/测试，同站片段或重叠窗不跨集合；固定预先选取标准，避免只选容易成功的背景。

“无明显事件”不能等同专家金标准正常，残余真实异常需单独标注或排除。注入事件的真值与原有事件分开，只评价可确认标签。公开NGL及领域论文的数据入口可作为候选，但本轮没有取得并筛选实际背景。半实物成功可以支持真实背景适应性，仍不等于真实滑坡活动金标准或现场预警验证。

## 5. 推荐的最小下一轮验证

拟议名称：**GNSS视觉形态确认与数值精确定位实验**，实验代号可用GNSS-VLM-EXP05；目前尚未登记或启动。

1. 新开发站上先跑数值候选诊断，不请求视觉模型。统计阶跃候选严格/±3日召回、窗口覆盖率和候选数量，比较两种简单定位来源；不改尖峰与暂态。
2. 从新验证集固定首6站，比较完整输入、全局输入、全局＋阶跃局部输入三种配置，共18次请求。边界策略从相同响应派生，避免额外请求和混淆。若某配置失败，记录失败，不以重试覆盖。
3. 扩至24新验证站后选择输入及日期/边界策略；主指标继续四类等权日F1，配套报告通用F1、事件F1、四类精确率/召回率、正常站误报和活动边界错误。不要仅按最高通用F1挑选会丢失点事件的方案。
4. 冻结最终方法及适配清单，在两个新种子的新测试站比较EXP04固定方法、简化法、新阶跃定位法、数值法和可运行的近期源码方法。同类重复事件可加一个独立小场景，仍使用简单噪声，无需改变主模拟任务。
5. 少量独立复测用于检查在线服务波动；固定边界与去图的效益必须同站比较。不把已分析的EXP04两测试种子重新称为未见测试。
