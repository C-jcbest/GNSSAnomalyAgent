定位主分数的提升受唯一失败强烈影响：case_0023 全局控制输出 activity=[300,450],[680,850],[1020,1094]、uncertain=[450,680]，第 450、680 日共享闭区间端点。HTTP 200、JSON 有效，但违反互斥契约，整项未知；没有人工修补或重试。局部组成功，命中 271 个活动日，同时有 186 个参考负日误报。

共同成功的五例中，定位 F1 从 0.844 降到 0.841：局部组少命中 6 日，FP 不变。该子集只解释失败影响，不能替代含失败主表。两组均漏掉唯一的 81 日弱位移段；case_0003 的 92 日平台误报和 case_0006 的 166 日平台误报也都未减少。本轮没有支持“加局部图稳定提高活动识别准确率”的结论。

阶段 A/S/D 的 F1 从 0.557/0.103/0.573 变为 0.730/0.167/0.550，加速与匀速改善、减速略降。866 个明确阶段日中，正确日从 438 到 536，范围内错分从 420 到 320；匀速 TP 24→38，S 假阳性 401→375，精确率约 0.056→0.092。旧同类全局配置 0.466、本轮控制 0.411，表明单次调用变化不可忽略。

## 阶段高分不代表稳定期加速误报低

| 阶段配置 | 非活动参考日上的确定阶段 | 其中虚假加速 A |
| --- | ---: | ---: |
| 全局视觉 | 213 | 60 |
| 局部视觉 | 272 | 41 |
| 视觉活动＋XGBoost | 220 | 205 |
| 数值活动＋XGBoost | 0 | 0 |

这里只统计标签 activity_label=0 的有观测日，排除未知边界和缺测。虚假加速也不包括真实活动中的 S/D→A 错分，两种问题要分别报告。

视觉活动＋XGBoost 在明确阶段日正确 807、错分 54、第一层漏 5 日，但错误活动门控内有 205 日虚假加速。源码确认：阶段头只在有特征支撑的 A/S/D 日训练，没有非活动类；因此它遵守传入门控，却不能自行拒绝错误活动。结果与这一训练契约一致，尚不能据此判断真实物理原因。

这 205 日分别来自 case_0003/0006/0023 的 41/150/14 日，主要集中在 case_0006 的活动后平台；其原始位移与阶段结果图已复核。这是特定困难背景的失败，不能当成现场统一误报率。

局部视觉的虚假加速降低，但非活动日上的确定阶段总数增加，不能称所有稳定期误报改善。数值活动＋XGBoost 当前总分最好且该项误报为零；这仍是开发标签上的结果，标签和数值方法共享派生工具证据也可能影响一致性。

## 下一轮应检验的具体问题

优先问题是：在固定误报暴露下，多尺度累计位移候选和原始位移确认能否增加弱活动召回、减少活动后平台误报？阶段头继续保留保存的 XGBoost 与规则，不同时调动全部环节。

1. 候选与确认分开：比较原数值候选、较长尺度累计候选及视觉候选；所有候选必须再依据原始位移确认持续变化，候选并集不直接成为确定活动。
2. 用独立训练/验证记录补足弱运动、近似匀速和困难负例：相关漂移、季节变化、仪器跳变、活动后平台、停滞后重启及缺测。不采用重叠窗随机划分。
3. 冻结确认器后比较“候选直接输出／数值确认／视觉确认／视觉＋同源结构化数值证据确认”。阶段头、信息来源、评价记录与重复数固定；关闭模块时保留其他相同条件。
4. 主表同时报告活动召回、负日误报、弱段召回、端到端阶段 macro-F1、非活动日虚假加速、边界误差、未知覆盖与契约失败。先确定主指标，不在本批错误上选择最佳阈值。
5. 局部图如继续研究，单窗调用与多面板输入需另冻结实验；本轮不按错误窗追加请求。模型重复次数预先指定并保留全部结果。

现有记录足以开始撰写方法、实现、开发实验和失败分析；支持可审计的活动/阶段分工，尚不支持视觉优越或现场滑坡预警结论。投稿实验仍需独立标签与未查看记录，条件允许加入真实案例。当前居中 31/61/91 日导数和全记录图是离线识别工具；未来预测必须单独做时间前缀、尾随估计和按事件验证。
