## 方法与范围

新增独立名称 `reference_trend`，采用 Theil–Sen 中位斜率与中位截距拟合前45日有效观测，用其外推表示窗口开始时的既有运动趋势。随后检测相对该趋势的持续位移偏离。这是传统稳健回归残差方法的工程组合，不声称新算法，也不冒称CUSUM。

本轮只运行该候选的48个开发案例和SCWM-04无标签辅助案例，核对是否适合在原三个数值方法名额中替换CUSUM；不扩成六方法正式矩阵。旧三数值方法、视觉和固定组合结果均保留，固定组合仍为Hampel＋视觉。新方法暂不开放给Agent，不追加模型调用。

## 在查看本轮分数前冻结的参数

| 参数 | 设置与解释 |
| --- | --- |
| 参考段 | 开始45个日历日，至少30条有效观测且首末跨越至少30日；每个分量独立判断 |
| 拟合 | 所有有效日期对的斜率取中位数，截距为观测减斜率×真实日索引的中位数 |
| 偏离门槛 | 4×max(参考残差MAD×1.4826, 0.5 mm)；0.5 mm只是工程噪声下限，不是仪器精度或显著性阈值 |
| 持续性 | 后续14个日历日内至少10条有效观测，至少10条在同一方向超门槛 |
| 区间 | 对满足持续性的14日窗，仅标记其中真实观测且同方向超门槛的日位置；可以回标确认窗中的日期，不能把一次报警无条件延长到窗末 |
| 缺口 | 不插值、不压缩时间；缺口超过7天时清空持续性窗口，但沿用最初参考趋势。恢复后的位移偏离可检测，缺口中不定位起点 |
| 计算覆盖 | 满足参考拟合条件且处于至少10条有效观测的完整14日确认窗中的真实观测单元；参考段不算被检测。无任何可评估单元返回insufficient |

以上是单一未校准配置，不进行阈值搜索、不因分数低而换背景、修改标签或放宽门槛。先检查恒定/匀速、突发尖峰、持续速率改变、位移恢复、随机缺测和长缺口等工程行为，再冻结源码并运行。指标仍为observed-cells-v1.1，参考段阳性及未覆盖阳性照样计FN。

## 能回答与不能回答的问题

本方法针对“相对开始时既有状态的持续偏离”。原本稳定非零斜率不应自动报警；持续变化结束后若仍偏离原参考轨迹，可以继续报警。14日确认使用未来观测回标，属于离线回顾性定位，不能称在线预警或把回标日期当实际发现时刻。

主要限制：参考段本身可能已经异常、非线性或不稳定，稳健拟合不等于参考段已被确认正常；短参考段斜率误差经外推会积累，季节性也可能产生假报警；早期45日内事件不评估，发生在缺口中的起点不确定；返回原趋势附近的位移会停止报警，可能与受影响位移标签不完全一致。固定45日参考来自工程假设，不按注入起点或SCWM六月线索挑选。

本轮结果只与第二轮同数据上的历史结果作描述性对照。若方法仍不能满足任务需求，保留失败，不宣称替换已成功。两背景的AI审核已完成，见[背景审核](background-review-guide.md)；它不构成独立密集真值，当前仍不制作正式能力卡。
