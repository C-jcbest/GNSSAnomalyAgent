# 原图活动接口同期配对实验 v2

## Material Passport

- workflow: ARS experiment-agent / run
- experiment: landslide-reference-interface-v2；2026-10-08
- source: 新背景开发 public 包，12条完整记录；不读取封存测试或机制真值
- reference: 两组均为相关模型的 AI 开发草案，非独立专家参考
- preregistration: 本文件、配置、源码和24份实际请求计划在首调用前冻结

## 问题与干预

历史 v1 的4条失败包含13个活动可能范围／静稳范围共享的闭区间端点，整例失去可用草案。本实验检验减少重复范围表达能否降低接口失败，以及是否改变活动判读。历史17次调用不重跑、不修补、不作为同期对照。

对全部12条开发记录各做一次同期 episode_v1 与 partition_v2 原图层请求，共24次。episode_v1逐字复用冻结v1提示和解析器；partition_v2保留原图观测任务文字，仅更换日历／输出契约：一个有序、连续、覆盖0..1095的半开分区，每段状态为activity/stationary/unknown，未知允许覆盖整条。活动保守内核与两侧未知表达的科学语义不变，但表达结构和示例改变，可能影响判读，不视为纯解析器干预。

partition_v2以[start,stop)表示，stop为不包含的日索引，1095是记录末尾切点，不是观测日。相邻段共享切点合法，每个观测日只属于一个段。间隙、重叠、乱序、越界、布尔端点、空证据、额外字段均拒绝，不排序、裁剪、回填或事后修复。缺测最终统一掩码未知。失败仍整例未知；没有旧答案适配或旧格式回退。

## 固定执行

- 模型qwen3.8-flash；temperature=.1，top_p=.3，max_tokens=2048，thinking=false，JSON返回；24次预算，单遍，无重试。
- 全部12条，不只重做历史失败；按case升序，奇数先episode，偶数先partition，平衡先后顺序。
- 两组每次发送同四张冻结原图，全局及三个固定局部，字节、顺序、轴限不变。无辅助图、数值摘要、作者诊断、旧答案或隐藏机制。
- 不调用阶段模型；不使用v1旧阶段给新活动贴阶段。完成两组活动后冻结，后续阶段须依其自己的冻结范围开展。
- 跨请求无会话状态；运行目录不可覆写，硬超时1800秒，每次HTTP最多150秒，记录逐调用开始和返回。

## 检查与分析

检查全部实际请求体／图片哈希、提示重建、CSV与JSON逐日重放、缺测和网页色带相同。报告同期契约成功数、失败类型、观测覆盖、活动／静稳／未知数、两组逐日3×3转移（排除缺测）及共同成功记录。接口成功不等于原图读对；覆盖提高不等于准确率提高，活动增加不等于弱段召回提升。

历史结果只作来源背景。单遍12条开发对照没有稳定性或泛化证明，不计算F1／精度／召回／显著性，不将逐日数据当独立样本。初步成功仅支持进入原图内容复核；不直接替换论文主方法。阶段类别／证据一致性保持为下一独立实验。封存测试继续不解封。
