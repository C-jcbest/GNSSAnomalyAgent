## 本轮试运行带来的设计调整

1. PELT、XGBoost、TCN 已证明基础代码可运行，不再把仓库存在视为完成复现，也不需要继续扩充模型名单。
2. TAMA 已有完整流程的实际调用记录；正式主对比必须统一“持续位移活动”的任务定义，并说明模型从论文配置改为当前共同模型。原始通用提示另列迁移分析，不作为唯一对照。
3. 所有方法的时轴、缺测、边界、输出格式必须在评分前冻结。越界和解析失败记录为失败，不静默裁剪、不利用真值修正。
4. PELT 使用包返回的半开区间结束点；视觉输出包含端点。统一转换到内部 [start,end) 后评价，并为首日、末日、单点和缺测边界增加共同契约检查。
5. TAMA 可将平台、孤立尖峰视为通用异常；活动判别基准应明确平台不延续活动，尖峰/单次仪器跳变不等于持续移动。真实误差导致原因不明时允许不确定，不强行解释为坡体活动。

## 任务和数据协议

第一层是持续位移活动定位：输出确认区间、不确定边界、缺测/证据不足。第二层只在确认活动内判别加速、近似匀速、减速等演化；低速是独立强度特征，可以同时加速。L 标签不能直接自动转换成匀速。

当前 v2 标签是 AI 辅助开发标签，24 条记录全部已查看，只供调试。下一批采用独立背景记录划分训练/验证/测试，再切窗口；同背景的不同噪声版本放同组。生成机制真值和观测可辨标签分别保存并分别评价，不能将自己定义的规则生成标签再把规则对标签的高分当外部有效性。

快速启动可先用仿真机制标签检查训练管线，但正式“观测阶段”成绩需独立标签。真实数据先完成 Oak Ridge 文件质量审查与阶段标注试点；两个站仍属于一个场地。跨场地结论需要其他独立场地。样本量依据开发试点的方差和目标误差区间确定，不用当前单例 API 成本推断统计功效。

所有视觉组使用共同任务说明：活动是持续累计位移相对之前平台的变化；移动停止后保持的偏移不继续算活动；孤立点、单一台阶和导数峰不自动成为活动；输出合法日期和未知状态。参考正常片段仅来自训练/开发部分，图像不带真值阴影和生成标签。

## 必要消融

先完成“定位方式（数值/视觉）×第二层（固定规则/模型）”四组合，复用同一定位缓存和同源数值证据。与主表配置重复时复用输出，不重新抽样挑最佳次。

额外保留两项核心消融：相同两阶段和相同证据但解除活动约束；固定定位、第二层去掉全部派生数值及导数图。它们分别检验活动确认逻辑和辅助证据，而非单纯多一次调用。

固定全局/局部图长度、纵轴规则与预算上限。图轴敏感性至少采用预先选择的原跨度和扩大跨度，不逐例调图。TAMA 本轮多项修复不作为单因素消融，不能用两轮开发输出差异声称某一模块有效。

## 评分和成本

- 活动事件以一对一 IoU 匹配，报告 Precision/Recall/F1、逐日覆盖、弱活动召回、稳定暴露期每站年误报。不能只给总体 Accuracy。
- 阶段采用端到端逐类和 macro-F1；第一层漏掉的真实阶段计入 FN；同时报静稳期虚假加速、边界误差及不确定/缺测覆盖。
- 各方法分别在验证集选参数，使用共同选参准则。测试集不能选择阈值、画图尺度、窗口或最好一次输出。数据划分与随机种子在正式运行前保存。
- 使用独立记录/场地的配对差异和分组不确定区间，不将每天和重叠窗口视为独立样本；训练随机性与场地抽样不确定性分开描述。
- 实际预算记录调用次数、图像数、输入/输出 token、耗时和失败率；单一 token 总数不换算未经核对的费用。TAMA 当前三条单轴记录每轮 9 调用、约 4 万 token，是开发量级参考，不是完整三轴测试的上限保证。
- 对格式/越界失败主结果保留分母，并报告失败率和不确定覆盖；可另报成功解析子集的诊断指标，但不得代替端到端主表。

## 初稿交付顺序

现在即可用核查资料写引言、相关工作、任务定义与方法草稿，同时完成共同数据/评价器和自动执行器。接着冻结训练/验证配置，在未查看测试上一次执行主对比与核心消融，再写结果、定量摘要和结论。保留失败案例与负结果，不以“代码跑通”替代滑坡有效性证据。

当前自动执行器和共同评价已实现并完成开发运行；独立标签、真实案例、弱位移覆盖与稳定阶段输出是正式实验的主要缺口。当前结果没有证明视觉两阶段优于数值/学习基线，见开发执行记录。预测未来位移和失稳时间留作后续扩展，不扩大这一轮初稿范围。
