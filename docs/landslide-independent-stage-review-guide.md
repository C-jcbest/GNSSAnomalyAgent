# 独立活动内阶段复核准备指南

本指南与模板只是准备材料，没有完成独立阶段标注。已有活动来自同会话AI作者review-v3，因此即使后续阶段独立复核，评价仍条件于这份活动；端到端金标准需另行独立活动审查。

## 输入与盲性

运行产物的`public/independent-stage-review-template.json`列出全部12条记录及21个冻结名义活动内部区间，链接无预测色带的四原图和三辅助图。优先将这些输入单独打包给复核者；不提供本轮网页、模型输出、作者疑点、生成阶段、场景名或数值规则预测。不要把复核者称为独立专家，除非身份、资格、是否看过预测及是否参与活动标注都有真实登记。

填写reviewer_identity、reviewer_blinding及各活动的review_status。所有默认unreviewed、空stages和null观察表示尚未审查，不是未知／正常参考标签。不要直接将空模板送入评分器。

## 复核顺序

1. 原始位移先确认可见运动，冻结活动内部只研究阶段。不对不在活动内部、起止未定或缺测日赋确定阶段；允许注明活动参考本身需要另审，但不要悄悄改这次条件实验的活动范围。
2. 将方向与速度大小分开记录。N/E/U正／负方向不是加速／减速；观察原始斜率绝对值变化，并查31/61/91日辅助的速率演化。
3. 记录内部峰、转折、近恒速段及不确定时间带。一个活动可能有多个A/S/D和未判段，不能仅给整活动一个主类。
4. A：持续速率总体增加；D：持续速率总体降低。瞬时符号不必全相同，不以单点峰、导数提前响应或永久偏移脉冲建立阶段。
5. S：有可辨识的持续非零运动，并有近似恒定速率的独立证据。缓慢、噪声、小加速度或曲线平台都不能单独推S。尚无已标定的统一恒速／显著性阈值，不编造精确标准；证据不足保留未定并说明。
6. 支撑不足、窗间冲突、截断端点与不确定转折允许未定；原始运动存在而导数无法估计时，不能推为无活动。缺测的逐日参考保持未知。

每个确定阶段填半开整数start／stop、feature（acceleration／steady_motion／deceleration）和可核查原图及辅助证据；stages只在当前名义内部且不重叠，不跨活动外待定区间。turn_uncertainty记录不能可靠定位的时间带；steady_nonzero_evidence记录S的非零及近恒速依据。没有S时也应注明是否检查过。

## 形成参考的条件

建议至少两位具备相应背景的复核者独立完成，再保存分歧和裁决过程；若只能一位，真实披露单复核者。发生分歧时不要用当前模型预测或同源规则符号裁决。保存输入哈希、模板版本、时间及身份；复核完成后另存参考文件，原空模板和冻结预测不改。

参考完善前只报告覆盖、未知、重复性、失败与内容疑点。完善后冻结评分协议：逐日阶段macro-F1及各类精确率／召回率，事件匹配和边界误差按共同可评价区域计算，失败整条保留；不得将参考未知自动当负例、将模型弃判删出分母，或使用point-adjustment制造范围召回。正式测试仍封存。
