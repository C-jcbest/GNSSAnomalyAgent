# EXP21：多尺度原始位移图的直接区间识别（MRL-VLM）

2026-10-15，于新数据生成及任何新视觉调用前登记。本轮目标改为直接识别异常范围，不继续只做跳变向量配对。参考AnomLLM的区间输出、TAMA局部放大和正常参考思想；这是本项目适配，不是这些论文原法复现。

方法名：**MRL-VLM（Multiscale Range Localization with VLM，多尺度视觉区间定位）**。主模型qwen3-vl-plus，沿用原接口，temperature=0，enable_thinking=false，无自动重试。生产原SDR-VLM不改。

## 数据、输入与执行

- 原生成器和噪声，开发种子2026101515，96训练/48验证/48测试。仅使用验证集，test不打开；本轮不按结果再挑种子。
- 数值对照`segment_numeric`、`rf_split_temporal`。保留尖峰/阶跃的数值结果，视觉拥有transient/deformation全部区间，可新增、删除、改边界。先小批前6验证站（按站ID），三种输入各一次；完成后看区间指标与实际读图能力，决定是否扩至全48站。
- `range_visual`：原始N/E/U与历史正常参考残差六面板全景，220dpi，日索引主刻度50；只显示历史正常区，不提供数值检测候选/真值。残差为历史拟合辅助，原始曲线优先。
- `range_text`：与图上相同每日原始/残差数据，使用round-trip浮点文本，不削减信息；没有图。元数据、提示、输出格式和模型相同。
- `range_no_image`：只给长度、正常前缀与缺测位置；缺少观测应输出空区间。用于检验先验幻觉，不把无证据补全当作用。
- `range_zoom`：复用range_visual首轮结果，在其提议起止附近各±35日生成局部图，使用原日索引、5日主刻度和1日次刻度，图宽约1760像素；再加全景请求一次修订完整区间。首轮为空则无局部候选，不新增请求；输出与首轮同一格式。每站最多4个区间、8个局部窗口；超出则保留全景和首轮完整判断并披露未放大的部分。提议边界附近缺测不强迫精确定位。
- 直接比较单轮与局部复核流程。不提供测试真值、生成机制参数或目标异常数。原图窗口不能来自真值。
- 长期活动先从原始位移确认持续运动，再定范围；停止平台不算持续活动。只有残差漂移、季节变化、瞬时阶跃不能定活动；不细分阶段，不设置跨站位移/速度阈值。缺测索引不赋确定标签，预测mask统一排除缺测。

## 评价与决策

区间主结果使用EXP20冻结的Affiliation P/R/F1，分暂态、形变及两类并集；同时报告日F1、事件IoU .3/.5 F1、最佳IoU、覆盖率、匹配边界MAE、负站FP日及误报事件。原四类日F1仍列作辅助，不能凌驾于新任务。

小批仅作诊断。若视觉或局部流程在两类站均Aff-F1或事件IoU .5 F1上较数值有可见提高（至少0.02），且至少一种区间指标优于等价文字、无图，则扩量；同时检查误报/覆盖，不能靠铺满时间轴获得漂亮Affiliation分数。若仅边界最佳IoU/MAE改善也可继续，但必须有至少3个真值匹配且IoU提高至少0.03，并明确登记扩量理由。无有效区间预测/明显退化则取消，不为跑满48站继续付费。

全48站仅为开发证据：若有图相对数值和等价文字有至少一种区间指标实质改善、另一主区间指标不明显下降且正常站误报未明显恶化，才考虑另行冻结新正式检验；不要求统计显著，也不把换指标后挑出的高分直接放入论文主表。所有比较指标和负结果完整保留。
