## 结论

## 为什么33个短窗可用日只恢复8个

三头共同弃判的35个确定参考日中：

| 条件 | 日数 | 意义 |
|---|---:|---|
| 31日有限速度／切向 | 33 | 估计可用，未保证原生有类或窗完整在活动内 |
| 31日有限切向且完整在同一活动内 | 13 | 满足补充支撑边界条件 |
| 规则原生有确定阶段 | 0 | 仅换最终门控无法恢复 |
| XGBoost原生有确定阶段 | 0 | 同上，不等于重算短窗原生分类器 |
| 视觉原生有确定阶段 | 25 | 来自既有回答，另10日内容层已未知 |
| 视觉原生确定且31补充门控通过 | 8 | 两条件交集才得到最终恢复 |

这解释了“短窗33日有估计”不等于“能补回33日”。规则／XGBoost若要研究短窗内容，需要另立特征提取、训练或规则实验；不能在本消融里偷偷重算内容。剩余视觉分歧也不是靠门控改类别能够修复。

视觉恢复A[435,438)、D[480,485)，均在case_0001活动[420,505)内部，与作者参考同类。该记录另D[471,480)恢复9个参考未定日；case_0011活动内D[728,730)、D[731,742)恢复13个未定日，缺测日不桥接。后22日没有确定参考，不能称正确或误报。收益全来自单记录8日，不具记录级稳定优势证据。

## 对论文主线的影响与下一步

当前证据支持：活动确认、原生内容和最终支撑是三个可分别失败的步骤。第一层必须从原位移确认持续活动；第二层不能仅凭位移方向或高速度给A；第三层可控制证据不足，但不负责纠正已有类别。完整内31补充可以保留为**待独立验证的局部覆盖配置**，不能升格为论文主方法或总体视觉优势。

下一步优先补独立共同阶段参考、恒速支持和未用于规则设计的记录，并审查真实资料的可观察活动与阶段；随后冻结最终内容配置做正式比较。当前116视觉异类仍全在作者D参考（98→A、18→S），内容与转折判别仍是开发瓶颈。暂停本批进一步试窗口／阈值或叠提示选最高F1，也不把本批共同辅助估计与作者标注的一致性当独立准确率。

初稿已能加入两层任务定义、完整失败传播、受控因素负结果及此门控取舍。正式优势表、现场泛化与预测／预警主张继续等待对应证据；居中证据含未来信息，仍是离线回顾任务。
