# EXP45：数值活动锚定的视觉边界候选（NAB-GNSS）

2026-10-17，在用户明确形变“接近数值即可”后登记。既有EXP41—44负结果不改。

## Material Passport

- 模式：形变分支性能保留实验；仿真GNSS，不是现场验证。
- 研究问题：数值活动范围保底时，引入视觉边界候选后能否保持接近数值的形变指标？
- 文献动机：TAMA的全局/局部复核、TSAD-Agents的数值/视觉职责分工，见exp41-reading-notes.md。
  本轮复读本地缓存中的对应方法段；没有执行两篇完整作者流程，不挪用其原数据成绩。
- 适配：本项目原有activity_fit的线性累计/平滑累计位移形状，增加视觉给出的候选边界。
- 非目标：不要求形变视觉独立超过数值，不强制新增检出，不宣称各类领域SOTA。

## 固定流程

1. 冻结分段数值方法先从观测位移给出活动范围；数值无活动范围时不请求视觉，原结果保留。
2. 向视觉模型提供原始N/E/U全局曲线、正常参考和数值活动边界±21日图，数值范围明确是可错候选。
   模型确认原始位移持续活动后，可提出其边界，或输出uncertain/空列表，不输出内部阶段。
3. 对原数值边界和与其相交的confirmed视觉边界，用完全相同观测掩码/背景/跳变项
   计算累计linear与smoothstep活动模型拟合增益。选增益最大的边界，同分保留数值。
   数值候选始终在选项内；空输出或失败时保留数值，不重试，不将该保底冒充视觉识别成功。
4. 不新增无数值支持的形变区间，不改变单点/阶跃/暂态事件；形变各候选phases为空。
   缺测不赋逐日标签，视觉边界只取其区间内首末实际观测；活动确认先于边界细化。

按原分段方法使用90日正常尾部、本站正常历史噪声归一化、屏蔽独立spike、
背景常量/线性趋势及全部数值阶跃作干扰项。两种累计模板和至少15日的原有支持条件不改。
没有跨站毫米/速率阈值，也不扫描参数；最大拟合增益不保证标签更准，必须按真值评估。

## 对照和消融

- `nab_image`：数值活动保底＋图像候选＋同准则选择。
- `nab_text`：相同候选与全部绘图样本/中位线文字，模型与选择规则相同。
- `visual_bounds_image/text`：去数值边界选择，直接使用条件视觉输出替换形变，未路由站保持无活动。
- `segment_numeric`：整个流程无视觉的数值参考，也就是固定数值边界消融。
- 其余5个实际执行数值/ML方法同数据展示，无类型的通用方法不编造类型分数。

条件视觉输出含数值路由/候选，不能称完全纯视觉。主报告说明形变检出由数值拥有、
视觉只可能改变已支持活动的边界；逐站记录视觉调用、失败保底、实际改变/未改变。
其他三类分数不算本轮新视觉作用。论文无需单列自有数值近邻，本轮不为其新增计算。
