# GNSS-VLM-EXP03-v2：GNSS排序候选视觉确认、可修正活动边界与训练规模对照实验

## 问题与预先定义

主方法 `ranked_boundary_fusion`；数值定位 `rf_split_temporal`；旧主方法 `anchored_fusion`；
同响应自由视觉对照 `guided_fusion`。不根据测试名次改主方法。
EXP02三个已用测试种子只用于错误诊断，不作为本轮未见测试。
诊断显示数值与锚定融合各有1393个停止后假活动日，自由视觉234日；
23个可观测阶跃中20个被局部图覆盖，数值精确命中仅5个。

## 方法

不新增模型请求或改变EXP02绘图/提示：每站一轮全局+历史+六候选局部图。
数值模型、后验排序及窗口宽度沿用EXP02；持续运动必须由原始位移而非导数确认。
v1边界单项改进 `boundary_fusion` 的尖峰/阶跃保留数值与视觉相同类型、完全同日的交集；暂态沿用旧规则，
视觉确认范围必须完整处于数值选出的暂态窗。形变改为：视觉confirmed活动
与至少一个数值形变proposal有可观测日交集，则保留**视觉完整边界**，不再保留数值边界。
交集只支持存在相同形态，不证明视觉整个边界正确；可能减少平台误报也可能引入提前活动。
数值漏检仍会导致拒绝视觉活动；这项限制通过自由视觉对照测量。
`boundary_numeric_points` 为同响应消融：点类型直接保留RF默认判决，取消视觉否决；
`boundary_no_local/no_scores` 分别沿用EXP02同组输入消融，主融合规则不变。
v2主方法的尖峰/阶跃改为：每类型已有两个排名候选峰，只有视觉confirmed
点与候选峰完全同日、同类型且当天可观测才输出；**不再要求RF默认票决阳性**。
不作邻日吸附、不增加候选数量、不调概率截点；候选排序本身不是异常判定。
`ranked_no_local/no_scores` 分别去局部图组/显式分数组；
`boundary_fusion` 是只改边界、仍保留RF票决的对照，`boundary_numeric_points` 是取消视觉点否决的对照。
增加候选召回可能带来更多噪声误报，必须一起报告精度与正常误报。
所有失败输出零检测，不回退RF；uncertain不计确定检出；缺测从图、CSV与评分一致排除。

## 训练规模与数据

简单730日NEU仿真、365日正常历史、6场景及噪声机制全部保持不变。
开发种子2026101206：96训练、24验证、24测试；该种子测试不用于正式结果。
额外72训练站取新独立随机流，前24训练及验证/测试记录保持字节相同；
24训练对照是96训练的显式嵌套子集。各类型机制事件约8→32个，实际可观测数另报告。
视觉先执行前六验证站的3组输入，共18请求；先检查结果再执行大批。
小批显示两个尖峰排第一但被默认RF漏检；在已保存同响应上开发v2排名确认，
不调整分类器票数截点、物理阈值或窗口参数。v1/v2开发过程与负结果全部保留。
正式新种子2026101207、2026101208：各96训练、24验证、24测试，合计48测试站。
RF随机种子固定2026101206。所有数值法的96训练对照相同；额外24训练对照
在相同新测试记录上执行。新测试任何已查看结果不再用于本版本调法。

## 对照、指标与证据范围

正式主种子执行默认/平衡RF、ExtraTrees、IsolationForest、rf_temporal、
rf_split_temporal、visual_only、EXP01 fusion、guided三组、anchored_fusion、
boundary_fusion/点消融及ranked三组。
第二种子执行关键数值/视觉方法；相同数据分别执行24训练与96训练的
数值定位（必要时相同视觉输入方法）以区分训练与融合收益。
主终点形变日micro-F1、事件F1 IoU≥.5；报告四类型、精确点/±3日辅助、
正常误报、活动前/停止后假日数、缺测及全部失败。无point adjustment。
站点成对bootstrap2000次，合并时在种子内重采样；它条件于已拟合模型，非现场保证。
不得将已有多尺度/参考/数值协作思想宣称首次提出。
作者VisualTimeAnomaly原prompt/API/原解析适配的旧实验保留，不能称完整论文复现；
本轮机制同EXP02，新增对比只说明本轮适配与方法。在正式主批重新执行作者源码适配
及同响应原解析，以与新方法共享相同测试数据。

## 参数和来源披露

RF balanced权重、100树默认argmax；训练侧插补、48/30特征分工、
训练标签学习Viterbi转移、Laplace+1，均为GNSS适配而非作者默认复现。
正常前缀线性+年度季节背景和MAD是站点参考，不是统一mm阈值。
固定窗口5/21/45/60日、候选数量2/2/1/1及交集规则全部沿用或明确披露。
本轮两项融合变化是视觉活动边界所有权和排名点候选；分别通过boundary_fusion
与anchored_fusion对照，点否决消融独立报告。
Crocetti等2021正文3.1–3.3实际阅读：21日重叠三分量原坐标窗口、
多类断点位置、剔除缺测窗；当前手工特征/并存标签/插补/日级评价均不同，不能冒称该论文复现。
论文还区分正确类型但错断点时间，支持本轮精确日与±3日分开报告。
证据及后续开发结果见对应开发记录。
