## 值得保留的混合场景结果

六场景分层原已登记，所有场景均完整导出。图像对同粗筛文字在两批互不重叠新站上，
混合场景的范围与日级指标均较高：

| 新开发批次 / 混合场景站数 | 联合图Aff / 日F1 | 同粗筛文字Aff / 日F1 | 图像TP差 / FP差 |
|---|---:|---:|---:|
| EXP34 / 12站 | .4084 / .5345 | .2449 / .2918 | +78 / −1 |
| EXP34-S1 / 6站 | .4719 / .4335 | .1667 / .3457 | +23 / +7 |

混合场景含暂态、永久阶跃、真实形变及单点扰动的叠加，这与GNSS问题定位相关。
这些结果可作为“视觉图像在叠加事件中帮助识别暂态范围”的有限证据，
而不是图像全面优于数值或所有场景的证据。样本仍小，S1中改善集中于一个混合站，
且当前关注该分层是看过结果后的解释，不把它冒充新的事前主要终点。

仅暂态场景本轮图像Aff .8328、日F1 .9526，文字.8333/.9659，图像略低；
没有异常的正常/单点场景图像未产生暂态误报，但形变场景一站产生223FP日，阶跃场景另4FP日。
因此后续应围绕“形变与暂态区分”优化，而不只是继续增大图或延长自由形式推理。
