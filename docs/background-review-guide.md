## 后续补充的方法

查看无注入、无预测叠图的180日原曲线，必要时放大局部，并核对原值。30日分段只作导航，不能当异常边界。先描述形态，再记录原因及证据；稳定非零斜率不自动算异常。

| 字段 | 填写要求 |
| --- | --- |
| 站点和分量 | 匿名站点，N/E/U；不同分量可分行 |
| 观察范围 | 明确日期或约略月份；分别记录起止不确定性，不将月级线索硬填月初 |
| 曲线形态 | 孤立偏离、波动、台阶、持续趋势、加速或无法判断 |
| 原因与依据 | 质量异常、真实形变或原因未定；区分曲线判读、现场/维护记录和其他传感器 |
| 来源身份 | 审核者、日期、版本、是否接触检测输出 |

缺口内不猜起点，跨缺口差值不当单日跳变。缺测不自动标异常，未列范围不补正常；没有滑坡、没有换机或数据完整都不等于正常认证。SCWM-04月份级人工线索不能移用于其他站点。
