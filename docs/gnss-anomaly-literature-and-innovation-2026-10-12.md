# GNSS 异常识别：异常类型、指标、前沿方法与低训练成本创新方案

调研日期：2026-10-12。范围：以本项目日尺度 N/E/U 坐标／位移时序为主，补充原始 GNSS 观测与导航安全任务的边界。本文是定向文献调研与方法建议，不是穷尽式系统综述；“常用”指代表性文献及领域实践中的常见做法，不是文献频率统计。

本轮读取了原始论文网页、部分正文、作者代码说明及项目已有实验记录；逐项阅读范围见[证据记录](../artifacts/gnss-anomaly-survey-2026-10-12/reading-notes.md)。没有运行新模型、从零训练或开展新性能实验。以下“创新点”均为待验证研究假设，不能据此宣称首创或已取得提升。

## 1. 研究定位与优先结论

**优先研究：复杂观测干扰下，GNSS 目标形变事件的识别、定位及与质量异常的分离。** 这比笼统判断“曲线异常”更容易建立清楚的贡献：减少仪器偏移、尖峰和相关噪声造成的误报，同时保留叠加这些干扰的真实形变。

最值得先试两条路线：

1. **联合干扰假设的事件识别＋受约束视觉复核**：复用强数值候选和预训练 VLM，新增可计算的“即使允许观测干扰，是否仍需要持续形变解释”证据。无需从零训练大模型。
2. **冻结时序基础模型＋任务条件化的轻量适配**：借鉴 MOMENT、NCL 与 Anlu，用小型适配器／分类头区分目标形变、观测质量事件及其共存。核心不是更换骨干，而是让模型遵守 GNSS 的目标定义、噪声及缺测约束。

第一条与项目已有候选 NCDA 连续，不能重新包装成全新提出；第二条是可比较的备选主线。先各验证一个核心机制，不把基础模型、视觉、LLM、图网络与强化学习全部堆在一起。

项目已有120条仿真记录结果中，视觉数值配对方法日 F1 为0.908419，84日 XGBoost 为0.909885；对应事件 F1（IoU≥0.3）为0.657061和0.694611。因此目前没有证据认为引入视觉／大模型自然优于强数值方法。来源：[已有全量评测](landslide-persistence-scale-results.md)。这些已浏览记录可用于开发诊断，不应反复选方案后继续充当独立测试集。

## 2. GNSS 领域到底识别哪些异常

应区分三个层次：**观测形态、物理／仪器成因、任务目标**。同样的阶跃可以来自设备更换或同震位移；单站坐标曲线往往只能可靠识别形态，不能唯一恢复成因。正常长期构造运动或正常季节响应也不应一律当异常。

### 2.1 坐标／位移时间序列层面

| 类型 | 典型表现 | 常用识别依据 | 对当前研究的意义 |
|---|---|---|---|
| 孤立粗差、尖峰 | 单点／少数点明显离群，随后返回背景 | 稳健残差、MAD、局部差分、前后恢复性 | 质量异常；避免污染形变估计 |
| 永久阶跃／不连续 offset | 水平突变，之后维持新平台或原趋势 | 变化点、前后位置差、三分量窗口特征 | 可确认阶跃形态；“仪器”或“地震”归因需日志等依据 [G1,G2] |
| 暂态水平变化／异常片段 | 偏离原水平，持续一段时间后回归 | 成对变化点、区间对比、局部背景残差 | 可能是处理问题，也可能是真实暂态运动；不能仅由形态定因 |
| 速度变化、斜率变化、漂移 | 持续离开原趋势，或原速度改变 | 分段趋势、稳健斜率、累计位移、趋势模型比较 | 适合当前长期形变任务；不等于必然滑坡失稳 [G2,G3] |
| 非线性瞬变 | 加速、减速、震后衰减、慢滑移等 | 时间函数、局部速度、非线性／分段拟合 | 需先确认原始位移活动，再描述内部变化；不同成因不能混成统一标签 |
| 方差／噪声状态变化 | 波动突然变大、有色噪声增强、低频漂动 | 滚动稳健尺度、残差自相关、频谱、噪声模型 | 可导致大量假趋势；噪声变化与目标形变可同时存在 [G3] |
| 周期／季节结构异常 | 原有周期幅度、相位或形状发生变化 | 季节模型残差、频谱、跨周期比较 | 周期本身通常不是异常；本项目尚需明确正常季节背景 |
| 缺测、长中断、重复／冻结值 | 时间戳不连续、长期不更新、重复输出 | 数据完整性、间隔、重复率、质量标志 | 数据质量状态单独输出；GNSS稳定时相近坐标不等于传感器冻结 |
| 站网共模与空间异常 | 多站同步偏移或局部站点偏离邻站 | 空间一致性、共模估计、站间残差 | 同步性也可能是真实区域形变，不能默认全部去除 [G3] |

以上是适合组织研究的综合分类，不是某一篇论文提出的统一分类标准。Gazeaux 等的经典对比重点是 offset；Crocetti 等主要识别地震引起的不连续；EGU26 摘要明确列出 outliers、mean shifts、velocity changes。[G1,G2,G4]

**本项目建议输出两套可共存标签**：

- 目标事件：持续形变及其起止范围；必要时在范围内细分速度变化。
- 质量事件：尖峰、阶跃形态、噪声变化、缺测等；没有外部证据时不写死“仪器故障”。

例如“正在缓慢运动，同时发生设备偏移”应允许两类阳性。若观测不足以区分弱运动与漂动，输出待定，而不是强迫二选一。原始缺测位置不赋正常；活动边缘待定处不赋确定加速／减速。沿用[项目长期形变规则](landslide-design.md)。

### 2.2 原始观测和导航安全层面

| 任务 | 常见输入／检测量 | 当前只有日尺度 NEU 能否完成 |
|---|---|---|
| 周跳 | 载波相位、Geometry-Free（GF）、Melbourne–Wübbena（MW）组合、Doppler／TDCP一致性 | 不能直接确认周跳；坐标跳变不是周跳真值 |
| 多路径／非视距 NLOS | C/N0、卫星高度角／方位角、伪距残差、码相组合、多历元与环境信息 | 可见解算误差表现，但通常不能可靠区分这两种原因 |
| 异常卫星测量、钟差等故障 | 伪距、残差／创新、标准化统计量、解分离与一致性检验 | 缺少观测级冗余，不能直接复现此类算法 [G6] |
| 欺骗 spoofing、干扰 jamming | 接收信号、AGC、C/N0、相关器、时间／运动一致性，以及可信外部参考 | 仅凭日尺度单站坐标不能完成可靠攻击归因；干扰实飞观测层例子见[G7] |
| 高采样率地震检测 | 秒级或更高频率的三维位移、重构误差、多站一致性 | 日尺度序列只能研究另一时间尺度的事件，不等价于实时地震检测 [G5] |

这些任务值得了解，但第一轮不应全部塞入现有 NEU 实验。若以后取得 RINEX 或解算质量字段，可另立观测质量异常分支。GF/MW 的适用性取决于可用频点，不能将一个频率组合视为所有接收机都可用。具体输入依据为ESA Navipedia的[GF检测](https://gssc.esa.int/navipedia/index.php/Detector_based_in_carrier_phase_data:_The_geometry-free_combination)与[MW检测](https://gssc.esa.int/navipedia/index.php/Detector_based_in_code_and_carrier_phase_data:_The_Melbourne-W%C3%BCbbena_combination)官方教材。

## 3. 常用检测指标／特征

这里的“指标”是模型输入或异常评分，不是最终效果评价。以下既包含文献直接采用的特征，也包含建议用于本项目的具体实现；建议不冒充领域统一标准。

| 特征组 | 代表量 | 适合检测 | 主要限制 |
|---|---|---|---|
| 幅值和稳健残差 | 去背景残差、局部中位差、MAD标准化、极差 | 粗差、偏移、异常波动 | 先去趋势可能消除目标运动；需定义背景 |
| 时间变化 | 一阶增量、前后块位移差、稳健斜率、CUSUM／变化点评分 | 阶跃、漂移、活动起变 | 相关噪声会伪造趋势；原始二阶差分容易放大噪声 |
| 分段解释 | 平台／阶跃／线性／连续分段趋势的拟合代价差 | 偏移与持续运动混淆 | 代价差不是自动校准的概率，复杂模型有过拟合优势 |
| 三维联合 | N/E/U窗口、各轴极差、噪声标准化增量、方向一致性 | 小幅多轴变化、持续位移 | 不要求三轴全部显著；U噪声不能直接套N/E尺度 |
| 波动与记忆 | 滚动MAD、方差比、自相关、白／闪烁／随机游走等噪声模型 | 噪声突增、低频漂动 | 短窗频谱及噪声参数不稳定 [G3] |
| 季节与频率 | 年／半年项残差、频带能量、周期一致性 | 背景季节变化与异常残差 | 真实季节性活动可能是任务阳性，不能无条件滤除 |
| 学习模型分数 | RF／XGBoost概率、Isolation Forest／LOF分数、预测／重构误差 | 多类异常、弱监督异常 | 大误差不必然是目标形变；基础模型也可能重构异常 [M2] |
| 支撑与质量 | 有效样本率、最长缺口、边界是否有观测、局部噪声估计 | 判断结论能否成立 | 作为可靠性条件，不应让固定缺测模板泄漏标签 |

一个简单的稳健标准化形式是：

\[
z_{t,a}=\frac{x_{t,a}-\widehat b_{t,a}}{1.4826\,\mathrm{MAD}_a+\epsilon},
\]

其中 \(a\) 为分量，\(\widehat b\) 为明确规定的背景估计。1.4826 是正态情形下 MAD 的尺度换算，**不是 GNSS 有色噪声下的通用置信保证**；\(\epsilon\) 只是数值保护。阈值应在独立背景数据上校准，而不是默认所有站“3σ”都等价。

Crocetti 等的直接 GNSS 例子很有参考价值：归一化三分量滑动窗口，加上各分量在归一化前的极差，用常见分类器检测不连续；其训练／测试按站分开。该文§4.6还报告，添加一阶、二阶导数没有进一步改善结果。因此不能把“加入速度／加速度特征”本身当作必然有效的创新。[G1]

建议第一轮保留原始毫米量纲、相对噪声尺度和缺测掩码三种信息。逐窗口标准化虽方便基础模型输入，但可能抹掉物理幅值差异；应将尺度作为附加特征，并与不做此变换的基线比较。

## 4. 怎样评价异常识别，避免“高分但不好用”

### 4.1 文献常用与本项目推荐

| 指标 | 测量什么 | 本项目用法 |
|---|---|---|
| Precision / Recall / F1 | 报警可靠性、漏检程度及二者折中 | 基础必报；点、活动日、事件分别统计，不混在一起 |
| ROC-AUC、PR-AUC／AP | 分数排序能力及阈值曲线 | 推荐PR曲线优先，ROC补充；记录AP还是梯形PR-AUC，不能混称完全相同 |
| 事件级 Precision / Recall / F1 | 找对多少个完整事件 | 主终点之一；预先规定一对一匹配与IoU阈值 |
| 区间IoU、边界误差 | 覆盖与起止定位 | 同时报漏检／误报事件；仅匹配成功事件的低MAE不能代表整体更好 |
| Affiliation P/R/F1 | 预测与真实事件的局部时间接近性 | 辅助诊断；仍需单独评价无异常记录的误报 [E1] |
| VUS-PR | 综合阈值和时间容忍范围的区间评分 | 近期TSAD重要补充；记录实现、时间buffer范围和缺测处理 [E2] |
| 误报事件／站年、误报持续时间 | 实际报警负担 | 长期监测关键；无目标形变记录必须纳入 |
| 发现延迟、固定误报水平下召回 | 在线检测是否及时 | 仅用于严格只读历史数据的实验 |
| 分类型macro-F1、混淆矩阵 | 是否只擅长高频／强幅度异常 | 区分尖峰、阶跃、活动及混合事件，另报幅度／持续期分层 |
| 风险—覆盖、校准误差 | 待定／拒判是否有意义 | 启用待定输出时报告；不能删除难例后只报高Precision |
| 时间、内存、模型调用／token | 实际计算代价 | 分开记录训练、编码、推理和端到端成本 |

\[
P=\frac{TP}{TP+FP},\qquad R=\frac{TP}{TP+FN},\qquad
F_1=\frac{2TP}{2TP+FP+FN}.
\]

\[
\mathrm{IoU}(A,B)=\frac{|A\cap B|}{|A\cup B|}.
\]

建议主报告：**活动日P/R/F1＋事件F1（IoU 0.3与0.5）＋PR-AUC／AP＋无形变记录误报事件率**。另报起止误差、VUS-PR、分类型结果和成本。0.3／0.5是本项目可预登记的操作选择，不是GNSS领域统一标准。

质量异常与形变分别评分：尖峰按日期或预先指定的小容差匹配；阶跃按变化发生时刻匹配，不能将阶跃后整个新平台都算成“持续故障事件”；持续形变按区间匹配。单条混合记录可同时贡献质量和形变两项真值。

### 4.2 必须规避的评价问题

1. **不用 point adjustment 作为主成绩。** 只命中一小段就把整段真值改成检出，会夸大表现；Kim 等专门讨论了这个问题。[E3]
2. **测试集不选阈值。** F1-max可说明理论上最优阈值的结果，不等于真实部署成绩；阈值、后处理及持续长度均在训练／验证侧确定。
3. **不能只报Accuracy或RMSE。** 类别不平衡时Accuracy误导；删掉真实运动也可能降低残差RMSE。GNSS轨迹拟合与异常识别是相关但不同的任务。[G3]
4. **未知与缺测不是正常。** 已知活动中的弃判仍记漏检；参考未知区不当作正确结果，并报告评价覆盖率。插补值不生成新的真实观测标签。
5. **按完整记录／站点划分和重采样。** 重叠窗口不独立；同背景衍生样本不能跨训练测试，空间相关时采用更高层级分组。
6. **保持离线与在线分开。** 居中平滑、完整记录归一化及全局图用到未来；回溯得到早期起点，不等于当时已经报警。

### 5.1 直接 GNSS 证据

## 6. 六个可检验的创新候选

### A. 干扰条件化的非互斥事件识别（优先）

**要解决的问题**：真实持续形变与尖峰、永久偏移混合时，通用异常分数无法说明“测量出了问题”还是“位移持续发生”；先去阶跃再检测也可能损伤真实运动。

**组合基础**：GNSS轨迹／变化点建模＋稳健拟合＋强XGBoost／RF候选＋VLM4TS的候选复核范式。[G1–G3,M3]

对候选窗口，用相同观测、噪声处理和缺测掩码比较：

\[
H_0:x_t=b_t+j_t+e_t,\qquad
H_1:x_t=b_t+j_t+g_t+e_t.
\]

\(b_t\) 是任务允许的背景，\(j_t\) 是稀疏阶跃／质量干扰，\(g_t\) 是连续目标形变。两边共同允许干扰，不把“有阶跃”视为“没有形变”。通过稳健代价与复杂度惩罚得到证据差：

\[
D=\min_{H_0}J-\min_{H_1}J.
\]

D作为连续特征，不直接称Bayes因子、p值或后验概率。为避免复杂模型天然占优，必须固定候选搜索空间，在独立背景／验证集上标定阈值，并检验不同相关噪声。

**拟增加的贡献**：目标形变与质量事件可共存的GNSS事件判别，以及在共同干扰解释下的证据融合。LLM只读取原始图、两种解释的可复算量及候选时间范围，输出保留／修改／待定；边界由程序在真实日期上验证。不能声称多模型比较或两阶段复核本身新颖。

**最低成本版本**：先只做数值证据＋小分类器。如果不能改善“仅干扰”误报和“形变＋干扰”召回，就停止该模块；不要先大量调用VLM。

**关键消融**：两假设共同允许干扰 vs 只有背景假设允许干扰；有无D；纯数值 vs 同证据VLM；普通固定融合 vs 候选方法。候选生成必须完全相同，另报候选召回上限。

### B. 冻结基础模型的GNSS任务条件化适配（优先备选）

**要解决的问题**：通用基础模型可能把异常也预测／重构得很好，且“偏离常见形态”不等于“目标形变”。一个只由平直曲线构成的正常子空间还会把季节项、仪器偏移全部当成形变。

**组合基础**：MOMENT冻结表征＋NCL正常性约束＋GNSS三轴／量纲证据。[M1,M2]

实施步骤：

1. 从独立训练记录提取三轴多尺度patch表征；骨干冻结，编码一次复用。
2. 使用已知的目标定义建立参考：静稳／允许的背景，以及单独标记的质量干扰样本。质量异常可以是“无形变”负例，但不能被称为总体正常观测。
3. 训练小头，分别输出 \(p_{\mathrm{def}}\)、\(p_{\mathrm{quality}}\)，而非强制互斥softmax；保留毫米幅度、稳健噪声尺度、有效采样支持。
4. 第一版只比较普通线性／小MLP头与带任务条件约束的小头；不同时解冻骨干、增加VLM与复杂图结构。

**拟增加的贡献**：让冻结表示对目标任务有选择性——对不同噪声强度有合理稳健性，同时对持续累积敏感，并保留混合事件。需要在相同训练数据和同容量下证明任务约束有用；普通NCL迁移、双头或换一个骨干本身不足以构成贡献。

**关键消融**：专家特征XGBoost、冻结表征＋线性头、普通NCL适配、相同数据单头／双头、去物理量／去缺测支持。比较跨噪声、跨缺测、未见混合机制；不能只比较同分布F1。

**成本控制**：只用一个可获取权重的骨干、小头及少量固定配置。NCL正文的少量训练设定可借鉴，但GNSS是否只需5个样本必须实测；固定样本量学习曲线比先承诺“数分钟训练”更可信。

### C. 合法参考背景约束的上下文异常识别（需要明确新任务）

**问题**：相同速度在某站是正常背景，在另一站或另一时间段可能异常；“异常”是相对任务与正常机制定义的。

**基础**：Anlu的reference-conditioned detection＋GNSS背景运动／季节模型。[M4,G3]

**新增假设**：依据站点历史正常期和已知允许的背景，建立可追溯参考库；比较query与参考的相对趋势、残差和不确定性，而不是给一个全站通用阈值。用合法反事实配对验证模型确实使用参考：参考改变且任务定义确实改变时，标签才允许改变；加入无关参考不应随意翻转结论。

**潜在优势**：缓解跨站／不同正常速度和季节机制的迁移问题；可以冻结骨干，只训练参考适配头。

**必要边界**：当前项目把目标坡体持续活动当阳性，不可为此方案擅自把旧活动改为正常。需要新定义的背景数据及独立评价协议；来源语义不同的参考不能混用。Anlu本轮仅摘要级核验，第一步应继续核查正文、代码和权重。此方向暂不领先于A/B。

### D. 缺测与不可辨识性感知的区间识别

**问题**：长缺测覆盖了起变过程时，一次阶跃与一段持续运动可能产生相同可见端点；强行输出精确起点和唯一类别没有观测依据。

**基础**：多假设模型比较＋预训练模型／VLM的有限证据复核；遵守原始位移优先的活动规则。

**新增假设**：模型同时输出“确定活动内部”“可能边界带”“候选机制集合”。在数值接近的假设之间保留歧义，只有实际新增观测、站日志或参考站才能用于进一步消歧。不同平滑窗口的一致性可用作诊断，但不能直接称统计置信区间。

**潜在优势**：减少缺测、弱信号和记录截断处的虚假精确结论；不用大规模训练。创新性需要落在可辨识性分层的GNSS评价和识别收益上，而非“允许模型说不知道”。

**关键评价**：相同覆盖率下的错误率、活动召回、错误确定性声明、边界带宽度与覆盖、普通强信号表现。必须防止通过扩大未知区获得漂亮分数。

### E. 保护真实区域形变的多站共模识别（有站网数据后做）

**问题**：多站共同变化既可能来自处理误差，也可能是区域真实运动；直接共模去除会误伤科学信号。[G3]

**组合**：稳健低秩／PCA共模估计＋局部事件残差＋站点空间关系；可加冻结时序表示的小型判别头，第一版无需GNN。

**新增假设**：联合建模“广域共享变化”“空间局部连续运动”“单站质量干扰”，通过参考站、空间范围与外部已知事件约束归因，并保留无法辨识的共模。创新价值是降低真实区域事件被当共模删除的比例。

**必要数据与评价**：同期多站NEU、地理坐标及适当外部参考；评估事件F1、误报、真形变损伤和速度偏差。当前独立单站仿真不能证明该方向有效，空间相关本身也不保证唯一分离。

### F. 受物理／时间契约约束的离线LLM特征发现（低优先级）

**基础**：M5让LLM在开发阶段产生特征，最终CPU执行固定数值检测。

可探索的增量是：生成候选必须通过时间间隔、单位、缺测、常量平移等语义检查，并在机制留出上验证稳定性。只把LLM放在离线开发阶段，部署不逐条调用。

但项目已经做过近邻试验且未优于强基线，[停止记录](landslide-feature-discovery-results.md)应保留。“让LLM写特征”已存在，重启同一思路没有充分依据。只有新的约束确实能排除已观察到的无效特征、且在训练侧小规模试验有信号时，才考虑开展新登记实验；不列入第一轮主方法。

## 7. 推荐的最小验证路线

### 7.1 先固定任务与数据，再比模型

目标是识别事件，不先把所有活动强制细分成完整加速—匀速—减速链。基本评价覆盖：纯背景、纯尖峰、纯阶跃、连续形变、形变＋尖峰、形变＋阶跃，交叉有色噪声、幅度、持续期、缺测和截断。背景季节／正常漂移只有任务定义明确时再加入。

保留原始日期和缺测。过程真值与可观测参考分开报告：仿真潜在活动不代表在该噪声下必然可识别；AI视觉参考不能称独立专家金标准。新增种子只能检验同一机制的重复性，**机制留出／真实站点外测**才能加强迁移论据。

### 7.2 分两步控制工作量

**第一步：A的数值可行性与B的冻结表征可行性。** 保持相同训练／验证记录，先跑现有强XGBoost、稳健变化点／趋势检测、A的联合假设证据、一个冻结MOMENT小头。开发侧若没有稳定纠错收益，则暂停相应候选。

**第二步：只推进胜任的核心假设。** A若成立，再比较同候选的数值判定、固定融合和VLM复核；B若成立，再比较普通小头与NCL式任务约束。避免先做十几个大模型、再从测试集挑赢家。

本地机器学习可优先CPU，小头／特征编码视模型要求用现有GPU。不要先从头训练Transformer、全参微调LLM或强化学习Agent。统一记录实际时间、峰值内存、编码开销和API调用；没有测量前不承诺耗时或费用。

### 7.3 最终对照与成功条件

至少保留：现有最强数值模型、传统稳健变化点／趋势方法、所选前沿方法的明确GNSS适配、同数据同信息的简化组合、候选主方法及对应机制消融。

成功证据应包括：

- 整体活动与事件识别不因追求某个难例子组而显著受损。
- “纯干扰”误报减少，同时“形变＋干扰”事件召回得到保持或提高。
- 相对于相同信息量的强数值模型有可复现增益；如果视觉／LLM无额外收益，就不把纯数值收益归给它。
- 阈值在验证侧冻结，在新的整记录／站点／机制上测试，报告整记录配对不确定性。
- 增加训练、标注、推理的成本与收益相称；解释质量不替代识别质量。

可优先使用的工作题目是：**“复杂观测干扰下的 GNSS 形变异常识别：联合假设证据与轻量多模态复核”**。若B在跨背景迁移上更好，再采用 **“面向混合形变与质量异常的冻结时序基础模型轻量适配”**。题目属于候选定位，尚无新方法效果证明。
