# EXP28：竞争解释反事实视觉复核（CEV-GNSS）与720站扩大评估

2026-10-15。分支`codex/exp28-expanded-competing-review`，父版本`134738c`。
优化前保留`backup/exp27-before-expanded-cev-20261015`，EXP27完整ZIP的SHA重新核验通过。

## 结论与采用决定

本轮完成96独立训练站、360开发站及360测试站、22方法的完整评估。
**发现了可保留的、依赖模型与指标的视觉范围识别收益：CEV-Qwen-VL的有图版本相对同信息文字，
开发和测试暂态Affiliation F1分别提高6.07、6.00个百分点。**
测试三个种子均同方向，图像和文字请求均成功，存在真实恢复暂态的案例；不是只与没有观测的去图版本比较。
但误报增加、测试日F1略降，不能描述为所有指标更好。

预定主方法**CEV-Flash / `ce_flash_image`未达到原登记采纳条件，取消生产集成**。
Qwen-VL是事前登记的模型对照，保留为有视觉证据的研究变体，不事后替换本轮主方法。
原ECV边界放大在测试集改善，但开发集未优于原CFV，保留为补充候选。
生产`src/gnss_research`及既有Word草稿不替换，避免把仍有取舍的单项结果写成全面升级。

这批数据现已用于评价，后续修改方案须另取新测试站，不能继续称本批未见。

开发/测试各360站中，**各28站触发自由候选复核**，并非720站都调用视觉模型。
开发有68组自由候选，触发站数已明显多于EXP27的2站。
无候选的站保留在全站主表，既给全站指标，也给触发站、混合场景及三个种子分层。
各分区先60站验证执行，再完成300站，没有因为开发分数不好取消独立测试。
本轮增加数量，没有增加真实GNSS现场数据或专家标注证据。

## 方法及消融

新CEV逐候选比较原位移、仅扣暂态、永久扣除、仅遮蔽起点单个观测四列，
三轴共享纵尺度、原始日索引及候选ID；扣除量只从起点局部估计，不拟合返回边强制闭合。
不设跨站统一毫米/速率阈值，不改原数值参数，不引入复杂噪声，缺测不填充。
图是假设诊断，不是真值；输出仅选择既有暂态配对，长期活动及内部阶段仍沿用数值结果。

主实验19方法在调用前登记；完整开发后、任何测试调用/评分前，追加EXP28-S1的原CFV
同提示文字、仅原图和完整去图，最终22方法。追加时间明确保留，不冒称原协议预计划。
CEV的文字控制含同窗口逐日原始/历史残差归一化点与offset估计，可重建假设操作；
完整去图仅删图片、缺少逐日观测，是较弱控制，不能独自证明图像不可替代。

完整方法键、原库与GNSS适配、指标及作者源码边界见[方法与指标说明](exp28-methods-and-metrics.md)。
主协议、补充协议、测试冻结SHA分别见[主协议](experiment-exp28.md)、

开发图/文字Aff-F1为.8587/.7980，测试为.8717/.8117，差值分别+.0607/+.0600。
测试图多106个TP日、少106个FN日，但多183个FP日；精度下降4.13个百分点、召回提高2.23个百分点，
日F1下降.0041，四类F1下降.0027。开发日F1则由.8330略升至.8352，但仍多230个FP日。
因此可以报告**视觉有助于混合场景中暂态候选的范围发现，存在召回与误报权衡**，
不能写成“视觉全面提高GNSS异常检测准确率”。

测试相对文字，17站最终事件改变：暂态正站Aff改善11站、退化5站，另1个负站误报改变。
有7站TP日增加；另有3站Aff增加但TP未增加且新增FP，必须区分两种情况。
VL图与文字两条路径在开发和测试各28次请求均成功，图/文字差异不是解析回退造成。

测试28触发站图/文字Aff-F1为.8646/.5767，日F1为.5722/.5445；
60个混合站图/文字Aff-F1为.8935/.7735，日F1反而为.7965/.8017。
差异集中混合站，单一暂态场景各结构方案相同，不推广为所有异常类型均改善。

描述性配对站bootstrap 2000次：VL图相对文字的Aff差值开发95%区间[.0160,.1125]，
测试[.0221,.1066]。此计算在评分后补充，用于展示不确定性，不是采纳硬门槛或新的方法选择。

不能声称稳定优于强数值方法，更不能声称优于本轮未重跑的近期论文管线。

## 其他方案的判断

- **CEV-Flash不采纳**：开发/测试相对CFV的Aff差值为−.0851/−.0609，日F1亦下降。
  测试虽相对同提示cfonly日F1提高.0066、FP少90日，但Aff下降.0179；有局部改善不足以替换原法。
  新主方案输出失败16/28，成功子集另报，不能把含失败成绩全部归因于图像本身。
- **原CFV不形成稳定范围提升**：开发图优于文字Aff .0198，测试反而低.0235。
  测试四类F1仍比文字高.0101、FP少35日，但日F1略低，继续作为指标取舍变体。
- **ECV保留补充候选**：测试相对CFV的Aff提高.0225、日F1提高.0219、四类提高.0088，FP多11日；
  开发Aff低.0091，不能用测试改善覆写开发负结果。大样本没有同ECV提示的文字/去图控制，
  与CFV文字的比较不能单独隔离ECV提示与放大图贡献。
- **TCV未发现更稳定收益**：测试Aff略高CFV、日F1略低；开发两项均更低，不升级。
- **长期形变没有新增视觉收益**：结构方案测试形变Aff均.9366、形变日F1均.9002，
  四类F1变化主要来自暂态与阶跃重新分类，不由视觉形变阶段改进产生。

## 对论文与下一轮的建议

按EI应用论文目标，本轮足以保留一项有限且有依据的论点：
**在简单GNSS机制仿真的混合异常中，候选引导的视觉核验可提高特定模型的暂态范围Affiliation指标，
相对同信息文字具有可复现方向的增益，同时存在精度与日覆盖取舍。**
还不足以写成全类型、全模型或所有近期论文方法上的最优。
目前最有用的证据是VL图/文字的匹配消融与实际TP恢复，不是主CEV-Flash的成绩。

下一轮优先验证“强数值近邻给出初始配对，视觉只裁决有冲突的区间”，
原因是本轮近邻日F1强，而视觉在e0149/e0191/e0341有互补恢复，也在e0119等站带来明显退化。
先在新开发站比较数值近邻、原VL竞争图、仅原图、仅CFV图及同信息文字，
不预设“有图就覆盖数值”，不按当前测试结果挑站制定规则。
应补足VL仅原图/仅CFV图控制，才能区分普通图像输入与四列竞争解释设计的独立作用；
本轮不能把已证实的模态收益直接等同于四列布局必然更好。
后续仍保持简单数据、无统一物理告警阈值，并沿用本轮扩大规模，不回到仅数站决定成败。
