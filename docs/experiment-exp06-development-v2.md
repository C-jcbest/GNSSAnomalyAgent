# EXP06开发v2：保留数值检测，视觉消解返回对歧义

## Material Passport

类型：首6站开发结果驱动的方法修改；不是未见测试。新方法`segment_pair_repair`，暂定 **SDR-VLM（位移结构分解与视觉语义修复）**。
沿用[v1全部数据、数值参数、模型、图像与主指标](experiment-exp06-development.md)，只改变视觉职责。

v1首6站：数值新分解四类日F1=.9954，视觉逐项否决融合=.7877，旧完整图=.7895。
混合站数值活动563—690被视觉标uncertain，且尖峰站有一次视觉输出失败。
因此不继续把视觉当全部检测的必需裁判：数值检测独立输出，视觉只修复未配对的跳变类别。

1. 数值选中的尖峰、阶跃、暂态及活动全部保留；活动边界不因视觉遗漏或不确定而截短。
2. 对数值未选中的备选返回对，只有视觉明确确认暂态、两边界各在±7日内、
   两边均仍对应数值阶跃，才将这两个阶跃改为一个暂态。不得任意新增、删除活动。
3. 已被数值配对的返回对不拆开。视觉无法确立未观测的返回。
4. **视觉请求失败时没有语义修复，数值独立路径仍输出；显式记录`visual_dependency_status=failed`。**
   这是一项新增方法定义，不是隐式重试或错误当成功；父视觉失败数单列。
   纯视觉、旧融合及v1否决融合失败仍按零检测。两类方法不能共用“失败全零”的描述。
5. 首6站复用已存响应作一次显式离线派生，记录原注册/候选/响应哈希，不重请求、不覆盖v1。
   余18站按本协议新登记并执行54次请求。两部分合并为24站开发证据，不能称独立测试。

预先定义的主方法候选仅`segment_pair_repair`；若全24站不优于旧完整方法或自身数值消融，
如实说明视觉增益是否成立。主指标仍四类等权日F1，各辅助指标全部保留。
正式测试必须先据24站冻结，再使用2026101405/2026101406新站。

对照维持v1，新增`segment_pair_repair`和同响应`segment_fusion`、`segment_visual_bounds`，
使否决式与修复式视觉职责能够直接比较。无需新增代理、微调或复杂噪声。
