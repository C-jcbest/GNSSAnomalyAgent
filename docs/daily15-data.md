# 当前数据口径：每日15点与180天长窗口

2026-09-22。用户决定暂时只分析每日15点，并延长测试窗口。当前采用 **北京时间每日15:00，180个日历日**；此前三种日代表值对照和小时任务暂不继续。

## 固定规则

- 从已收束的 `data/processed/offline-v2/` 离线提取 UTC 07:00，即北京时间15:00的记录。直接选值，不取平均、中位数、附近时刻，不去趋势。
- 每站日序列移除首尾全部分量缺失的日期；内部缺失日期、部分分量缺失和零值原样保留。保留原CSV中所有坐标列及选中行文本，来源哈希可追溯。
- 保存全部可用日历史；主窗口取该站日历史末端的 **180天**，不按曲线或检测结果选段。沿用此前长窗至少80%三轴完整的门槛，即至少144个完整日。
- 历史不足180天或该窗完整率不足的站点只保留日历史，并记录原因；不填补、不缩短主窗口，不重新分配来源组。
- SCWM-04整站仍单列辅助，保存267天日网格、263个有效日（2025-12-29至2026-09-21）；网页也可查看最近180天，包含六月前上下文。
- 日窗口显式携带 `sampling_hours=24`；历史小时窗口缺少此字段时按1小时兼容。缺失天不能删除后压缩为相邻日。

180天是为覆盖多月变化采用的操作设置，不是文献证明的最佳长度。长度和完整率不代表背景正常性；候选均未批准正常，没有生成真值。
