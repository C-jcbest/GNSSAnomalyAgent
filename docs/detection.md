# 检测与评价

## 智能体目标分工

2026-10-01明确设计目标：智能体有效结合数值与视觉的优势。Range利用视觉识别持续异常形态，并通过观测数值工具精确定位活动范围的起止；Point以数值可疑点为起点，结合视觉与局部数值证据筛除非异常点。Point筛选须同时报告误报减少与真实异常误删，Range定位须同时报告边界误差、覆盖指标、漏检与正常误报。

两种检测任务均处理全部输入，不能根据真实异常类型选择分支；工具与提示不接收真值或注入参数。后续设计优先服务于范围定位和点误报筛选，不默认增加曲线重构、多事件残差循环或多智能体。

Point已支持候选保留/拒绝；原Range边界协议只允许候选内收缩。新增定位工具协议实现了观测窗口内的边界方案搜索与智能体选择，效果须由新背景实验检验。两种协议的冻结运行分别保留，不改旧登记。

## 当前流程

研究主线是检验智能体联合视觉与数值证据能否提高检测准确率。固定数值基线后，优先比较融合复核与各单路、简单并集/交集及按任务固定分工；数值侧修改须服务于已明确的融合问题。若融合增加一次模型复看，应提供同路由的视觉复看对照，区分证据组合与额外调用机会的收益。当前实现使用 LangChain `create_agent`，在候选约束下执行一次自主工具查询和一次最终判定。历史单轮复核仅作为设计依据。

当前流程：独立Normal校准 → 登记协议和预算 → 新背景数值/视觉独立检测 → 共享候选复核 → 离线评价。冻结参数在数值源码与配置一致时可以复用；历史运行保留其原始版本，代码整理不产生新的科学结论。每次正式实验先明确数据划分、样本数和调用预算，不以工程测试代替实验。

准备阶段可读取数据目录和真值文件以登记哈希，但检测进程只读 `inputs/`、`config.json`、`parameters.json`、`registered.json`。真值、类型、背景组、生成幅值和活动位置不会复制到推理输入。数值及视觉全部分支处理全部观测，不按真值路由。

## 数值

`numerical.py` 是自定义工程对照，不是论文算法复现：局部双侧中位数差识别孤立Point；相反方向的水平变化配对识别暂态；滑动Theil–Sen斜率与高低阈值识别活动趋势。持久水平变化仅用作内部去阶跃，不作为Point输出。

参数必须从独立Normal数据显式校准。校准边界检查数据批次为完整Normal集合；算法只接收观测，不读取真值。阈值按Normal的峰值/斜率分位数计算。输出参数带校准输入哈希、seed和数值源码哈希。登记评价数据时拒绝相同seed和完全相同校准输入；复制或外部修改的数据还需人工按背景组检查，不把简单哈希匹配称为所有泄漏的证明。

## 视觉与预算

固定 `qwen3.8-flash`，显式 `enable_thinking=false`，temperature=0，max_tokens=8192，JSON Object请求加本地严格校验。凭据从环境或显式指定的本机env文件读取，旧的模型环境变量不覆盖型号。

`rendering.py` 只绘制观测：1800×1200像素、N/E/U三个对齐面板、日索引0–364、毫米纵轴，无真值。Point和Range分别发送提示。提示只定义检测任务和输出格式，不包含生成参数。

n例初始请求为2n，最多4n；仅正常结束但结构错误允许纠正一次。网络、型号不符、thinking输出或截断错误不重试。首例两次正式请求承担连接与格式检查，不额外发送探针。登记后合法结果即停止；未知中断不自动恢复。逐请求保留开始/结束账本、实际型号、响应ID、usage和耗时；金额未返回时记未知。

## 评价与输出

- 点异常（Point）与范围异常（Range）均记录 Precision、Recall、F1，以及 Affiliation 的 Precision、Recall、F1。总体结果和按类型分组的 JSON/HTML 报告都包含这六项。
- Precision 是报警中命中的比例，Recall 是真值中被检出的比例，F1 综合两者。Point按精确日期计分，Range按逐日覆盖计分；先汇总全部样例和分量的命中、误报、漏报数，再计算指标。Point的±3日结果仅作定位诊断。
- Affiliation 衡量预测与真值在时间上的接近程度。第100天的点转换成覆盖一天的区间 `[100,101)`；两端均含的范围 `[100,113]` 转成 `[100,114)`。这是计算所需的表示，不扩大标签或增加容差。
- Affiliation先对每个有真值的样例分量计算，再分别平均Precision、Recall、F1，同时记录参与平均的分量数。失败或没有预测的正分量三项均记0；没有正分量时三项均为N/A。正常分量不参加这个平均，误报和失败仍单独记录。
- 区间两端均含，按唯一日期集合计数。预测中的重复点或重叠区间不重复计分。
- 缺失或失败阳性仍计FN；失败正常例单独记录，不能算干净。无阳性F1为N/A，误报数仍报告。
- 类型只用于评价后的分组统计。组内派生相关，后续置信区间必须按背景组重采样。
- 离线对照 U/I 将数值与视觉的逐轴日期集合取并集/交集，不增加模型请求；任一路失败或缺失时，对应融合任务记失败，不回退为单路。Range集合重建为不重叠、两端均含的连续区间。
- 开发报告使用运行前登记的seed、2000次背景组配对bootstrap（第一阶段seed=2026093003），给出总体指标和方法差值的95%百分位区间；每次重采样重新汇总TP/FP/FN。区间仅作探索描述，不作多重比较后的确证。互补TP/FP仅在两路均成功的样例上计算，并明确排除数；主指标保留全部样例。

运行目录保存输入、配置、源码/依赖哈希、两路输出、请求账本、`evaluation.json` 和可独立打开的 `comparison.html`。写入拒绝覆盖，不提供历史迁移或兼容入口。历史运行必须结合对应源码与依赖快照读取；不得修改旧登记来适配新版本。未执行的一路在评价中算缺失，不是成功空预测。调用和评分命令见[开发与运行](development.md)。

## LangChain 共享候选实验

`experiment-register` 在生成前登记源码、依赖、种子、校准参数、对照及预算；`experiment-run` 一次执行生成、独立检测、三种复核和离线评分。它不提供自动恢复或重发入口。

候选由观测预测产生：Point 使用数值孤立点，Range 使用视觉范围和数值暂态范围。各复核组共享相同候选ID、起止日、来源和无标签全局图。三个原有复核对照只能逐候选保留或拒绝；边界收缩智能体仅对Range增加候选内收缩动作。没有候选直接返回成功空预测；候选上游失败传播为失败。所有输入均进入这一规则，不按类型或真值路由。

- 候选视觉复核：候选和图，初判后复查。
- 固定证据融合：预先计算所有候选的两类数值证据，初判后复查。
- LangChain 智能体：第一轮自主选择 `candidate_statistics`、`local_samples` 中的一种或两种及候选ID，工具执行后第二轮最终判定。每种工具最多调用一次。
- 边界收缩智能体：工具、观测证据和轮数与原智能体相同；Range最终输出每个候选的 `null`（拒绝）或两端均含的 `[start,end]`。保留整段返回原边界，收缩必须满足原起点 ≤ start ≤ end ≤ 原终点；不允许拆分、扩展、新增候选或改变轴。Point沿用布尔保留/拒绝协议。仅改变Range动作空间及其必要输出说明，不改变数值参数、工具、候选或背景。

工具仅接收观测、候选和已校准阈值。统计工具返回候选前后7日水平、孤立点分数和31日原始斜率；样本工具返回边界附近和区间内部少量真实观测。窗口和采样位置由候选确定，不能使用注入范围。原始斜率与处理后阈值不可直接等同。

四组均有两轮语义请求机会，每任务总共只允许一次结构纠正，最多3次模型请求。越界收缩属于结构不合法，不自动裁剪；正常完成时仅纠正一次。固定 qwen3.8-flash、thinking=false、8192回复上限；网络/截断/型号/思考契约错误不重试。LangChain 使用严格HTTP适配器，禁用远端追踪。每组首个有候选的Point和Range承担正式门禁；门禁失败即停止该组，其余任务记失败。

n例全部预算上限28n（独立视觉4n，四种复核合计24n），实际费用记录请求、tokens、耗时，金额未知时不估造；当前不开展缓存或成本优化。组间匹配调用机会，但第一轮功能和实际证据量不同，结论针对完整策略，不把差异完全归因于自主性。新协议 `langchain-boundary-v2` 主比较为边界收缩智能体与候选全部保留的Range F1；与原智能体的比较用于检验动作空间，另比较任务分工及两种复核对照。背景组配对区间下界大于0才支持本批主比较改善；同时报告Recall、正常误报、失败、TP/FP损失、Point及全部六项指标。事后形态分组和次比较仅作探索诊断；0次正常误报的bootstrap零宽区间不能解释为总体误报概率为零。

## 专门定位工具实验

`localization-v1`保持背景、模型、数值基线和共享候选不变，检验专门边界工具与方案ID选择这一完整策略。对照为N/V/U/I、任务分工、候选全部保留、两轮候选视觉复核、原边界收缩智能体、定位工具固定评分、定位工具智能体。Point沿用数值候选与原统计工具的布尔筛选；工具固定评分的Point等于数值输出，不将Point差异归因于Range定位。

Range每个候选的起点和终点各在原预测±31日内搜索，搜索区域外另取31日观测上下文，截断到0–364。候选不规定注入长度、幅度或位置；不新增候选区域。用冻结数值阈值移除孤立点后拟合常水平、永久阶跃、暂时水平偏移和连续渐变后平台；永久阶跃仅是非目标解释，不作为Point或Range输出。噪声尺度从原独立完整Normal校准观测的相邻差分稳健估计，校准输入哈希逐项核对。评分为SSE/σ²+k·log(n)，k分别为1/3/4/4，是固定复杂度规则，不宣称校准了指定误报率。

同一候选返回原范围、最佳水平方案、最佳渐变方案、非目标评分及原始观测样本。固定评分对照选择最低评分，非目标最低时拒绝；智能体第一轮必须为全部候选查询同一只读工具，第二轮结合原图输出每ID的null/original/level/trend。提示不显示程序最终选择。近优方案跨度仅为评分诊断，不是置信区间。比较同时包含工具、搜索动作和输出形式变化，不能据此单独证明工具自主选择或某项提示有效。

预登记主比较为定位工具智能体减定位工具固定评分的Range逐日F1，背景组配对区间下界大于0才支持本批额外智能体收益；与原边界版、候选集合、独立视觉及候选视觉复核的比较为探索性。两任务均报告六指标、Normal误报和失败；另记录边界误差及匹配/漏检事件数、增删TP/FP、Point误删。每复核任务两轮语义请求、总共一次结构纠正，最多3次请求；三个复核组加独立视觉共22n上限，不重试其他失败、不覆盖、不恢复未知中断。

## 观测窗口内端点搜索实验

`localization-window-v1`只改变定位端点的搜索域。旧定位组仍分别在原起点、终点±31日搜索；新窗口组允许两个端点在原有观测上下文[max(0,start−62),min(364,end+62)]内部任意移动，至少连续两日。原始数据、孤立点预处理、观测上下文、噪声尺度、四种拟合、复杂度评分、原边界选项、观测样本、提示、模型和两轮流程均相同。不根据真值扩大窗口，不新增候选区域，不预设异常长度。

同一批新背景同时运行旧端点工具/智能体、新窗口工具/智能体，以及N/V/U/I、任务分工、候选全部保留和两轮候选视觉复核，共11方法。新旧定位智能体共用旧定位组已经冻结的Point结果，含失败，排除重复请求的服务波动；Point仍处理全部输入，不能把共享结果差异解释为Point策略改变。新窗口组的Range门禁失败也不改写共享Point结果。

主比较为新窗口智能体减旧端点智能体的Range逐日F1，2000次背景组配对bootstrap。新窗口智能体减新窗口工具固定评分、新旧工具评分差值及与视觉/候选集合/候选视觉复核的比较为探索性。所有方法均报告Point/Range六指标、正常误报、失败，以及匹配/漏检事件数和条件边界误差；同时报告相同匹配事件的边界比较及两种搜索域的事后可达性，避免用少检出事件的条件误差掩盖漏检。

每例请求上限19次：独立视觉4、候选视觉复核6、旧端点智能体6、新窗口智能体Range3；新窗口Point不新增请求。保持正常完成但结构不合法仅纠正一次，其他失败不重试，未知中断不恢复。窗口扩大增加可选择的边界，也可能增加误报，固定评分不保证指定误报概率，不能仅由F1提高宣称每个边界更准。

## Point局部观测图实验

`point-context-v1`只为Point复核增加候选局部图，保留原全年图。数值候选、统计工具、模型提示、布尔保留/拒绝协议与两轮流程保持不变。每个数值候选的对应轴在日期前后14日内绘出逐日原始毫米观测，窗口截断到0–364；显示候选ID、全局日期、观测点及候选标记，标记只是提议。每页最多4个候选，不按真值筛图、不平滑、不删采样点、不截断幅度；每个面板纵轴独立，因此不能由面板高度比较跨候选幅度。

同批新背景运行全年图/全年加局部图与仅视觉/数值工具两种复核的四个组合。主比较为局部图数值智能体减全年图数值智能体的Point逐日F1；2000次背景组配对bootstrap区间下界大于0且局部组TP不少于全年组，才支持本批改善。另报告Recall差值、删除FP和误删TP、全体六指标、Normal及失败。局部视觉减全年视觉、局部数值智能体减局部视觉及相对数值基线为探索比较，不按赢家事后换策略。自主工具选择可能随图改变，新增像素及其影响属于整个策略，不能单独证明视觉注意力机制。

Range保留观测上下文内任意端点定位，两个局部组分别共享对应全年组的冻结Range输出，包括失败；Point门禁失败不改写共享Range。各组仍处理全部输入，空候选直接空预测，上游失败传播。完整对照包含N/V/U/I、任务分工、候选全部保留、四种复核和窗口工具固定评分，共11方法。工具评分Range依赖视觉候选，不能称为独立纯数值方法。

局部图在推理前生成，登记候选、配置和全部图片哈希；复核前核对，不接受篡改图或未登记图。每例请求上限22次：独立视觉4，全年视觉6，局部Point视觉3，全年数值智能体6，局部Point数值智能体3；共享Range没有新请求。各任务仍两轮语义请求与最多一次结构纠正，其他失败不重试、不覆盖、不恢复。当前不做成本优化。

## Point双解释判定实验

`point-hypothesis-v1`只增加Point系统说明：每个候选同时比较真实孤立异常与正常背景偶然尖峰，结合局部原值、全年背景及可用数值强度；孤立形状和超越候选阈值只是入选证据，不能直接作为独立确认。不规定幅度阈值、注入数量、长度或必须拒绝的数量，不新增解释字段。最终仍只输出逐ID布尔值，结构纠正保留本组判定说明。

新旧说明分别用于仅视觉复核和数值工具智能体，共四个Point组；四组使用相同全年图、全部候选局部图、候选、数值工具、两轮和输出格式。唯一改变为系统判定说明，不改局部图、数值阈值或工具。后台不收集解释，因此不能从结果直接推断模型实际采用了哪种理由。

窗口智能体先产生冻结Range，四个Point组均复制这份Range结果，包含失败；Point门禁失败不改写共享Range。窗口智能体的全年图Point仅作留档对照，不纳入主比较。另保留N/V/U/I、任务分工、候选全部保留及窗口工具评分，共12方法，全部处理全部输入。

主比较新说明工具智能体减原说明局部图工具智能体的Point逐日F1；2000次背景组配对区间下界>0且新组TP不少于原组，才支持本批改善。新旧视觉说明、新说明工具减新说明视觉、相对数值及原工具减原视觉为探索比较。报告Point/Range六指标、Normal与失败、FP删除和TP误删；不由更高F1单独宣布目标达成，不按本批标签选阈值或改参重跑。

每例请求上限22次：独立视觉4、窗口智能体6、四个Point复核组各3；四组Range不新增请求。固定模型、thinking=false、8192回复上限，一次结构纠正和失败规则均保持不变。额外提示长度和可能变化的自主工具查询属于整个策略，不能单独证明某个句子或内部推理机制有效。
