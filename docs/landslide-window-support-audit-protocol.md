## 预先固定的统计

1. 每个中心日、每个窗口重建完整居中窗、中心有观测、至少ceil(0.75*w)个有效样本、两侧各至少0.6*(w//2)个样本、最长连续缺测不超过7日的守卫。主原因互斥，按上述实际执行顺序选择；重叠失败原因另列。边缘缺口计入最长缺测。`valid_counts`逐日核对；所有守卫通过应与缓存有限拟合／速度／加速度／速率同时可用一致，否则审计中止。
2. 有限切向加速度必须有有限速度，且与缓存v·a/||v||相符；速度有限但切向缺失只能解释为缓存显示门控未通过。误差尺度未缓存，不推断物理平稳、低速或统计置信度。
3. 对有观测活动日报告各窗速度及切向支撑，三窗并集／交集，31窗相对61窗新增及丢失日、91窗相对61窗新增及丢失日。分别报告窗口完整落在同一活动内部、跨边界与跨边界观测组成。活动外分为作者stationary／unknown／其他activity，不能把unknown当平台；跨边界不等于污染已被证明。
4. 三个窗口对报告共同有限速率／切向日、速度向量夹角余弦、速率绝对差和相对差（除以两者较大值）。向量模须>1e-9才能报告夹角，仅为数值除零守卫。切向异号按a*b<0机械计数并保留双方幅度及分位数，零值不算异号；不设物理显著阈值，不据此赋A/D或弃判。近零异号可能仅为噪声。无置信区间、显著性检验或独立性能分数。
5. 总体、12记录、21活动内部完整汇总；逐日窗口CSV及窗口对CSV可查。所有活动统计分母是有观测活动日，缺测单列。断带按日历连续索引，不跨缺测聚合。
