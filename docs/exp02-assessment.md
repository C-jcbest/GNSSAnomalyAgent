# EXP02优化后的研究判断

实验：**GNSS-VLM-EXP02-v3，GNSS活动与质量异常分离的时间解码及局部视觉复核实验**。
主方法对应 `anchored_fusion`，数值定位对应 `rf_split_temporal`；
`guided_fusion` 是同一响应直接作为检测输出的对照，`fusion` 是EXP01原方案在新数据上重新执行。
本页基于实际保存的三种子测试结果；详细数字见[三种子结果](../results/exp02-three-seeds/results.md)。

## 已有证据支持什么

三个独立数据种子、合计72个测试站，主方法形变日micro-F1=.6038，
对应数值法=.5412、原融合=.3050、平衡RF=.5234、默认RF=.5716。
主方法减数值法的差值=.0625，种子内成对站点bootstrap的95%区间[.0197,.1278]；
减原融合=.2988，区间[.1801,.4135]。这支持当前仿真条件下的增量。
相对默认RF的差值=.0321，区间[-.0409,.1158]，**不能声称稳定优于所有数值基线**。
这些区间条件于三组已训练模型，不代表所有训练随机性，也不是现场置信保证。

主方法形变事件F1（IoU≥.5）=.4348，数值法=.3509；平衡RF仅=.0201。
时间解码主要改善逐日预测的事件碎片，不保证日F1在每个种子都提高。
主种子平衡RF形变日F1=.4394，时间解码=.4343：这是明确的日指标退化，未删除。
只连接缺测的对照事件F1=.0423，仍低于时间解码=.3333，不能把主要事件收益仅解释成缺测表示。

短窗/邻日特征帮助区分立即回弹和持续跳变，三个种子数值法的阶跃精确日F1=.2941，
高于平衡RF的.1765；主方法为.3333。尖峰主方法=.6486，说明主要质量类型得到实际检测，
但阶跃仍明显薄弱，不能仅因支持输出四种类型就宣称已可靠覆盖所有主要异常。

## 反证与取舍

自由视觉对照 `guided_fusion` 的形变日/事件F1=.6581/.6667，均高于主方法的.6038/.4348。
测试结果没有证明锚定边界优于自由视觉；不能因为开发小批自由视觉失败，就忽略这个反证。
锚定融合在尖峰上高于自由视觉（.6486对.4878），但会拒绝数值漏检的质量点、
保留数值自身错误的活动边界，并降低对长活动的召回。它是明确的任务归属取舍，不是最优方法证明。
主方法与自由视觉的形变日差值区间[-.1576,.0578]，没有确定优势。

主种子局部图消融：anchored_fusion形变日F1=.4547，去局部图=.4602，去显式数值信息=.4410。
**不能据此断言局部图给主方法带来独立收益**。原方案与新方案改变了RF监督候选、
历史拟合参考、邻日数值和局部图等多项输入，必须结合相同RF和信息组消融判断，不能全部归功于视觉。
独立二元RF在验证侧退化、48特征在形变侧退化、两批视觉小批的误报均保留在开发记录。

VisualTime作者严格解析适配在主种子24/24站失败；同响应作者原解析重放仍15/24站失败，
通用日F1=.1734。六路全部成功政策、GNSS图和模型更换属于本项目适配，
不能用这个结果评价原论文，也不能声称完整官方TSAD-Agents复现。

## 后续最值得投入的方向

1. 提升阶跃与混合暂态的边界识别：增加独立训练事件数，评估点/区间任务各自的数据需求，
   优先解决当前每类型每个训练种子仅约8个机制事件的稀少样本问题；不靠测试标签调截点。
2. 检验可修正的数值活动边界：当前锚定只核验形态并保留数值起止，不能修复提前或延长的数值边界。
   下一版应独立研究原始位移中起止证据和不确定性，且在新验证/测试上执行，不能继续调当前已用测试。
3. 引入独立现场NEU及人工活动范围/质量标签，确认正常背景条件和位置差异；当前三种子仅改变随机流，
   没有改变简单白噪声机制，不等于跨分布或现场有效性。

VLM4TS/TAMA已有多尺度复核，VisualTimeAnomaly已有数值协作，本轮不宣称首次组合。
本轮贡献的证据重点是非互斥活动/质量任务、时间解码、任务分工及其真实收益和代价；
阶段分类、物理原因、失稳时间和统一毫米告警阈值均不是本轮验证结论。
