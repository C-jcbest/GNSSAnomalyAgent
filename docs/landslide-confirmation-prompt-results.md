## 下一轮应验证什么

1. **先解决坐标契约可靠性。** 在新协议里统一坐标表达和端点语义，预先固定验证及失败策略；先做不含标签的契约样例检查，再同图比较。必须确认没有改变可见信息或缩窄可输出范围。本轮失败继续保留，不回填。不能用人工裁剪或只重跑错误例代替可靠性改善。
2. **检查分块是否代替了真实边界。** 预先固定块相位／分辨率与自由边界对照，在相同候选上完整运行，报告起止偏好、普通活动FN和弱活动召回，保留全部重复。不根据本批标签选择块起点；先固定可靠坐标契约，再比较观察因素。
3. **单独检验可核查的短原始数值摘要。** 如果纯图像边界仍不可靠，可加入无标签的前中后非重叠观测变化、噪声代理和观测数；不把导数提前响应当活动起点。数值摘要与图像来自同一观测，不能称独立证据。与纯图像受控比较，不同时换图、模型、提示及阈值。
4. **第二层另行诊断。** 固定保存阶段头的本轮没有改善D→S混淆；先做参考活动范围下的诊断，再回到实际预测范围评价端到端效果，不能把第二层置信度用于反向证明平台活动。
5. **最终主比较回到独立资料。** 当前六例、一个弱段和相关AI辅助标签只用于开发。补未查看的弱运动、平台、漂移、新组合及合理负例；观测参考与待测预测隔离，独立完整记录分组。最终方法与阈值冻结后才进行强数值、PELT、XGBoost及视觉近邻适配的统一对比。初稿可先整理定义、实现、开发消融与错误传播，优势主张等待正式证据。

这些是后续验证优先级，本轮没有追加模型调用、改标签、重训阶段头或执行新的自由边界／数字摘要实验。
