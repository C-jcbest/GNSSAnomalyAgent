# EXP38：正常参考与位移残差双视图识别（NRV-GNSS）

登记于2026-10-17，在任何EXP38预测和评分前。用户授权设计并执行实验；不是作者方法复现。
稳定版本为b2a39b91；标签backup/exp37-before-exp38-20261017；完整忽略材料沿用已核验EXP36/37外部ZIP。

## 假设与方法

EXP37暂态Aff较高，但正常、永久阶跃、持续形变站误报很多，且形变没有视觉参与。
假设：同站正常参考、按分量共享纵轴、原始位移与正常历史残差双视图，有助于区分噪声、
永久平台、暂态与持续活动。此为待验证假设，不是预先成立的结果。
借鉴TAMA同通道正常参考和VisualTimeAnomaly类型分工，具体来源及读取边界另记。

正常历史[0,364]上拟合既有numerical_evidence线性、年周期模型，复用其MAD，不重新训练。
显示[180,364]正常参考与[365,729]目标：原始位移/本站MAD及残差/本站MAD，
每分量同一表示的参考和目标共享纵轴；3日中位线仅供阅读，原始缺测保留。
一步视觉输出暂态、形变活动范围，不输出内部阶段、不访问数值候选或真值。
形变必须先由原始位移证实连续运动，残差或导数本身不确立活动；永久平台不延伸为活动。

完整系统保留冻结近邻的单点/阶跃日事件；两种范围分别采用数值原事件，加上与该类
数值范围不相交的视觉confirmed事件；相交视觉事件不替换原数值事件。
这是显式补漏规则，不按真值选择范围。纯视觉另行评分。失败请求输出空视觉事件，
完整系统因上述固定组合规则保留数值结果；失败不得重试或从统计移除。

## 准入与停止

pilot对暂态与形变逐类检查，不跨类型平均：至少一类完整系统Aff较数值提高>=.01，
且该类较文字提高>=.01、该类实际TP增加；另一类Aff下降不超过.005；
暂态阴性站误报须比旧OWV减少>=25%。纯视觉图文结果及其余消融全部披露。
若达标，冻结源码后对54新开发确认，仍执行5模式；confirmation同样检查且至少2种子
改善类Aff较数值方向为正。达标才登记720测试的运行；否则取消集成、不请求测试。
不因单独范围日F1下降判失败，但必须报告每类日F1与FP。
