## 假设与数据

EXP30的图像粗筛命中优于文字，但各区域独立局部判断切割上下文，且全局/局部结论矛盾。
新方法将相接/重叠裁剪合并，以一站一次终轮联合读取全局和全部合并局部。
检验是否增加强数值以外真实TP，以及局部图在保留全局时的独立作用。
文献流程启发与作者方法复现分开，不给未运行的作者框架填成绩。

数据使用EXP30已生成、尚未预测的288开发站：三种子各站内序号24—119。
先每种子24—35，共36开发pilot（六场景各6站），通过门槛后再跑其余252站。
旧72开发站只用于设计诊断，不进本轮分数。EXP30全部360test尚未预测，只有本轮完整开发
通过研究变体门槛才启用；test同样先36再324，不在test修改方法。
原模拟、730日/365日历史、缺测与EXP28独立96站数值模型不变，不新增训练和物理阈值。

## 冻结流程与对照

粗筛逐字复用EXP30-S1原提示、三窗与模型；每站最多两区域。每区域两侧各扩35日，
按原始半开索引合并相接或重叠上下文，最多两张局部图。该合并规则不读真值。
终轮一次请求查看该站所有上下文；任意日期重定界，保留confirmed/uncertain，
不加入自动语义否决、端点吸附、按真值裁剪或幅值门槛。
全局图与局部图分别明确标记图角色和原始索引；同一观测重复出现不是新证据。
提示先要求确定受影响分量上的起点、持续内部和返回，再输出完整暂态；
不要求绝对外侧水平相同，不将平滑位移或停止后的平台误判暂态。

| 方法键 | 终轮信息及对照目的 |
|---|---|
| `jcv_image`（主方法） | 图像粗筛＋全局图＋全部合并局部图＋数值软证据，一站一次终轮 |
| `jcv_local_only` | 相同首轮、合并局部和提示，删除全局图 |
| `jcv_global_only` | 相同首轮、合并区域元信息和提示，只给全局图 |
| `jcv_text_final` | 相同图像首轮、相同原始全局/局部观测，换成文字；重复索引只序列化一次 |
| `jcv_text_pipeline` | 文字粗筛及自己的合并上下文，终轮文字；完整去图 |
| `jcv_image_no_numeric` | 相同图像输入，删除数值阶跃软证据 |
| 上述各键＋`_pure` | 仅对应confirmed暂态，不加入近邻；四类F1不用于与完整系统评优 |
| `air_image`、`air_global`及其`_pure` | EXP30-S1旧逐区域局部/全局流程，在本批同站重跑；共用相同首轮响应 |
| `vrc_image`、`vrc_text` | EXP29旧单轮自主范围互补，在本批同站重跑 |
| `vector_nearest`与六原数值方法 | 原冻结数值方法，无本轮重训或阈值扫描 |

主终轮沿用EXP30 LocalDecision结构。只允许在合并上下文之内输出区间；
全局图作为辅助，不允许跨未包含的间隙任意补段。数值软证据同为各上下文内的阶跃日期及向量。
confirmed与近邻仍add-only，重叠暂态不覆盖；pure与贡献审计用于识别融合遮蔽。
所有对照的图像数量、token和调用预算据实报告，不声称完全等成本。
模型`qwen3-vl-plus`、temperature0、enable_thinking=False，原接口不变；并发3，120秒，无自动重试。
失败保留并按既定近邻回退，不把成功解析当识别正确。登记文件和已有响应不覆盖。

## 分阶段标准

36开发pilot扩量条件：主方法相对近邻或原VRC至少1站新增真实TP，
且相对近邻暂态日F1下降不超过0.03。失败则停当前主方法，不事后换对照当主方法。

完整288开发的**范围研究变体**门槛：主方法相对近邻、全文字的暂态Aff-F1均至少+0.01；
相对近邻有实际新增TP；至少2/3种子Aff高于近邻。若通过，可进入新test独立确认，
即使日级有所取舍也完整披露，符合以范围识别为主要研究目标的定位。
**替换稳定系统**另要求暂态日F1相对近邻下降不超过0.01、四类日F1下降不超过0.005。
两类决定分列；范围研究通过不能写成全面优于数值。test仍使用同样两类标准，不另选阈值。

评价全量保留：暂态与形变Affiliation P/R/F1、日P/R/F1及TP/FP/FN、四类日F1、
范围联合、一般异常、正常/无暂态站误报、种子/场景分层、描述性配对bootstrap，均无point adjustment。
过程审计区分粗筛命中、原裁剪/合并上下文完整性、confirmed/uncertain、pure识别、
被近邻覆盖、最终新增TP/FP及仅Aff上升无真实TP。不把输入可见性当最终召回。
