# EXP29-S1：视觉范围引导的有序边界联合验证

2026-10-15，在 EXP29 的 360 开发评分与逐站诊断之后、S1 工具结果产生之前登记。属于针对已观察开发失败的适配实验，不把开发成绩说成独立验证。EXP29 冻结实现、主方法失败结论和原始结果保持不变。

依据：原工具独立选两端，71 个视觉建议中有 42 个边界相同或倒序；直接视觉互补比近邻多 28 TP 日和 88 FP 日，而经验证互补无新增范围。有真实补回，也有误报，不用 Aff 单项掩盖代价。

唯一核心改动：在视觉给定起点/返回各 ±14 日内联合枚举原始观测可支持的有序双边界。对所有候选使用同一个固定原始观测上下文（两个搜索窗口并集再各加30日），选脉冲模型信息准则最优的有序边界。其两侧各须至少5个有效观测，已有数值 spike 日不参加拟合；三模型均保留连续折线和其他数值阶跃 nuisance。再比较同边界的连续、脉冲、独立双阶跃，只有脉冲两项均胜才接受。边界由成对证据联合支持，不再要求每个边界独立通过单阶跃筛选。无新增物理阈值、没有依据真值调整时间窗或惩罚。

复用原开发视觉请求与响应，只有工具改变，不再重复抽样。主 `joint_vl_image` 为验证后近邻 add-only 互补；匹配 `joint_vl_text`；`joint_numeric_all_pairs` 将全部原 PELT 阶跃组合送入完全相同的联合工具；均与原近邻、EXP29 完整验证和去验证结果分列。候选互补按输出顺序接受互不重叠范围，视觉顺序来自自身回答，数值控制按日期序。全部报告，不能看到分数后换主方法。

开发升级门槛：主相对原近邻及匹配文字的暂态 Aff-F1 均≥+0.02，暂态日 F1 均不下降超过0.01；至少有一个站真实 TP 增加，三个种子至少两个 Aff 增量为正。否则取消升级并保留负结果。若全部达到，另登记独立测试推理与 S1 工具阶段；测试沿用尚未推理/评分的360站，模型和提示不改。不能用“去验证”开发较好变体事后替代预选主方法。数值全组合若更好，也须如实报告，不宣称视觉独占收益。

以相同多指标和2,000次配对 bootstrap 报告，不调整生成机制，不输出形变阶段。代码、协议、复用输入哈希在 S1 registration 中冻结；无新的开发模型费用。
