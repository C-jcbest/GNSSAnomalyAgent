# 原生缺测日比较 v1

确定于2026-09-23。本轮按用户要求不注入额外缺测，只保留`daily15-v2`来源窗已有的缺口；不插值、不删日。它是已查看过上一轮测试结果后的**事后敏感性实验**，不是新的独立盲测或对检测方法的重新校准。上一轮144例及运行结果保留不变。

输入仍为北京时间每日15:00、180日日网格和固定来源组。沿用[日同期比较协议](daily-comparison-protocol.md)的种子20260923、五种情景注入加无新增注入、注入幅度和标签定义。每来源每情景只保留`native`状态：六个来源窗共36例，开发12、验证6、测试18。构建器保留原协议的随机种子派生及case ID，因此本轮输入文件应与上一轮`native`子集逐字节一致，逐案例标签对象相同；只有manifest的案例范围和协议名改变。运行前按文件哈希核对，禁止依据测试分数筛例。原生缺测仍可能存在，不能称为无缺测数据。

复用`configs/daily-comparison-v1.json`中全部检测器、视觉提示和模型参数；仍是Hampel、CUSUM、Isolation Forest、独立纯视觉、同期视觉∪Hampel五方法。开发、验证各完整运行；验证全部合法后仅冻结配置身份，不按注入标签调阈值；测试用同一冻结配置完整运行。视觉需重新调用，API响应随机性或时间变化可使本轮与旧`native`子集不同；比较缺测影响时应另列旧运行的同案例配对结果，不把两轮模型差异归因于缺测。

主指标仍为`observed-cells-v1.1`的日×分量微平均P/R/F1，未覆盖阳性计FN；并列类型、完成率、首次合法率、报告负担、覆盖和成本。原生变化未标注，标签外报告不是已确认现场误报。36例只来自六个相关来源窗，测试18例仍是同一个来源组的三个窗，不能作为18个独立场地或现场准确率证据。该轮只检验去除**额外缺测派生**后的固定方法表现，不证明缺测是旧低分的唯一原因。
