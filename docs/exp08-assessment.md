# EXP08结论：独立尖峰学习未推广，保留SDR-VLM

2026-10-14。实验全名为**GNSS独立尖峰先验与视觉位移分解融合正式复核实验**，
代号GNSS-VLM-EXP08，候选名ISP-VLM，对应报告`binary_rf_default_repair`。
当前保留方法仍为EXP06 SDR-VLM（`pair_focus_repair`），生产源码未改变。

## 开发线索与正式决定

首开发2026101410：原数值F1=0.699758，balanced独立RF=0.621550，
balanced ExtraTrees=0.710174，两预设主候选取消。默认RF消融=0.738957；
由消融形成新假设，在另一个开发批生成前登记唯一默认RF候选，不能回写成原冻结候选。
第二开发2026101411：原完整方法0.853775，候选0.879285（+0.025510），通过开发条件。
该批视觉没有改变最终数值事件，全部增量属于数值组件。

随后冻结两个全新正式种子2026101412/2026101413，各96训练站、24测试站，
共48同组测试站。所有站均纳入，不按测试数值成绩筛选视觉方案。
原48维特征、默认二分类RF，只显式固定random_state，不扫概率阈值或类别权重。
训练仅使用训练站可观测分析日，插补来自训练集；其余分段、图、提示、模型及修复同原方案。

这批原版0.7724与EXP06/07约0.865来自不同站，不能把跨批下降当成算法被修改，
也不能只保留较好批次。新批成绩说明已有方法对模拟场景组成仍有波动。

## 变化来源：数值收益接近零，视觉存在响应波动

正式原/新尖峰模型四类尖峰F1相同，为0.6364；数值主指标仅增加0.000089。
1412仅s0067/s0071事件改变，1413所有站的数值事件完全相同。
5组原/候选视觉请求逐字节相同，但1413/s0059及s0065的最终修复不同。
因此候选视觉下降部分是**相同输入的服务响应波动**，不能解释为独立RF导致语义退化。
temperature=0也不能保证服务输出完全确定。这不改变本轮不升级的决定：
没有证据证明新增分类器带来可推广的明显收益。

原视觉相对同站原数值主指标增加0.033679，但1412视觉略低于数值、1413高于数值。
应报告合并与分批表现，不能宣称视觉每批必然改善。
下一项可检验假设是歧义返回对的重复判断与多数修复，而不是继续堆叠尖峰权重或提示。
