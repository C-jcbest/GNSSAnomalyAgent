# EXP24：SDR-GR 缺测边界恢复

2026-10-15，EXP23新48验证站已评分后提出的机制修正，明确为事后开发分析，
不是新的未见测试。复用EXP23全部已保存响应，0新增模型调用。

## 问题依据

现有`segment_proposals`在PELT边界前一日缺测时会跳过jump候选，
这是一项明确的观测支持约束。EXP23恢复所有被舍弃边界后，原1406/s0063的
缺测后平台被正确恢复，但新1516中两个连续观测的平滑边界被误接为暂态。
为此只在**补充恢复路径**允许缺测后首个已观测边界；原Flash全部识别范围仍保留。
该限制不规定任何位移或速率阈值，也不依据真值距离选站/调参。

## 方法与复用边界

对EXP23同一图、同一提示的原始pair_ids增加确定性结构约束：
start本日有观测且start-1日无观测才允许新增暂态。其余选择被拒绝，不改已有Flash事件。
日期仍为首个已观测活动平台日，不推断缺测内精确跳变日期。缺测mask不变。
这是一项响应后的约束，**没有把修改后候选/提示的模型响应当作实测结果**。
所有原响应（包括无图幻觉观察）保留。数值恢复和全接纳候选也做同样约束。

报告原48站与新1516验证48站，各自独立表格，不把两者混称新的96站测试。
主要指标继续Affiliation P/R/F1，附日F1、覆盖、误报及其他范围指标。
原始未加约束的EXP23结果不覆盖；不以IoU决定是否保留。

若旧站增益得以保留、新站不再新增误报，保留为**针对缺测边界的补充候选**。
该判断只支持特殊场景与机制合理性；还需后续独立缺测边界实例验证泛化，
不能宣称优于所有数值方案。已授权原SDR-Flash-Aff始终保留。
