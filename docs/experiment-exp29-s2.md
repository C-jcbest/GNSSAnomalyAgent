# EXP29-S2：视觉定位—数值取证—局部视觉终审

2026-10-15，S1 开发结果已知、S2 新模型请求之前登记。S1 仅增加1个TP日及22个FP日，Aff增加0.0095，未采纳。本补充为开发驱动的新方案，不能替换原 EXP29/S1 预选主方法的失败结论。

参考已实际阅读的 AnomaMind 的粗到细定位、DAST 的 VLM→分析→VLM 核验，以及 TimeRLM 的代码/视觉交替；仅作 GNSS 适配，不称作者原法复现。

固定三步：复用 EXP29 的首轮自主视觉/文字定位；调用已冻结 S1 联合边界工具，连同其未通过的信息准则结果一并作为证据；同 qwen3-vl-plus 看局部原图、原候选扣除图及数值证据，选择完整的暂态解释或保留原数值结果。数值否决不再具有最终决定权。备选范围包括自主视觉原日期、联合工具最优日期，以及落在其±30日上下文内的原数值近邻范围，完全相同范围去重。模型只能选备选ID，不得读取真值或强制数量。

终审采用原图及各候选的仅起点局部7日中位差扣除图；返回端不参与offset估计。图片和文字终审提供相同原始点、历史残差和offset；数值BIC型分数对两者相同。反事实不作为真值。改变原配对时，恢复被取消配对两端的已有PELT step，随后仅去除新选范围精确端点上的step；其他活动和尖峰不改，不推断内部阶段。模型明确选择 replace_ranges 且空列表时允许清除当前复核集合；keep_numeric或调用失败保留基底。未提出范围的站不请求终审。

三条完整路径：主 `vnv_image` 为图像定位→联合数值取证→图像终审；`vnv_text_final` 复用同一图像首轮，终审仅用同信息文字，隔离终审图像贡献；`vnv_text_pipeline` 使用文字首轮、自己的联合工具与文字终审，隔离整条流程的图像作用。无视觉近邻、数值全组合、原硬否决、去否决及S1均分列。首60站（与EXP29同一技术pilot）后再扩大；所有开发首轮响应复用，终审单次，无隐式重试、并发3、120秒。

升级门槛：360开发主相对近邻及全文字路径暂态Aff均≥+0.02，日F1均不下降超过0.01；至少1站真实TP增加，至少2/3种子相对近邻Aff为正。终审的图文差异另报，若无增量不宣称第二轮图像独立有效。达标才另外登记360站未见测试；失败则保留探索变体、取消集成，不打开测试寻优。

主指标、正常站误报、全部类别指标和配对bootstrap沿用EXP29。再次强调：仅Aff增加且TP不变的站不能写成真实检出，不能将某个补充变体的开发最佳值冒充原主方法成功。
