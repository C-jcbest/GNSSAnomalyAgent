弱子集在新评分前固定为观测复核中的0051 `[220,390)`、0054 `[470,650)`、0057 `[225,420)`、0060 `[480,640)`，有效观测分别166/176/194/157日，合计693日。它不是所有可能弱运动的自动穷尽集合。事件复用一对一缺测掩码IoU .3/.5和确认内部的episode ID；不把缺测切成不同参考事件。边界MAE相对保守确认内部，仅在成功匹配事件上计算，不能称物理起止误差。
