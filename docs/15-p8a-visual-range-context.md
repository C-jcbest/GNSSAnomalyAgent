# P8a：纯视觉 Range 全局与局部上下文对照

> 2026-09-28 · 原 60 例对照及用户指定的完整 Pilot300 扩展均已完成。原继续 Gate 未通过；全集开发结果见第 9 节。全部请求最大回复 8192 tokens，不是独立测试。

## 1. 研究问题与依据

当前视觉 semantic-v2 在完整 Pilot300 的正轴逐日 IoU 为 0.5400，但存在范围误报、边界偏差和结构失败。P7b 仅保留/删除的复核损失了 419 个正确 Range 日期，未通过继续 Gate。本实验检验：允许双向边界修正后，补充局部原始曲线能否改善范围定位，同时保留召回。

[TSAD-Agents（WWW 2026）](https://arxiv.org/html/2502.17812v2)提供任务分工和检查修正的参考；[VLM4TS（AAAI 2026）](https://ojs.aaai.org/index.php/AAAI/article/view/39319)结合局部候选与全局上下文，并做组件消融。VLM4TS 的多尺度模块是视觉编码器，不是本实验的 Qwen 局部图提示；本实验是受这些思路启发的新对照，不是官方复现。

## 2. 数据与三条件

直接复用 P7b 已冻结的输入包及选择身份：6 Normal、30 Single、24 Multi，总计 60。只按原元数据分层选择，不重新挑案例。推理进程只读 input.json、原始 PNG 和只含身份/哈希的 manifest；不读取同目录的归档数值/视觉预测，也不读取 selection.json 或 truth.json。

| 条件 | 输入与处理 | 目的 |
| --- | --- | --- |
| V0 | 原 semantic-v2 Range 提示与原始三联图，回复上限改为 8192 | 同期初轮视觉基准 |
| V1 | 同一次 V0 的完整预测 + 原始三联图 + 修订提示 | 复核调用的效果 |
| V2 | 同一次 V0 的完整预测 + 原始三联图 + 局部图 + 与 V1 完全相同的修订提示 | 增加局部视觉证据的效果 |

V1/V2 都可保留、删除、延长、缩短、拆分、补充区间；返回完整结果，不返回修改指令。两者都检查概览中的遗漏，初轮空结果也复核。没有数值候选、数值摘要、异常类型、注入参数或真值进入请求。模型不要求解释成因。

## 3. 局部图规则

每轴固定四个 inclusive 窗口：`[0,119]`、`[90,209]`、`[180,299]`、`[245,364]`。这些宽度是工程选择，尚无最优性证据。

- 初轮非空时，选择与该轴任一预测区间前后扩展 30 日相交的窗口。所有候选共同选择，不按置信度筛除或截断候选。
- 初轮全空时，显示三轴全部 12 个窗口，用于完整再检查。
- 未被初轮选中的轴仍在全局概览中；因此局部证据对遗漏的帮助有局限，需要明确披露。
- 每张局部图最多 3 个面板，每面板单轴，1800×1200 PNG；最多 4 张局部图加 1 张全局图。保留全局日索引，局部刻度每 10 日，线色/线宽与原图一致。
- 局部纵轴范围按该轴全年度原始观测计算，与原 renderer-v1 的范围一致。只放大时间轴，不增加曲线数值、平滑或真值标记。

V2 比 V1 增加图像输入，因而它检验的是“补充局部视图这一整套输入策略”，不能声称隔离了图像数量、局部刻度密度和时间放大各自的贡献。实际 tokens 与成本单列。

## 4. 参数、预算与执行契约

`configs/p8a-range-context.json` 是唯一请求配置。模型 `qwen3.8-flash`、temperature=0、enable_thinking=false、max_tokens=8192、JSON Object、单图 max_pixels=2160000、超时 120 秒、并发 4；每逻辑请求一次尝试，无补救。保留 P4 既有 schema，包括 inclusive 区间、允许相同端点的历史规则，不修改评价器。

两例 Pilot 外工程输入（原工程集合第 1、4 例）分别跑三条件，最多 6 次接口预检。只检查模型身份、正常结束、JSON 和多图接收，不按检测准确率调参。正式最多 60 + 60 + 60 = 180 次请求，总上限 186。V0 失败则 V1/V2 都以依赖失败保留在分母，不发请求；复核失败不回退 V0。V1/V2 每例各一次请求，不循环复核。

先完成所有 V0，再执行交错排列的 V1/V2；按 case 位置交替先后顺序，减轻调用时间偏差，但不声称完全消除服务端漂移或随机性。共享 V0 的实际成本只计一次；计算单独部署 V1/V2 的端到端成本时，每种都应加上 V0 成本。

模型回复通过既有严格 N/E/U 本地校验，额外键、重复键、数组顶层、越界或逆序区间失败；保留原 P6 支持完整 JSON 代码围栏的兼容规则。JSON Object 不等于服务端强制 schema，本实验不混入新的 schema 条件。

发送前以排他创建写入持久账本，不写凭据；完成后原子保存回复和预测。中断后未知尝试标记失败，绝不自动重发。进程锁防止并发续跑；若进程被强制终止，先核对锁中 PID 已退出，再移除该运行目录内的锁后续跑。已完成运行拒绝覆盖。

## 5. 评价与预登记 Gate

推理完成后，独立评价程序才读取 canonical truth。全部 60 例进入分母，仍使用 [P4](05-p4-pilot-evaluator.md) 与 [多版本指标](09-versioned-comparison.md)：

- 主指标：Range 正 case×axis Affiliation P/R/F1。
- 补充：正轴逐日 IoU、全轴逐日 micro P/R/F1、成功负轴 FAR、Normal 诊断、执行成功率。
- V0→V1、V0→V2、V1→V2 的唯一日期集合变化：新增/删除正确日、新增/删除错误日。只在对应两条件都成功时解释为修订行为，失败变化另外列出。
- 按 Normal、五种 Single、六种 Multi 分组；分组仅事后评价，不进入推理。
- Theil–Sen 的同一 60 例归档结果仅作数值参考，不与历史 300 例混合排名。

继续到完整 Pilot 的严格开发 Gate 预先定义为：V2 相对 V0 的 Affiliation F1 与 IoU 均提高、Affiliation recall 不下降、负轴 FAR 不升高、成功率不下降，且 V2 相对 V1 的 IoU 提高。否则停止扩展，报告所有权衡，不按某个补充指标临时改 Gate。该规则是本项目开发筛选规则，不是通用统计显著性标准；60 例不足以支持泛化结论。

### 7.1 修订收益与代价

以下只在每对条件都成功的案例上计算唯一日期集合，避免重叠区间重复计数；执行失败引起的损失不混作主动修订。

| 修改 | 配对成功案例 | 新增正确日 | 删除正确日 | 新增错误日 | 删除错误日 |
| --- | ---: | ---: | ---: | ---: | ---: |
| V0→V1 | 55 | 10 | 85 | 140 | 465 |
| V0→V2 | 55 | 50 | 68 | 408 | 1640 |
| V1→V2 | 54 | 126 | 69 | 456 | 1363 |

V2 成功修订净减少 1232 个错误日，同时净减少 18 个正确日；另一个 Range 阳性案例的复核结构失败使其 V0 已有 45 个正确日归零。两部分合计解释全分母 TP 从 1581 变为 1518，不能把全部差额都归因于边界修订。

六个 Normal 案例在三条件下都成功，均有 13/18 轴报警（72.22%），对应预测日期为 2337、2452、1907。局部图减少了一部分报警范围，但没有减少这些 Normal 报警轴。数值在同一六例无报警；它们属于曾用于数值阈值校准的开发 Normal，不能解释为独立误报保证。

### 7.2 分组和共同成功诊断

Single Transient Shift 的 IoU 从 0.7241 提高到 0.8955（各六例成功）；Single Slow Trend 从 0.6299 到 0.6474（各五例成功）。Complex Multiaxis 从 0.3667 到 0.5794（各四例成功）。Single Acceleration 从 0.6123 降到 0.5609，同时成功案例从六例减为五例，不能把下降全解释为几何定位。Longterm with Local 从 0.3554 降到 0.2995，说明局部图的收益并不覆盖所有组合。

排除所有条件任一失败后，共同成功仅 54 例。V0/V1/V2 的 Affiliation F1 为 0.8289/0.8017/0.8268，IoU 为 0.5543/0.5305/0.6469。该事后诊断支持“部分范围重叠改善”的解释，但主表仍为全部 60 例。不能用共同成功筛选提高正式成绩。

这些小分组已经是开发分析，不能转为运行时按真值类型路由，不能据此宣称局部图对某种真实异常稳定有效。

## 8. 结构可靠性、成本和验收

正式 V0 60 次请求有 3 个顶层数组和 1 个缺少轴键的对象，均正常 `stop`；V1/V2 各 56 次请求，各有 1 个顶层数组。剩余 4 个依赖失败使两组复核各保留 60 行、成功 55 行。没有网络失败或补救调用。所有 172 个正式回复都可解析为 JSON 语法，其中 6 个不满足 N/E/U 输出契约。

三组记录到的最大 completion_tokens 都只有 55，且结构错误不是截断结束。本实验因此没有证据支持“继续增大 token 上限可以解决当前结构失败”。JSON Object 请求未保证顶层对象或字段契约；后续若研究服务端 schema，需独立工程验证与版本登记，不修补本轮输出。
