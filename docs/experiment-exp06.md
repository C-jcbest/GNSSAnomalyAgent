## 方法参数与原码身份

1. 正常前缀线性＋年周期背景，各轴正常MAD归一化。尖峰采用训练RF的48维形态特征默认票决，
   从分段拟合和辅助轨迹拟合中排除RF尖峰。后续异常可共存，不用场景真值决定分工。
2. **作者库原算法**：`ruptures==1.1.10` PELT，源码不改；BSD许可与安装源文件哈希已保存。
   **GNSS适配**：三响应线性最小二乘代价、原始观测时间，缺测跳过且不重编号；
   min_size=7有效样本、jump=1、惩罚6log(3n)、保留正常前缀最后90日。
   库默认min_size=2、jump=5，且必须提供pen等停止条件，本配置不是作者默认。
3. 变点在±3日细化，在左右最多21日且限于相邻分段的原始位移中比较线性、阶跃、
   连续折线、阶跃＋折线。准则为归一化RSS+3p log(3n)，两侧至少5有效点，跃迁相邻日均观测。
4. 背景＋独立水平跳变之外比较一个有界位移轨迹：线性、smoothstep两种通用形状；
   7日粗网格、±7日细化，最少15日，最多1个活动区间；惩罚5log(3n)+2log2。
   无真实位移阶段/速度模板输入。停止后平台的水平项不作为继续活动。该模型为项目代码，非CPOP复现。
5. 扣除估计活动轨迹后，对相距≤120日的跳变比较独立跳变与相反返回的脉冲；
   前后30日上下文、连续折线 nuisance 项。数值配对不改；未选中配对作为视觉待辨假设。
6. 仅有备选返回对时请求视觉。提供全局原始NEU、候选局部的原始NEU与辅助残差并排图。
   辅助图是正常历史残差上联合拟合21日固定结点连续线性样条与独立跳变后，只扣连续项。
   数值预测类别不放入视觉文字；提供可能配对日期和原始缺测，专门辨别永久阶跃/暂态。
7. 保留所有数值存在与边界决定。视觉明确确认未选中的返回对、两边界各在±7日以内，
   且两边都仍对应数值阶跃，才用一个暂态替换这两个阶跃。其他类别不因视觉遗漏/不确定而删除。
8. **失败政策**：主方法的数值路径独立；视觉失败仅无修复，保留数值结果，
   `visual_dependency_status`明确失败。无歧义站为not_requested。父模型失败、实际请求单列。
   纯视觉和旧完整融合依赖视觉，失败按零检测；不混写全部方法失败均零。
9. 所有统计惩罚、时间尺度与单活动限制披露；不设跨站点统一毫米/毫米每日告警阈值，
   也不写“完全无参数”。图像、CSV及评价共用最终标签与原始缺测掩码。

## 同组对照与消融

| 结果行 | 身份/用途 |
|---|---|
| random_forest、extra_trees、isolation_forest | sklearn原库默认判决＋共用GNSS输入适配；IF仅通用异常 |
| rf_balanced | 特别标注class_weight=balanced，不能混为默认RF |
| rf_split_temporal | 项目既有形态分工与训练侧解码 |
| visual_only | 同模型纯视觉完整检测 |
| guided_fusion、morphology_fusion、localized_fusion | 旧完整图同站重跑，旧规则保持 |
| segment_numeric | 新结构分解、无视觉的核心消融 |
| pair_focus_repair | 冻结主方法SDR-VLM，原始图＋慢轨迹扣除图 |
| pair_raw_repair | 只去正常历史背景、不去额外慢运动的图像消融；同候选、同角色提示、同修复规则 |
| pair_focus、pair_raw | 中间配对审阅输出，只承担阶跃/暂态子任务，不按完整四类检测排名 |

另执行作者PELT API默认构造(l2)及README示例(rbf)，原示例pen=10（明确非自动GNSS默认），
不调惩罚。共用站点残差/缺测时间映射输入，报告非尖峰形态变点边缘的严格/±3日F1，
与GNSS结构适配的边缘结果分列。原库无四类标签/活动日掩码，**不伪造其四类日F1**。
