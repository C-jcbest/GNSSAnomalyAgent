# EXP37图文接口成功性敏感性分析

2026-10-17，54开发确认结束后、360test推理初期且尚未评分时记录。
本项对54站为事后诊断，对360站为评分前规定的附加分析；均不参与原准入。

主表始终保留所有站与所有失败。另取图像和文字响应均成功的同站子集，
原样复用各自已保存预测及评分，比较独立视觉/文字与融合/近邻的暂态Aff、
辅助日F1和真实TP/FP变化；同时列两者成功、仅图成功、仅文成功、两者失败站数。
不补调API，不排除定位错误，不因子集成绩更好替换全站结果。

此项检查“图文差异是否主要由请求失败造成”，不消除子集选择偏差，
也不将成功站子集冒称新的独立测试。输出新子目录，原summary/预测保持不变。
