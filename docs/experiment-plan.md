# 当前实验方案：每日15点异常定位

更新：2026-09-23。研究任务仅为在固定北京时间每日15:00的GNSS三轴观测中定位异常点及区间，输出N/E/U及含端点的起止索引/日期。180日主窗，原值、零值和内部缺测保留；不插值、不压缩日期、不做小时检测、日聚合或时刻优化。15点取点不等于GNSS原始日解，也不宣称最优。详见[日数据契约](daily15-data.md)。

## 方法与数据

使用冻结本地`daily15-v2`的六个候选窗，不回源。沿用平台组划分：开发两窗同组、验证一窗、测试三窗同组，所有派生继承来源组，不跨组。原[日同期比较协议](daily-comparison-protocol.md)构建144例注入/缺测派生；后续[原生缺测敏感性实验](daily-native-only-protocol.md)仅保留其中36个`native`案例，不增加缺测。“未注入”仅表示没有新增干预，不证明原生背景正常。SCWM-04已用于开发辅助，其月级变化线索不转逐日真值或独立测试。

对比三种固定数值方法（Hampel、CUSUM、Isolation Forest）、无数值先验的纯视觉，以及复用同例纯视觉响应与Hampel结果的固定并集`daily_union`。数值可检局部或长期，视觉也可检多种形态，不预设能力优劣；组合不要求双路共同确认，按日期×分量去重，保留原分支轨迹，失败不当作空预测。运行时不读取注入类型、测试标签或事后语义，不推断设备故障、真实形变或滑坡成因。旧数值候选→视觉重判的`fixed`与本组合不同，不进入本轮排名。`reference_trend`和Agent均不进入本轮五方法比较。

## 评价与边界

主评分沿用[observed-cells-v1.1](metrics-criteria.md)：只按实际观测日×分量汇总TP/FP/FN和P/R/F1，不用point adjustment；未覆盖阳性计FN。并列注入类型、缺测、无新增注入窗报告量、完成率、首尝试合法率、模型请求、耗时和未知成本。无注入目标时F1为N/A；掩码外预测不是现场确认误报。因测试只来自单一来源组，不能把72个相关派生案例或模型单次输出当独立场地证据。

配置在运行前固定；开发/验证按完整案例运行，验证全部完成后不凭弱标签调阈值地冻结配置，测试按冻结配置运行。原生缺测实验是首次测试已揭示低分之后的事后分析，不再称独立未见测试。各轮结果和限制见[项目状态](project-status.md)。本轮只论受控注入定位和报告负担；如需估计现场准确率，先另行取得独立可信标签与共同未知范围评分协议。是否设计轻量Agent须基于新的独立证据，不预设其优于任一单方法或固定并集。
