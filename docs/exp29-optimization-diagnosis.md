# EXP29后续判断：方向未被否定，当前实现尚有未解决的瓶颈

日期：2026-10-15。针对“是否方案没有优化到位”的补充分析。仅复查360开发站、已保存输入与响应，不新增模型调用，不改变任何预测，不重新利用独立test寻优。可复算入口为 `scripts/audit_exp29_optimization.py`，输出为 [audit.json](../results/exp29-optimization-audit-v1/audit.json)。本文件是事后机制诊断与下一轮设计，不能作为新方法的效果证据。

## 结论的边界

**存在明确的实现瓶颈，当前证据不足以认定视觉先行或多轮视觉没有优化空间。** EXP29否定的是所登记实现达到综合采纳条件，尤其S2的固定候选终审流程；它没有充分检验“模型先粗定位、主动请求局部图、再重新提出边界”的自适应流程。VRC的独立Aff收益已经说明图像具有部分互补信息，纯视觉的低分和融合后的局部收益也提示融合掩盖了首轮能力不足。

不能反过来保证继续优化必然超过近邻。本轮已经有720站证据，不能只因结果不好就归咎于提示；需要让具体改动在匹配对照中验证。

首轮图像的具体漏提案例是v0003：真暂态[562,582]，请求成功但建议为空。保存的[输入图](D:/CodeWorkSpace/AgentWorkspace/GNSSAnomalyAgent-sim/artifacts/exp29/validation-visual-v1/inputs/v0003/scan.png)右列保留了三轴同步偏移及返回，并非数据没有进入图像。这是可读信息未转化为检测的案例，仍不能只凭人看得清楚断言换提示就能解决。

43条重叠建议中的v0095原视觉[504,517]命中11个真异常日，其中5日不在原近邻范围内；融合因日历范围重叠而跳过。该例说明规则确实限制了视觉修补权限，不代表把重叠全部合并就会提高总体指标。

短范围不能简单按固定长度删除：7个未被近邻阻挡的单日建议总共带来1个真异常日和6个误报日，既不足以解释全部误报，也会丢掉实际命中。应先查清模型在报边缘还是报完整平台，而不是事后加持续日数门槛。

## 与已有文献流程的差距

AnomaMind作者Locator代码明确把首轮定义为coarse candidate ranges，要求视觉概述和逐区间理由，后续交给工具处理；本项目虽然给了相似方向，但把单轮直接输出的起止当作最终暂态日期，且未得到有效观察说明。作者代码允许reference strip，但该能力不是本轮实际执行版本的效果保证，不能说加入示例一定有效。

TimeRLM的代码查询与look绘图交替，以及DAST的粗筛与高分辨率核验，是研究自适应取证的依据。本项目S2的所有图和候选均预先生成，模型没有决定“下一步看哪里、需要什么证据”的权限。因此S2负结果不能泛化为这些完整作者框架无效，也不能直接归因为多轮机制本身。原文版本、作者源码读取范围和任务差异见[文献笔记](exp29-reading-notes.md)。

当前1800×1080是文件尺寸，不等于模型编码后的有效尺寸。保存的请求未指定像素预算，也没有模型最终视觉token网格/内部缩放尺寸证据；不能将缩图当作已证实根因。过去EXP17—19已有分辨率与流程负结果，不优先重复单纯增大像素。

## 下一轮的最小可判别实验

优先验证“**视觉粗筛→局部放大重定界→数值取证与受限融合**”。重点是改变任务分工及取证权限，不是增加代理数量。沿用同一模型和模拟机制，不设跨站物理阈值。

1. 在独立的新开发数据按固定窗口扫描，每站采用相同窗口与预算；粗筛只给区域和可观察形态，边界不清时允许保留疑点，不强迫完整配对。这样才能检验70站入口漏提是否改善。
2. 对粗筛区域提供局部三轴原图，允许重提日期和“不足以确定”。先与同预算的重复全局读图、固定局部图比较，分开判断放大与自适应选区的贡献；文字路径提供相同原始点。
3. 数值只提供局部连续/暂态/独立阶跃解释证据；原始视觉日期和数值日期均保留。分别报告纯视觉、视觉后数值、数值后视觉与无视觉近邻，不让融合高分掩盖首轮低召回。
4. 首先保持原近邻基底，仅检验新增范围；局部边界修补单独作为消融，避免重演S2对已有正确结果的大面积破坏。
5. 先小批验证动作是否真正恢复漏提与范围，再扩大完整开发数据；冻结后另设独立test。事前约定Aff、日P/R/F1、四类F1、负站误报和实际新增TP/FP的报告及采纳条件。

必须新增的过程评价是：真暂态站首轮建议率、建议命中真实异常日的比例、局部重定界前后TP/FP变化、数值验证拒绝掉的正确范围数，以及对已有正确结果的破坏数。只有这些过程指标随改动改善，才有依据说“优化到了关键环节”；不能只挑最终一个较高的F1。

上述方案尚未调用模型测试，没有新成绩。当前决定仍为保留VRC范围研究变体、S2取消集成；补充认识是“继续优化有具体依据”，而不是“已证明继续优化会有效”。
