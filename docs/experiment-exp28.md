## 固定方法

主方法：CEV-Flash / ce_flash_image，qwen3.8-flash。
沿用CFV的数值自由边候选和起点7日中位数offset，仍只输出候选pair ID。
每候选图给原曲线、暂态校正、永久阶跃校正、仅遮蔽起点单个观测四列，
三轴按相同中心和纵尺度比较，原始日索引、其他候选边与缺测均保留。
永久阶跃假设从起点扣到局部视窗结束；暂态只扣[start,end]；
遮蔽只移除起点一个观测，不插值，不补值，不删除整个候选范围。
这三种操作是假设诊断，不是新观测或真值。模型必须比较内部持续性和两端变化，
区分单日尖峰、独立永久阶跃、连续运动与真实暂态，不把暂态校正图本身当作证据保证。
不使用真值筛候选或统一毫米、速率、持续天数阈值，不扩大形变输出权限。

固定对照/消融：
- cf_flash_image：冻结EXP26提示和输入方式，在720新站重新执行。
- edge_flash_image / trend_flash_image：冻结EXP27双边缘放大/趋势分离，在扩大样本上复核。
- ce_flash_cfonly：同CEV提示，仅给原CFV原图和暂态校正图，用于区分提示与竞争图收益。
- ce_flash_raw：同提示，仅原始上下文图。
- ce_flash_noimage：主方法请求仅删除image项。
- ce_flash_text：同窗口逐日原始/历史残差归一化数据和offset，保留5位小数；
  配合相同假设定义可重建全部图，不只给弱摘要。
- ce_vl_image / ce_vl_text / ce_vl_noimage：qwen3-vl-plus模型对照。
- vector_nearest：原向量近邻，同候选、未调参。
- segment_numeric、rf_split_temporal、random_forest、rf_balanced、extra_trees、isolation_forest。
- sdr_flash：原SDR，使用其既有RF来源和慢轨迹图，注明候选来源与CFV不同。

temperature=0，无thinking，无重试，API并发3。无候选不调用，保留在总体。
HTTP/解析失败保留并回退原数值，单列依赖失败；不选择性重新请求或覆盖响应。

## 评价与采纳

范围主评价为暂态Affiliation P/R/正样本站宏F1，继续使用锁定作者源码及缺测适配。
同时报告日P/R/F1、TP/FP/FN、范围覆盖、四类F1、各类F1、形变范围和活动误差、
通用异常指标、场景分层、种子分层、触发子集、多跳变子集、逐站改变与调用成本。
全720站各分区分别报告，开发与test不混合选最优；子集是诊断，不能替代全站主成绩。
无point-adjustment，不扫描测试阈值；IoU指标仅补充，不以其否定Aff收益。
描述性配对站bootstrap不设统计显著性采纳门槛。

开发与test均以预定CEV-Flash为主，不因VL或文字成绩好而改名换主方案。
候选采纳依据：独立test相对原CFV在暂态Aff-F1或日F1至少+.005，
且至少存在一个比同提示cfonly更好的范围指标和可核实正确站点改变；
无须所有指标、所有数值对照领先，但必须披露代价及同信息文字结果。
若仅提示产生收益，报告为提示改进；若文字/数值可等价解释，不能称视觉独有优势。
不满足时取消生产集成，保留负结果；完整大样本评估仍必须完成。
本轮不额外执行VisualTimeAnomaly/TAMA/VLM4TS完整原管线，不能用旧数据原法分数作同站排名。
