# GNSS-VLM-EXP06：GNSS位移结构分解与视觉语义核验实验

## Material Passport

类型：新方法开发协议；仿真、离线识别，不是现场预警验证。状态：登记前开发。
已有EXP04/05测试均已见；本轮只使用新种子2026101404的训练与验证分区开发。
方法暂名 **SD-VLM（位移结构分解与视觉核验）**，结果行`segment_fusion`。

## 研究问题与先验观察

EXP05完整图在混合站经常漏暂态，部分纯暂态被判为形变；活动范围常只覆盖中段。
新路线不继续减少图数：以原始位移的分段回归提供跳变、返回和停止的明确结构，
视觉判断形态，数值拟合定位。一般定位—核验架构已有VLM4TS先例，不宣称首次。

730日、96训练站、24验证站，沿用简单噪声和六种场景。先首6验证站，再余18验证站。

## 方法与参数披露

1. 正常历史前缀拟合线性与年周期，各轴以其MAD归一化。尖峰沿用训练站RF判决，并从分段拟合中排除。
2. 使用作者维护的`ruptures==1.1.10` PELT搜索；作者算法代码未修改。
   GNSS三轴线性最小二乘代价为本项目适配，原始时间不因缺测重编号。
   最少7有效样本、jump=1、惩罚6log(3n)，保留前缀最后90日。**不是库默认配置**。
3. 变点左右21日内比较线性、阶跃、连续折线和阶跃加折线；邻接分段限制窗口以免另一次跳变污染。
   日期±3日细化，两侧至少5点且相邻原始日均有观测。模型选择准则为归一化RSS+3p log(3n)。
4. 在背景与跳变项之外比较一个有界位移轨迹，线性与通用smoothstep两种形状。
   日期7日粗网格、±7日逐日细化，最少15日，最多一个活动区间。
   位移系数3个、起止2个，以5log(3n)+2log2惩罚增加的自由度及二选一形状。
   不读取生成器的潜在运动、速率阶段或真实活动日期；停止后的偏移平台进入恒定部分。
   这不是CPOP复现，也不是严格积分后的生成器模板。单活动假设是适用范围限制。
5. 减去估计活动轨迹后，在相距≤120日的跳变上比较独立跳变与相反返回的脉冲模型；
   左右30日上下文，连续折线项允许活动局部变化。数值选中与未选中的返回对均供视觉核验。
6. 输入全局原始NEU、正常参考和各候选局部原始NEU图；各站图数由观测候选决定。
   同一模型单轮审阅，可拒绝、确认或选择备选返回对，无真值、场景名称或异常数提示。
7. 融合保留RF尖峰；视觉确认暂态后采用数值两边界，并取消这对边缘的阶跃标签；
   阶跃需视觉日期距数值日期≤21日；暂态两边界各≤7日；活动需可观测重叠。
   这些是定位关联窗口，不是毫米阈值。活动采用拟合边界，视觉边界作为同响应消融。

统计惩罚和关联参数均须披露，不能写“完全无阈值/无参数”。使用正常参考且利用未来信息，不能写零样本或在线。
所有候选、拟合选择、提示、请求、响应、失败、图像和导出保存。缺测在拟合中排除，评价/标签/图中保持未知。

## 同组比较与消融

- `random_forest`、`rf_balanced`、`extra_trees`、`isolation_forest`：现有sklearn默认/显式平衡版，GNSS特征适配。
- `rf_split_temporal`：既有数值分工与训练转移解码。
- `visual_only`：同模型纯视觉。
- `guided_fusion`及派生`morphology_fusion`、`localized_fusion`：EXP04/05完整图在新站重跑。
- `segment_numeric`：新分解无视觉，检验数值结构本身的贡献。
- `segment_guided`：新提示的直接视觉输出，检验融合约束与数值边界。
- `segment_fusion`：暂定主方法；`segment_visual_bounds`：同视觉确认、视觉区间边界消融。

验证阶段可选主方法，但必须据全24站、全部失败确定，并在正式测试前另存冻结协议。
不能把数值方法的提升全归于LLM；若视觉无增益，应如实报告。
