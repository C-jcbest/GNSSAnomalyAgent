# EXP40：按类型分工的局部视觉范围复核（TLV-GNSS）

2026-10-17。研究对象是机制仿真GNSS观测；18已见开发诊断＋54新开发确认，非现场数据。
最终决定：**没有超过最强数值对照，不升级主方案，不执行预留720站测试。**
保留本轮作为范围复核消融与负结果证据，EXP37的360站独立测试及其结论保持原样。

## 方法与来源

OWV全窗视觉定位→候选边界局部原始位移复核→暂态与数值范围并集。
点异常发生日与持续形变活动范围由冻结数值近邻提供，视觉不删除这些事件。
原始位移先确认活动、缺测不赋确定日标签、不输出内部阶段，不设置跨站毫米/速率阈值。
两范围分别评价，不计算四类或两范围平均。
图文复核共享上游视觉候选，属于**复核阶段条件消融**；数值单独是完全无视觉对照。
独立复核输出也有候选输入，不能叫“无数值候选纯视觉”。

借鉴[TAMA](https://arxiv.org/html/2411.02465v1)的正常参考/多尺度复核，以及
[VisualTimeAnomaly](https://arxiv.org/html/2502.17812v2)的类型分工与Checking。
没有运行这些作者完整流程，也没有把其原数据成绩挪入本表。
近期LEARN-TS的正常语义调制仅作补读，不当作本项目已实现或被超越的方法。
读取范围、原文副本、HTTP/SHA和适配边界见[调研](exp38-reading-notes.md)。

## 能支持的视觉作用与局限

图像融合对同信息文字：Aff高.0077（0.77个百分点）、日F1高.2180、少616FP，TP相同。
图像独立复核对文字：Aff高.0868（8.68个百分点）、多97TP、少615FP，
说明复核阶段图像有范围判别作用，不只是生成解释。
相对未复核OWV并集，融合少1665FP、真实覆盖不丢失；阴性误报从1894降至294日，
减少84.5%。这主要是抑制误报，不能说新恢复了数值漏检。

全54站图文结果不全来自模态：51个图文均成功站中，融合Aff差缩至+.0013、少549FP，
仍有误报控制收益，但不能把全样本+.0077全部归因为图像。
完整配对计数和逐站变化见[贡献审计](../results/exp40-confirmation-v1/contribution-audit.json)。
同一51站的独立条件复核，图/文Aff=.8223/.6812、日F1=.6971/.4141，图像多119TP、少548FP；
这进一步支持复核阶段图像的范围识别作用，仍不能推出完整融合胜过最强数值方法。
计算结果见paired-independent-review-sensitivity.json，候选和失败定义不变。

数值近邻本批696个暂态真值日已全部覆盖，因此没有新增TP空间；TLV新增306FP，Aff也
略低于数值，三个种子相对数值的Aff方向均负。预定确认条件不通过，不用“几乎相同”改判。
这不否定EXP37另360测试站已观察到的视觉补漏，也不能拿其旧分数与本批直接排名。

当前294个阴性站暂态误报均来自三个持续形变站：v0022有160日、v0064有109日、
v0040有25日。正常、单点、阶跃场景本批暂态误报均为0；文字的大量误报集中于阶跃。
这表明本轮解决了部分永久平台误判，主要剩余问题是持续运动/停止与暂态返回的混淆。
后续应针对这种形态和同站三分量边界关系提出新假设，不继续只扫描图像DPI或格式规则。
这些站均已见，不再拿它们作下一方法的独立确认。

## 三项变体与采纳决定

- **EXP38 NRV-GNSS**：同站正常参考＋原始/残差双视图；暂态阴性FP降低，但没有新增TP，
  纯视觉范围识别偏弱。未通过，取消集成。[报告](exp38-assessment.md)。
- **EXP39 LCV-GNSS**：原始位移局部连续性复核；18站Flash暂态增加13TP、降低误报，
  但形变Aff下降.0194；VL误报仍高。整体未通过。[报告](exp39-assessment.md)。
- **EXP40 TLV-GNSS**：明确只迁移Flash暂态、保护其他三类。18站诊断通过，
  54新开发确认未通过；不升级主方案，不请求720测试，不将形变数值成绩归于视觉。

EXP40冻结协议见[协议](experiment-exp40.md)。未使用测试保留在artifacts/exp38/data，
生成了720站不代表已经测评720站；本轮实际不同站只有72。
