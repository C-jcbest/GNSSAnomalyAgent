# v4 登记后的离线分析说明

日期：2026-10-12。主批与复测保留相同的冻结检测源码、提示、数据和参数；本文件不改写原登记协议。

## 作者解析

开发源码调用返回HTTP200，但含解释文字和列表。v4的GNSS包装使用严格JSON解析，这与作者`src/result_agg.py::parse_output`不同：原函数截取首个`[`到最后的`]`，对部分截断输出补括号；`utils.py`原向量函数还会跳过无效点、裁剪区间。

因此新增`scripts/replay_author_parser.py`，从锁定commit的源文件提取并执行未经修改的三个函数AST，避免引入与解析无关的数据集/affiliation依赖。保存源文件哈希和每个子响应解析记录，使用同批原始响应，不请求模型、不修改提示、不扫描阈值。严格解析主列保留，作者解析另列`visualtime_gnss_author_parser`。沿用六个子请求全部成功的站点政策及GNSS NEU union/缺测掩码。

该分析在查看开发接口失败后增加，属于登记后分析。作者原解析行为保留，并不意味着恢复原论文数据、模型或指标，也不代表完整TSAD-Agents复现。论文应同时披露GNSS绘图、模型替换、NEU拆分/合并与站点失败政策。

## 报表适用终点

作者通用异常方法和iForest没有形变语义输出，报表的形变列始终留空。失败不能使一个通用方法突然拥有形变分类能力。阶段字段是机制真值的历史诊断结构，不是本轮模型终点，报表不比较阶段零分。

后续仅纠正离线评价的任务适用性与标签显示，不改变已保存的模型响应和预测。任何纠正须另存评价目录、记录评价源码哈希，并核对通用检测计数和所有适用形变计数与原评分一致。
