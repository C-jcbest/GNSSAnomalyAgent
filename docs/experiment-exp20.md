# EXP20：视觉异常区间识别的多指标复核

2026-10-15登记。父版本f42d1c2，备份标签`backup/pre-exp20-range-evaluation-20261015-f42d1c2`，本地完整受控文件备份`artifacts/backups/EXP20_pre_f42d1c2_tracked.zip`。本实验先复算既有预测，不产生模型请求、不调整预测、不重新选择原实验指标。这是事后补充分析，原test数据已见，不能称新增盲测。

研究问题：视觉输入是否改善暂态、持续形变的区间识别？两类分别报告，二者并集另报；尖峰、阶跃仍在原四类评价中单列。完整方法参与比较，配对子任务输出不当成完整识别方法。

采用Huet、Navarro、Rossi的KDD 2022论文《Local Evaluation of Time Series Anomaly Detection Algorithms》（arXiv:2206.13167，DOI:10.1145/3534678.3539339）作者代码`ahstat/affiliation-metrics-py`，锁定提交`8d8449858096bbade6a6e70848d05c9cc9b846fe`。作者MIT许可及完整源码保留于vendor；不修改积分公式或作者默认概率。AnomLLM论文也采用此类指标评价离散区间，不能以二值输出冒充连续异常得分计算VUS。

## 指标和GNSS适配

- Affiliation precision、recall、F1：按站、按类型调用作者实现；正样本站等权汇总，并报告站F1均值与汇总P/R的调和均值。这里的F1是本项目对作者P/R取调和均值，不是作者新增实现。主呈现暂态和形变两类的站均F1，不用四类日F1代替区间评价。
- 作者实现只接受至少一个真值事件。无真值站的Affiliation记null，不计作1；单列负站误报天数、误报区间数及每正常站年误报。正样本站完全漏检时作者P为NaN、R为0，保存P=null；用于完整站比较的F1和汇总P约定为0，并单列空预测数及作者定义域内P均值，避免删除漏检站。
- inclusive日期[a,b]映射半开区间[a,b+1)。保留原日期轴，历史正常前缀不参与，Trange=(background_end+1,记录长度)。缺测日从预测和真值同时置false，会分割区间；不压缩时间，不跨站拼接。Affiliation的距离仍按历时计算，缺测日并非从概率积分域删除；这属于明确的缺测适配，不称作者原始GNSS默认方案。
- 同时计算保留缺测内部连续跨度的Affiliation敏感性指标：按语义事件填充跨度，完全不可观测事件剔除；只用于敏感性分析，不能解释为给缺测日赋标签。若结论随缺测处理改变必须披露。
- 日P/R/F1（无point adjustment）、一对一事件IoU≥0.3/0.5的P/R/F1、匹配事件起止MAE、逐真值事件最佳IoU及覆盖率（完全漏检记0）、预测区间数、误报日和误报区间。IoU阈值仅是评价匹配条件，不是位移/速率告警阈值。
- 语义事件数与缺测后碎片数分开；边界MAE按匹配数加权，同时列出匹配数，不能用只剩少数匹配事件的低MAE声称整体更好。
- 无类型输出的方法仅参加原通用任务，不硬塞进两类区间比较。库/论文的GNSS适配均明确标识，不称相关优秀论文的原任务默认复现。

先复核EXP06同48站的全套完整方法，再复核后续有图/等价文字/无图开发对照。正样本站集合由真值固定，各方法相同；正常站误报保留。展示全部预定指标，不根据事后最高指标选结论。若有图与无图预测相同，新指标也不能证明视觉作用。

后续新方法需单独登记输入、流程与开发种子，先小批，再决定扩量。生产方法和论文正文在新证据完成前不替换。
