# EXP25：SDR-GR全面同站测评与模块消融

2026-10-15。实验编号**GNSS-VLM-EXP25**，名称**SDR-GR全面同站测评与模块消融**。
固定主方案为**SDR-GR-Flash / `sdr_gr_flash`**。分支`codex/exp25-comprehensive-evaluation`，
父版本`4e5259c`；开测前备份标签`backup/pre-exp25-comprehensive-20261015-4e5259c`。

**完成新48站、26种方法/消融的同站评价，并单独复算历史48站、29种方法。**
新测试支持整体方案对暂态类型识别的增益；图像增益随模型和指标变化，不能概括成所有指标领先。
Qwen-VL有图相对同模型去图同时提高暂态Affiliation F1和逐日F1，形成一个可定位的正向案例；
Flash有图提高逐日F1和四类F1，但Affiliation F1低于去图。GR在新测试没有合条件干预机会。

## 数据、执行与指标身份

新测试为seed2026101516的test48站；96站训练，已用于EXP23—24开发的48站validation不计入本轮新测试。
此前未评分的test在协议固定后运行；先6站检查流程，再完成42站，没有按成绩筛站或改参数。
每站730日，六场景各8站。暂态/形变分别16个正样本站；通用正样本39站，另9站在有效测试日上无异常，
其中包括异常落在缺测日的情形，不能机械将其解释成只有8个正常机制站。

范围主指标采用作者源码Affiliation P/R/正样本站F1均值，另报逐日、事件、覆盖、误报与边界。
原始日期/缺测保留；不point-adjust，不扫测试阈值，不用IoU否决Affiliation正结果。
作者原函数、GNSS适配、参数差异及全部指标定义见[方法与指标说明](exp25-methods-and-metrics.md)。
[开测前协议](experiment-exp25.md)、[原作者解析补充登记](exp25-author-parser-addendum.md)均保留。

**Flash图像作用有正有负。**相对完整去图，暂态日F1 +.0866、四类日F1 +.0441、
覆盖+.0834、FP减少10日；但主评价Aff-F1 **下降.0667**，按Affiliation排序去图更好，这个结论保留。
4站最终事件不同：s0101、s0107有图更接近完整暂态；s0125、s0143有图漏报，去图给出邻近短范围。
例如s0125真值666—690，去图预测661—665，没有有效日重叠但Aff-F1仍为.9246。
这是距离型指标的实际表现，不是计算错误；不删除该分数，也不以IoU另设采纳门槛。

**Qwen-VL有图相对同模型去图：暂态Aff-F1 +.0417、逐日F1 +.0364，FP同为5日。**
变化仅在mixed场景s0101：去图没有暂态，有图预测539—568，增加30个TP日、没有新增FP。
该站有图Aff-F1 .6664、去图0；原真值到588，有图仍未完整覆盖，不能写成精确恢复全部区间。
这是新测试中的有限图像增益证据。Qwen-VL整体又低于Flash主方案，不能据这一对照更换主方案或宣称模型全面更优。

**新增GR本轮无直接收益。**6站、10个恢复候选全部不满足“前一日缺测、当前首次观测”的约束，
因此GR相对原SDR逐站没有改变；不能把本轮叫作GR补缺测泛化成功。
去约束VL有较高Aff-F1 .8975，按用户要求保留；但TP仍489日、覆盖仍.8125、FP119日，
不能称新增准确检出。去约束Flash反而下降。慢轨迹辅助图本轮也未胜过去图版本`sdr_raw`，
应将简化输入列为后续候选，而不是事后替换冻结主结果。

## 场景与描述性区间

改进集中在8个mixed站：主方案暂态日F1 .8645>数值.6364，Aff-F1 .7446>.5000；
同场景Flash去图Aff-F1 .8779、日F1 .6910，仍体现评价取舍。
Qwen-VL有图/去图在mixed的Aff-F1为.6654/.5821，日F1 .7123/.6296。
正常、孤立尖峰、单阶跃、单暂态、单形变场景中，SDR派生与数值没有这类修复差异。

完整[场景表](../results/exp25-test-1516-full-v1/scenarios.csv)保留四类固定等权口径：
单类场景即使该类F1为1，四类均值也可能只有.25；正常场景无正例F1记0，须看误报，不能解释成识别全失败。

2000次配对站bootstrap：主方案减纯数值的暂态Aff-F1差值+.1223，描述性95%区间[-.0060,.3111]；
四类日F1差值+.0286，区间[-.0161,.0897]。主方案减完整去图四类日F1差值+.0441，
区间[.0038,.0964]，暂态Aff-F1差值-.0667，区间[-.2228,.0572]。
不将这些区间作为显著性采纳门槛；共享模型、模拟数据、单新种子限制外推。

## 请求、验证与证据文件

本轮**400次实际请求，400次HTTP 200，0重试**，输入519067 tokens，输出106106 tokens。
按冻结严格契约有286次输出验证失败：VisualTimeAnomaly严格解析282/288、纯视觉3/48、
Flash恢复1/6。不能把它们统称网络失败。原作者离线解析改善读取能力，但仍有32站部分失败；
原响应、原严格回执和补充解析都保存。
主方案实际依赖14次请求（8次第一阶段＋6次恢复），其中1次恢复失败按原规则无修复，最终48站仍有数值检测结果。
`comparison.csv`另列最终失败与阶段依赖失败，避免把派生status=success写成所有模型调用成功。
Qwen-VL第一阶段8次均成功；有图/去图分别保存，不共享模型输出。
