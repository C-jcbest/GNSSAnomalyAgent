# 实验全程审查与下一阶段建议

> 2026-09-27；审查对象为本模拟工作树的 P1～P7a。全部性能数据仍为开发 Pilot 结果。本文是审查和待实施方案，不是新实验的验收记录。

## 结论与复核入口

本次未发现数据损坏、历史报告无法重算或真值进入检测函数的问题。现有证据足以支持受控合成数据上的开发比较，尚不足以支持独立泛化、组合优势或现场预警结论。当前最应推进的是**冻结候选复核实验及独立评价入口**，随后才运行小规模开发实验；不继续修改生成参数或反复优化同一 Pilot 的提示。

运行 `uv run python scripts/audit_experiment.py` 可复核，摘要写入本地 `runs/audit-v1/summary.json`。该脚本读取历史产物，不调用模型；并集是离线诊断，不注册为新检测方法。本次通过：

- 全部 300 例文件哈希、分层配额、事件贡献与观测组合等式；位移、H/R3D 派生公式及连续日期。
- 300 个不同 case seed；annual/semiannual/noise 各有 300 个不同成分 seed，300 组不同背景数组。没有发现重复背景；这不能替代跨集合隔离检查。
- P5/P6/P7a 冻结推理源码及配置哈希；八份方法×任务预测和原 P4 报告逐项重算一致。
- 四个数值方法各重放六例（固定取 Normal 和五种 Single 的首例），共 24 次结果与历史预测一致；不是全量重新推理。
- 两版视觉、两任务共 1,200 条正式记录：每任务恰好 300 个不同案例，成功响应严格重解析一致，失败保留空预测；两版均使用相同 P6 PNG 哈希。

## 问题按优先级排列

### 1. 缺少独立确认集，是论文结论的主要限制

同一 Pilot 的 Normal 用于阈值校准，全部异常用于方法比较与选择，之后又用于误差分析和提示修改。因此当前所有分数均有开发选择影响，包括 P7a；将其中 60 例抽作开发后，剩余 240 例也不能再称为未见测试。

下一份确认数据应保留 `event-v6` 公式与预定义配额，使用独立 seed namespace，检查 case seed、成分 seed 和去掉 case_id 后的数值输入哈希不重合。方法、阈值、提示、失败策略和主次指标必须在读取确认标签前冻结。**新 Normal 不重新校准阈值。**独立同分布合成数据也只确认该模拟分布，不确认现场适用性。

### 2. 主指标正确，但不能用单一分数概括能力

Theil–Sen Affiliation F1 **0.9345** 与正轴逐日 IoU **0.3398** 同时成立：前者是距离关联指标，后者衡量预测与真值日期的重叠。新版视觉相应为 **0.8730 / 0.5400**。指标选择会改变方法排序，不能只挑有利指标。

保留原 P4 主指标、Point ±3 日补充视图、Range 正轴 IoU、全轴逐日 micro F1、负轴 FAR 和执行成功率。正轴 IoU 不惩罚负轴报警，必须与后两项结合。±3 日采用严格一对一，额外报警仍计 FP；不是“命中区间一个点就全段算对”的 point adjustment。±1/7 日只作敏感性分析，不据结果选容差。

FAR 是**成功的任务负轴**上的报警比例，不是只含 30 个 Normal 的 case FAR。失败负轴不计为正确无报警，所以方法间 FAR 分母可能不同；另报 Normal 成功轴 FAR、Normal 失败率和共同成功案例诊断。不能把分母变化后的 FAR 下降直接解释为所有正常窗口的报警量下降。

### 3. 数值方法的覆盖不均衡，不能据总体排名忽略 PELT

| 精确日命中 / GT 数 | Spike | Step |
| --- | ---: | ---: |
| SR | 302 / 302 | 15 / 141 |
| PELT | 0 / 302 | 91 / 141 |

这是事后按 GT 形态统计的召回诊断，不是类型识别准确率，也不允许据 GT 运行时路由。Point 的 443 个事件中约 68% 是 Spike，总体 F1 选出 SR 符合原规则，但不等于 SR 对突变起点也最好。保留四个基线及分组结果，P5 的冻结选择不改。

PELT L2/min_size=3 是均值分段方法，本来不适合表示单日尖峰；临时偏移的两个边界也可能被报为 Point。Theil–Sen 可能对 Step 附近窗口产生斜率报警。MP 的 z 标准化 self-join、30 日窗口及中心日映射，只代表当前实现，不能由其低分否定整个 Matrix Profile 方法族。SR 是简化谱残差实现，不是完整 SR-CNN。

若后续确需增加 Point 候选覆盖，应单独提出 **SR+PELT 新版本及其数值单独对照**，不得悄悄替换 P5、增加隐藏 ensemble 或用真值选择分支。只做 keep/drop 的复核不能恢复候选池中没有的正确日期。

### 4. 直接合并候选已有明确代价

复用冻结预测，把数值与 `visual-semantics-v2` 取并集；视觉失败时显式回退数值，因此并集 300 例均有效。不同于纯视觉的成功分母，以下仅为开发诊断：

| 任务 / 方法 | 主 F1 | 补充指标 | 负轴 FAR |
| --- | ---: | ---: | ---: |
| Point SR | 0.5518 | 精确 TP 317、FP 389 | 0.2101 |
| Point SR ∪ Visual-v2 | 0.3586 | 精确 TP 333、FP 1081；±3 日 F1 0.4297 | 0.4253 |
| Range Theil–Sen | Aff 0.9345 | 正轴 IoU 0.3398；全轴日 F1 0.4886 | 0.1954 |
| Range Theil–Sen ∪ Visual-v2 | Aff 0.9359 | 正轴 IoU 0.4951；全轴日 F1 0.4118 | 0.3609 |

Point 增加 16 TP，同时增加 692 FP。Range 的 Affiliation 几乎不变，但负轴报警增多，全轴日 F1 下降；其 IoU 也低于 Visual-v2 单独的 0.5400。候选互补存在，不足以直接推出融合有效。

### 5. 提示改善的因果证据和结构可靠性仍有限

P7a 只修改活动语义提示、沿用相同图片和请求设置，开发改善有记录；但两版是在不同时间各调用一次，温度 0 不保证服务完全确定，同名模型也未提供固定权重版本。共同成功案例分析可以部分排除解析失败率差异，不能排除时间漂移和随机性。

P7a 仍有 Point 3 例、Range 19 例失败，其中 21 例为根 JSON 数组，1 例超时。当前严格拒绝这些响应是遵守冻结协议，不应修复后覆盖旧分数。下一版本可以做 schema-only 工程预检，但必须核实实际端点支持，并把格式改进与复核算法增益分开。若论文要声称某段提示导致改善，需在已知开发子集上同期交错运行旧/新提示，预定重复次数（例如三次）；这不是当前版本已完成的证据，重复标准差也不是置信区间。

### 6. 真值访问和覆盖保护存在工程欠缺，已局部修正

P5 检测与校准函数只接收观测输入，但运行器预测前后的 `verify_pilot()` 会读取全部 truth。原文“评价前才读真值”表述过强，已修正 [P5 文档](06-p5-numerical-baselines.md)。本次没有发现异常真值进入 `_predict()` 或阈值计算；完整进程仍不满足严格的输入目录隔离。

旧 P5 运行器可覆盖同目录结果。本次在 CLI 加入已有预测/report/run 文件检查，存在任一文件即拒绝运行，重现实验应显式指定新的 `--out-dir`。冻结的 `numerical_runner.py` 不改，直接调用旧函数仍不具备覆盖保护；CLI 检查也不提供并发目录锁。新独立运行器必须使用独立输出目录、原子写入及输入/评分分离，不能把当前补丁宣称为完整存储保护。

当前生成入口固定 `pilot-v1` 身份，视觉运行器还校验该 Pilot 的哈希和数量。因此建立确认集需要新增版本化 manifest 适配及读取冻结参数的推理入口，不能仅换 seed 后调用原命令，也不能重新校准后称为冻结推理。

### 7. 外部效度与公平比较应明确边界

- 当前无缺测、相关噪声或真实站点背景，幅值/时长固定且异常密度受场景配额控制；这是受控形态比较，不是现实频率样本。暂不扩充生成模型，先验证现有研究问题。
- Slow/Acceleration 的首日贡献为零，早期变化可能低于噪声；某些相反 Step 与暂态形状也相近。标签是已知生成活动，不保证每个边界可由观测唯一识别，不能要求模型判断物理原因。
- 数值有已知 Normal 的校准，视觉无示例但新版提示受开发结果启发；准确表述为“Normal 校准数值基线”和“无示例、经开发调整提示的视觉基线”，不称二者都完全未经调参。
- 全 365 日输入、中心窗口和全局图均使用未来信息，属于离线定位，不是在线检测延迟或提前预警实验。
- 数值计时含校准和首次 JIT，视觉调用计时不含完整渲染流程。现有秒数不能用于公平的端到端速度排名；新实验同时报告调用次数、可得 tokens、缓存复用与完整流程耗时。

## 下一步：先准备 P7b，再做独立确认

以下为建议，尚未实施新调用或创建确认数据。

该建议随后已实施。详细术语和指标见[实验方法手册](11-experimental-handbook.md)；[P7b](12-p7b-candidate-review.md)完成配置冻结、输入隔离和 60 例开发运行，但两项主 F1 均下降，未进入独立确认。以下保留本次审查时的推进建议，不代表仍有待执行任务。

1. **先完成实验基础设施。**新增输入专用 manifest/加载器、冻结阈值推理入口、独立评分命令和不可覆盖的输出目录。推理环境不放 truth/分层类型；渲染与纯数值均只收 N/E/U。以当前固定样例验证新入口与旧预测等价，再用于新集合。
2. **冻结一个最小候选复核实验。**在元数据分层选定的已知开发子集上，对照 N、V、N∪V、固定复核(N∪V) 四条件。N 保留 SR/Theil–Sen，V 固定语义 v2；复核只接收输入图与有来源的候选 ID，keep/drop，不改轴、不移动日期/端点、不新增事件。不要求两路共同确认。候选过多、空候选、无效 ID 和调用失败处理均预先定义；复核失败记失败，不能悄悄回退抬分。
3. **先检验是否值得继续。**同时报告删除的 FP、误删的 TP、复核前后全部指标及新增成本。Point 额外报候选池精确/±3 日召回上限；Range 检查保留区间的日 IoU。keep/drop 不直接研究边界重定位；若未来允许改边界，另立方法版本和对照。工程 schema 支持先在 Pilot 外预检；如改变响应格式，相关纯视觉对照采用同期一致设置，旧 v2 作为历史对照保留。
4. **开发结束后才确认。**建议新建与 Pilot 同配额的独立 300 例确认集，保持生成公式，冻结后一次性评价。若还需要独立验证集选方法，须另留最终测试集，不能把选型用过的集合称为最终测试。以 case 为配对抽样单元报告差值的不确定性，三轴及同例多事件不能当独立样本；固定配额下可按原分层 bootstrap，并重算每次整体指标，说明区间只条件于该合成分布及已采集模型输出。

P7b 若不能证明复核减少过报且具有可接受的漏报和成本代价，就保留独立数值/视觉基线结论并停止组合路线。只有固定流程出现可重复的互补收益，才讨论轻量 Agent；Agent 不是预定必须得到更高分的终点。
