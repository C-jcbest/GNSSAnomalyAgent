# GNSS-VLM-EXP05：当前结果与论文使用判断

2026-10-14。实验名称：**GNSS视觉形态确认与数值精确定位实验**。
正式主方法：**SG-LocFusion（单图形态确认与数值定位融合）**，对应报告`localized_global`行。
正式主指标：四类等权日F1；各类型跨站汇总TP/FP/FN后计算F1，再四类型等权，不是各种子F1直接平均。
EXP04初稿保持原版本，本报告是新增实验依据，不能将两轮不同测试站混写成同组比较。

## 1. 已完成范围

新开发种子2026101401：96训练、24验证站，先6站18请求，再18站54请求。
依24站验证选择单图+新日期+视觉活动边界，在正式测试生成前冻结。
新测试2026101402/2026101403：各96训练、24测试站，共48新测试站；各自训练拟合。
两个测试种子的验证分区未用于开发，开发种子的测试分区也未用于选择。

开发72+正式192=264次视觉请求，失败无重试，派生结果不产生请求。

主方法较平衡RF的四类日F1高0.1464，较数值时间解码高0.1597。
较同输入旧日期规则高0.0105，阶跃严格F1高0.0422。较EXP04完整方案综合分低0.0179，
但阶跃F1高0.0621。不能写“单图全面优于多图”或按测试最优改认主方法。
完整图加定位的辅助变体较EXP04完整方案高0.0132，其余三类型完全相同，增量来自阶跃日期规则。
固定数值活动变体虽测试主指标略高，事件指标更低，不据此推翻开发时冻结的视觉活动边界。

## 3. 阶跃、活动与效率的具体证据

主方法四类日F1分别为尖峰.7200、阶跃.5806、暂态.4124、持续形变.6431。
15个可观测真阶跃：原完整7/5/8、单图旧日期7/4/8、单图新日期9/7/6，分别为TP/FP/FN。
新单图规则减少漏检，但误报从4增至7、精确率从.6364降至.5625；
不能将F1改善解释为每个日期都更准确或没有代价。完整图新日期8/5/7，是一项更保守的定位增益。
8个正常控制站，本项目数值时间解码及上述融合方法均未产生异常误报；不推断总体误报率为零。

16活动站有1694个可观测真活动日。数值、原完整、单图主方法的漏日为394/632/665，
停止后假活动日527/39/71。视觉减少停止平台误报，同时牺牲活动覆盖；
单图固定数值活动漏日629、停止后假日274，也说明边界策略存在权衡。

完整输入8图与单图父方法各48请求，输入token465075/196275，单图减少57.80%。
单图仍有数值候选文字和原始邻域值，不能说只有图像或零数值辅助。
请求中位耗时4.385/3.725秒，约少15%；受服务负载和缓存影响，不能当普遍加速定律。
这里不含数值训练、绘图和导出的全流程耗时，也不能说请求数减少了58%：两者均每站一次。

## 4. 文献与原码对照

方法依据复读VLM4TS定位—全局核验段、ChangePointCNN-GNSS正式方法段，见[续读记录](exp05-reading-notes.md)。
一般的候选与视觉核验分工已有先例，贡献要落在GNSS形态定义、站点参考、定位与成本权衡。
局部回归定位器是本项目代码，未冒称ruptures/CPOP/ChangePointCNN原码复现。
近期TimeRCD作者源码对照单独采用[协议](experiment-exp05-timercd.md)，
明确原API分数与缺测/判决适配。代码已锁定、运行环境安装完成，但官方/镜像/分段获取均未取得完整权重，
标准hf客户端下载也未完成；本轮停止资料获取并保留残片，**没有启动TimeRCD推理，没有该模型成绩**。
官方演示经源码核查使用旧权重，未将其当作替代。实际获取状态见`papers/exp05-timercd/setup-status.json`。

## 5. 面向EI论文的判断

本轮已有可以用于论文的正结果，不必以所有指标均领先作为完成条件。
合理论证是：相对常用数值对照改善四类识别，语义确认与数值定位改善严格阶跃识别，
单图配置以约58%输入token节省换取小幅综合分下降；完整图定位变体提供准确率优先的选择。
这些是任务条件下的观察，不是统计显著性声明或对所有近期论文模型的SOTA结论。
可以据当前已完成结果更新论文方法/实验章节；若要声称优于近期具体模型，须先补齐同组作者源码对照，
这一部分目前仍未完成。下一轮算法优化只针对混合异常的候选覆盖与暂态/阶跃干扰。
无需先引入多代理、微调或复杂噪声设计，也无需无限调优综合F1。
