## 1. 研究对象与可检验主张

建议题目：《面向滑坡监测的长期 GNSS 位移活动定位与阶段识别：视觉与数值证据的分层方法》。目前研究对象是位移记录中的可观测运动行为，不是已经确证的坡体破坏机制或失稳时刻。

- RQ1：两层识别能否在相近活动召回下减少静稳期误报？同时报告完整召回—误报权衡，不能单靠少报获胜。
- RQ2：视觉第一层相比同信息的强数值定位，在哪些活动类型、信噪比和截断条件下有收益或损失？
- RQ3：第二层模型相对于相同数值证据上的固定规则，是否提高端到端特征识别和边界质量？
- RQ4：真实记录、未见运动形态和显示尺度变化后，以上结论能否保持？
- 可选 RQ5：严格在线生成的阶段特征能否改善同一个下游位移预测器？不把它作为当前离线主实验已经回答的问题。

当前既有实验表明工具智能体尚未稳定优于充分工具规则；长期数据是新的任务，不可以沿用旧成绩论证新贡献。

## 2. 两层标签和自动方法契约

第一层输出活动确认范围、起止不确定带与证据不足范围。confirmed、uncertain、not_confirmed、missing 延用当前开发语义；not_confirmed 表示未确认活动，不应全部解释为已知物理静止。用于误报评价的稳定对照需独立确定。

应明确区分三个对象：供复核的高召回候选窗口、从位移确认的活动区间、区间内部的运动特征。候选可带上下文，但第二层不能在未确认活动的日期输出确定加速。新证据足以改变活动范围时，必须显式修改第一层并记录理由，不能偷偷越界。

“活动”与“异常”也要区分。长期稳定蠕变可能是该滑坡的常态；主任务建议称活动识别，另以预先定义的背景基准研究异常增速。仅凭单站位移不能始终区分坡体运动、基准漂移和其他系统误差，无法判别时保留未知，而不强行解释地质原因。

第二层建议将特征拆成两个维度，避免“慢速”和“加速”排他冲突：

| 维度 | 建议输出 | 约束 |
| --- | --- | --- |
| 运动强度 | 缓慢／较快／未知，并保留物理单位速度 | 阈值来自训练/开发数据或独立领域定义，不从测试样本调出漂亮分组 |
| 运动演化 | 加速／近似匀速／减速／变化不明 | 依据持续时间与速度变化证据，不以某日加速度正负直接命名 |
| 活动层 | 确认／不确定／未确认／缺测 | 停滞在活动层表达；不能因为累计位移保持较高就延续活动 |
| 观测质量 | 跳变、异常点、长缺测、可能漂移等标志 | 与物理阶段分开，不把仪器错误当成运动阶段 |

上述拆分是后续协议建议，本轮未改写现有 L/A/S/D 标签或接口。若保留这些旧开发标签作实验，须先冻结是否允许多标签及逐类定义，不能直接把重叠概念当作互斥多分类。

多轴处理必须明确。优先使用有物理依据且独立确定的沿坡投影；没有坡向时，保留 N/E/U 及其噪声和运动方向证据。负向运动加快时，带符号速度可能变得更负，这仍可能是速率增加。不能把单轴二阶导数为正简单等同滑坡加速，也不能把噪声下的三维模长正偏当作弱活动。

自动执行应冻结：观测输入、时间索引、缺测掩码、绘图参数、模型版本、提示、可用工具、预算、输出结构与解析失败策略。保存图像及哈希、数值证据和最终 JSON。输出错误或超预算计入失败率；不能依据测试真值修正后作为自动成绩。当前会话逐图复核不是已冻结的自动算法。

## 3. 数据与标注

现有批次 `landslide-v1-20261007-075217-7b9f8f2c` 的 24 条、每条 1095 日记录及 v2 标注全部作为开发资料。48 个确认区间不是 48 个独立滑坡，26,280 个日标签也不是 26,280 个独立实验样本。现有确认区间是保守内部范围，不是真实起变时刻。

后续至少包含以下三个证据层：

1. **受控仿真测试。** 新的独立背景记录和随机种子，涵盖全静稳、微弱长期形变、中途起止、多次再活动、加速后回缓、首尾截断、长缺测、跳变与相关漂移。把运动机制变化与测量误差变化分开；至少留出一种未用于开发的生成形态。只换随机种子不足以证明跨机制泛化。
2. **真实案例试点。** 已核对 Oak Ridge 仓库记录与文件清单：https://doi.org/10.5281/zenodo.11511667 。两个测站同属一个滑坡，适合检查真实数据可用性及专家标签成本，不足以做跨场地结论。尚未检查工作簿数据质量与阶段标签，不保证可直接用于评分。
3. **独立真实测试。** 争取多个不同滑坡或不同监测工程，按整个场地和测站群留出；另做历史训练、未来测试。若只取得一个场地，应把论文结论限定为单场地案例和受控实验。

仿真保留两套标签：潜在过程真值用于机制恢复；观测可辨识标签用于在噪声条件下可合理识别的活动与阶段。分别评分，不用平滑生成真值替代真实观测给模型看。测试标注建议由两名领域标注者独立完成，不能看到生成状态、模型结果或彼此标签；分歧经仲裁，记录边界区间和不确定原因。标注一致性低时，优先修订概念定义，不强行取单日精确边界。

不使用待测 LLM 自己生成的标签作为唯一金标准。若暂缺专家，只能明确报告 AI 辅助探索结果。标注者也不应只看与待测视觉方法完全相同的一张默认轴域图，应允许原始数据和标准数值检查，避免标签天然偏向该显示方式。

样本量先以独立开发试点估计事件发生率、误报方差和可接受差异，再为主指标设计区间精度或功效；不凭空指定能保证显著性的样本数。类别覆盖型仿真与真实发生率不同，分别报告，不从平衡集估计现场告警阳性预测值。

## 4. 最小对比矩阵

| 编号 | 方法 | 回答的问题 |
| --- | --- | --- |
| B0 | 鲁棒分段回归或局部斜率＋变化点定位＋固定阶段规则 | 强数值基线是否已足够；PELT 等应采用适配斜率/趋势的代价，不默认在累计位移上用均值跳变模型 |
| B1 | 单阶段视觉：直接从完整记录输出活动和特征 | 层级流程相对一次判断的增益 |
| B2 | 数值活动定位→与主方法相同的第二层判别 | 隔离第一层视觉定位的价值 |
| B3 | 视觉活动定位→与 B0 相同证据上的固定规则 | 隔离第二层模型判断的价值 |
| M | 视觉候选与活动确认→位移、局部图及数值证据细判 | 拟议主方法 |
| P | 一项可复现的相邻公开视觉方法，优先审查 TSAD-Agents 或 TAMA | 是否优于已有视觉流程；只具异常输出时在活动层比较 |
| O | 真值活动范围→同一第二层 | 定位误差影响的诊断上限，明确不参加公平主排名 |

增加一个“同样两阶段和同样预算，但没有活动证据约束”的消融，可区分仅增加调用次数与活动约束的效果。若输入或预算不同，应单列自然配置结果和受控配置结果。

AnomaMind 是必须讨论的近邻。后续源码核查已确认其工作流及公开 0.6B/8B 权重文件清单，可先验证发布权重推理；不能预设必须从头训练。若改变权重或流程，应明确标注，不能把弱化版失败解释为原方法无效。VisualTimeAnomaly 仓库 README 对会议年份有旧文本，当前树及入口也未核实完整 TSAD-Agents 实现；正式书目信息采用论文，直接视觉入口不冒充完整智能体。本轮尚未安装或运行这些仓库。

前人多数只输出一般异常，未定义滑坡阶段。因此共同活动层可直接比较，阶段层需要给各定位器接相同阶段头，并标明“任务适配”。不能拿通用异常 F1 和滑坡阶段 F1 混排。数值先候选→视觉复核也应保留，避免预设视觉顺序必优。

## 5. 公平性与指标

- 同一数据划分、原始观测与缺测信息；参考正常样本仅来自训练部分。外部降雨、孔压、库水位若引入，须建立相同外部信息的独立实验组。
- 同一模型检查点和固定提示开发流程；分别记录调用数、输入图数量、令牌、延迟、费用。重复运行只用于估计随机性，预先固定次数，不能挑最佳一次。
- 使用同一评价器和验证集选参准则，各方法的阈值分别在验证集确定后冻结，不强制不同分数尺度共用同一个数值阈值。最短持续时间、平滑窗和候选扩展量也只在开发集选定。不能根据测试真实异常长度设置窗口。
- 全序列和局部窗口以同样规则生成；不得显示真值阴影、阶段名称、生成潜在曲线，或泄露类别的文件名。

建议预登记以下评价口径：

| 层级 | 指标与解释 |
| --- | --- |
| 活动事件 | 用区间 IoU 作一对一匹配；建议同时报告 IoU 阈值 0.3/0.5/0.7 的事件 Precision/Recall/F1，0.5 作为候选主阈值，在试点后冻结；多次拆分或把整条标活动不能轻易获高分 |
| 时域覆盖 | 不做 point adjustment 的逐日 Precision/Recall/F1、活动 IoU，以及每个记录的宏平均；避免长事件掩盖短事件失败 |
| 静稳误报 | 稳定暴露期内误报事件数／站年、误报天数比例、加速误报天数；固定合并相邻告警规则，避免碎片化改变事件数 |
| 特征/阶段 | 端到端逐类和 macro-F1；第一层遗漏造成的阶段遗漏必须计入 FN。若采用重叠特征，按多标签逐类评分；条件于正确活动范围的成绩仅作诊断 |
| 边界 | 已匹配事件的起止偏差、中位绝对误差和分布，同时报告未匹配率。专家给出边界不确定带时报告落带率及带外距离；不能只公布成功匹配部分的漂亮误差 |
| 未知/缺测 | 已知标签上的弃判覆盖率与风险；过度弃判不能通过排除后只算高准确率。无法评价的真值未知区单独报告暴露比例；缺测不当稳定真负例 |
| 成本 | 推理失败、预算超限、总调用/费用和实际耗时；不是仅计算成功请求 |

同一场地的测站和同一原始背景的派生样本有关联，配对差异和 bootstrap 按独立场地/背景记录分组，不按日或窗口抽样。场地数过少时，以逐场地结果和描述性区间为主，不制造虚假的精确总体置信区间。多指标与消融的主要/次要地位预先区分。

建议结果表固定为：活动事件 F1、弱活动召回、稳定每站年误报、端到端阶段 macro-F1、边界误差、弃判率和成本。不存在所有方法通吃时报告权衡，不用单一综合分掩盖损失。

## 6. 纵轴、导数与复杂情景实验

用户提出的扩大位移轴上下限可改善趋势阅读，但不是默认“越宽越好”。固定参考量程、噪声约束的自适应量程，以及其 1.5/2 倍跨度可作为预先声明的敏感性设置（具体倍数是实验选择，非文献阈值）。同时改变图像纵横比与局部图长度，检验标签稳定性、弱活动召回和误报变化。极端点造成全图压平时，保留完整量程并提供明确标示的局部图，不静默裁掉观测。

速度和加速度用原始时间/位移单位计算；图上倾角会随纵横轴缩放变化，不能直接用于固定角度判据。若比较专业切线角方法，须按原方法的归一化和适用条件实现，而不是读取截图角度。

导数图是支持证据，不能替代持续位移确认。检验多窗口一致性、导数边缘支撑不足、长缺测两侧、起止附近平滑扩散。设纯噪声、低频相关漂移、孤立台阶和离群点为困难负例；设置低速长期累计、低速加速、加速后减速与负轴方向运动为困难正例。测试中不能手工根据真值为每例挑最好看的窗口或轴域。

## 7. 在线和预测扩展的单独协议

离线回溯可以看到整个记录，但论文必须明示。当前 31/61/91 日居中鲁棒拟合属于离线辅助，不能直接做在线预警证据。

在线实验按时间前缀逐日推进，只允许使用 ≤t 的观测、尾随窗口、前缀归一化和前缀图轴；插值、沿坡方向估计、特征选取和参考样本也不得使用未来信息。分别记录回溯估计的活动起点与真正首次发出告警的日期，前者不等于提前量。

预测扩展固定同一个预测器与调参预算，比较：历史位移；历史位移＋数值活动/阶段；历史位移＋本方法自动活动/阶段。建议预测未来 7/30 日位移增量，报告整体和活动段 MAE/RMSE，时间外推时隔离跨越分割边界的目标窗口。训练阶段也需使用无测试泄漏的阶段特征，不能把专家未来可见标签输入预测器。

若无真实失稳结局，只能称位移预测或活动变化预测；逆速度失稳时刻预测仅在适用的持续加速案例中单独比较，季节性慢滑不能强行套入临滑预测。相关领域方法与限制见简报 [6–7]。

## 8. 建议的实际顺序

1. 完成独立标签定义与困难案例小规模盲标，检查概念重叠、标注一致性和边界可辨识度。
2. 冻结自动流程、强数值基线与共同评价器，在开发资料上排除明显实现问题。
3. 锁定阈值、预算和图像设置，生成未查看仿真测试并准备真实场地留出；预测扩展另列协议。
4. 一次执行主比较，按预先定义分组分析失效情形。若数值同证据基线已足够，应如实限制视觉方法的价值主张。
5. 有真实场地支持且在线特征无泄漏后，再考虑将标题或结论扩展到预测用途。

本轮仅完成调研与设计文档，没有运行这些新实验，也没有修改标注算法、数据或论文正文。
