## 已实现的契约

内部区间为 `[start,end)`；模型接口的区间包含首尾端点，显式转换。缺测保留原日历，不压缩时间、不用零填成观测。活动为确认、未确认、未知三种状态；“未确认”是标注操作定义，不等于物理上绝对静止。

阶段只评价 A 加速、S 近似匀速、D 减速。L 缓慢位移属于强度概念，不重编码为 S；本轮单独报告 L 日期的活动检出率。过渡和阶段未知不计为错误的其他阶段。第一层漏掉的 A/S/D 必须计入端到端阶段 FN。

活动逐日 P/R/F1、事件一对一最大匹配 IoU≥0.3、弱位移召回、已知日期弃判覆盖、负暴露误报和逐类/宏阶段 F1 使用共同评价器。IoU 在标签已知的日期上计算，候选边界不能算静稳；参考事件按 episode ID 合并缺测，预测事件允许桥接最多 7 日未知，不能跨过明确预测的负日。额外保存 IoU≥0.5 敏感性结果。

输出失败不变成 TN：活动失败保留全部确认活动 FN；第二层失败保留成功的第一层，阶段全部未知并计 FN，另外报告阶段失败次数。单阶段整体 JSON 不满足契约时判整个输出失败，其成绩受接口完整性影响，不能解释为纯视觉识别能力。

负暴露误报率按有明确输出的负日期换算站年，同时保存弃判负日数；不得把因弃判而未覆盖的时段解释为无误报。完整负对照另行报告，不能把混合记录中所有“未确认”活动片段都当成已知物理静稳。

## 数值与学习方法

| 配置 | 实际实现与冻结选参 |
| --- | --- |
| robust_rule | 三个不重叠 14 日观测中位数块，检查前后都持续变化且方向一致；持续至少 14 个有支撑日。验证选择速率 0.03 mm/day、信噪比 2.0 |
| pelt_rule | 各轴分别以位移为单一响应、常数与时间为协变量作 CostLinear 分段，合并边界；不用 E/U 当 N 的回归解释变量。惩罚 40、速率 0.12 mm/day；短片段或拟合支撑不足保持未知 |
| xgboost | 31/61/91 日速度、切向加速度及相对加速度，加原始位移增量/噪声/方向特征；活动树深 4、概率阈值 0.65，阶段树深 2。各 120 树、学习率 0.05、seed 20261007、CPU 2 线程 |
| robust_xgboost_stage | 完全复用 robust 活动定位，接同一个训练后的 XGBoost 阶段头 |
| ungated_rule | 与 robust_rule 同一定位与证据，允许阶段出现在活动范围外，只用于检验约束作用 |

共同阶段规则由 61 日估计得到的 60 日相对速率变化判 A/S/D，验证选择阈值 0.25。活动选择目标是验证逐日 F1＋事件 F1，不用阶段成绩挑活动范围；阶段规则另按验证 macro-F1 选择。XGBoost 阶段只在训练集中明确 A/S/D 日期训练。

所有方法都是离线回顾。数值特征使用居中窗和全记录噪声估计；视觉看到完整记录。它们不能用于证明在线预警或提前量。PELT 的事件 F1 较高，但覆盖率仅约 55%，不能因此忽略其大量逐日漏检和弃判。

## 自动视觉与消融

模型 qwen3.8-flash，temperature 0.1、top_p 0.3，每请求最多 2048 输出 token，不自动重试。原始图三轴分别展示，纵轴每轴最小跨度 60 mm，再扩展为 1.5 倍；所有视觉组使用同一规则，无逐例手工调轴。辅助图使用原始位移与 61 日拟合、速度和加速度。数值多尺度特征和视觉图的表达形式不同，不能称增加了独立传感信息。

已执行：数值定位×规则阶段、视觉定位×规则阶段、数值定位×模型阶段、视觉定位×模型阶段；另执行固定视觉定位去除全部派生图、解除阶段活动约束，以及单次视觉同时输出活动与阶段。相同定位直接复用，不为每个消融重新抽样。

接口修订保留历史，不按性能挑一轮：

1. visual-v1 的请求缺少服务要求的“JSON”字样，18 次请求均失败；另有 1 次有记录的诊断请求确认 HTTP 400。它们是接口故障，不是模型识别失败。
2. visual-v2 修正 JSON 声明：36 次调用、156225 token、约 91.1 秒；9 次阶段契约失败都是相邻闭区间共用一天，例如 `[240,265]` 和 `[265,315]`。原输出没有裁剪、排序或用真值修复。
3. visual-v3 只增加闭区间相邻端点示例，第一层定位直接复用 visual-v2 缓存；数值预测、标签、划分、评价规则均冻结。重新调用阶段头和单阶段组，不把两轮成绩差异解释为该一句提示的因果收益，因为模型输出也有随机性。

visual-v3 实际新增 30 次请求、143363 token、约 85.4 秒；仍有 2 次失败：case_0007 数值定位→模型阶段越过确认范围，case_0023 单阶段输出仍共用边界日。视觉定位→模型阶段本轮 6/6 通过契约。两轮有效响应调用共 66 次、299588 token；另保留上述 19 次接口故障/诊断请求，不能将其成本隐去。这里只报告 token 和实测时间，不使用未核实单价换算费用。运行时间包含服务与渲染，数值运行复用了先前计算的辅助估计，因此约 9 秒的本次数值耗时也不是从原始输入开始的完整成本。

阶段失败计数和原始模型输出与识别指标一起保存。visual-v2 单阶段组有 5/6 契约失败，因此其 0 分不能用于证明两阶段架构优越。

取消模型阶段的活动约束后 macro-F1 反而较高，不能只选择有利的数值规则消融来宣称约束普遍有效。固定视觉定位下去辅助图的差异区间跨零，也未证明辅助图稳定有益。模型与 XGBoost 的训练信息不同：XGBoost 使用本批训练标签，视觉组没有训练样例；这是监督方法与无需本地监督训练方法的比较，不能据此推断模型家族本身的绝对优劣。

后续[准确率路线核查](landslide-accuracy-review.md)检查发现：本次 `visual_model_ungated` 六例均没有在预测活动范围外输出确定阶段，同一输出重新施加活动门控后 macro-F1 完全不变，仍为 0.5129749487。因此该组更高的成绩不能解释为门控裁掉正确阶段；本次观察到的是范围内阶段划分随提示和独立调用发生变化。原消融和主表保留，不据此改动冻结成绩。

鲁棒规则活动逐日 F1 为 0.916，XGBoost 为 0.902，视觉定位为 0.869。视觉定位将确认活动漏检从 199 日减少到 90 日，但引入 272 个参照标签负日上的活动误报。三个定位器均漏掉仅有的 81 个缓慢位移参考日。视觉定位案例仍会跨过中间平台，活动定义的文字说明尚不足以稳定约束它。

本轮不能宣称“视觉流程优于传统数值/机器学习”，也不能宣称弱位移性能得到改善。数值规则取消活动约束后，参考负日上的虚假加速从 0 增至 111 日，阶段 macro-F1 从约 0.753 降至 0.697；同时也必须报告带约束版本的活动 FN=199，而不能只展示误报减少。

按完整记录做 2000 次配对重采样，仅供探索。视觉定位相对数值定位的逐日 F1 差异 95% 百分位区间约为 [-0.178, 0.078]。六条记录和一个弱位移案例不足以支撑确认性统计；不能将日数当独立样本量或把该区间解读为跨场地证据。
