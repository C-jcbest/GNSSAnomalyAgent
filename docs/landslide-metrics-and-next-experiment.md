## 当前计算方式

依据 `src/gnss_sim/landslide_evaluation.py` 的 evaluate_case、match_events、aggregate_scores。先对每例计数，再跨六例累加 TP/FP/FN 后计算分数；不是六例 F1 的算术平均。

共同公式为 Precision=TP/(TP+FP)、Recall=TP/(TP+FN)、F1=2TP/(2TP+FP+FN)。分母为零时返回 null，不伪造满分或零分。阶段 macro-F1 对有定义的类别 F1 作算术平均；本次六例合并后 A/S/D 三类均有参考支持。

### 活动逐日 P/R/F1

- TP：参考确认活动，预测确认活动。
- FP：参考非活动，预测确认活动。
- FN：参考确认活动，预测未确认或未知。
- 参考未知/缺测日不参与 TP/FP/FN；预测未知不当 TN。参考非活动日上的未知输出既不计 FP，也不算正确负例，需另报覆盖。

评价组共有 6570 日，其中 5080 日活动标签可评分：1287 个确认活动日、3793 个非活动日；1490 日参考未知/缺测。标签“非活动/未确认”是观测操作定义，不等同于证明物理绝对静止。

例如固定旧视觉门控 TP=1197、FP=272、FN=90，Precision=0.815、Recall=0.930、F1=0.869。局部定位 TP=1196、FP=444、FN=91，F1=2392/(2392+444+91)=0.817。

### 活动事件 F1

参考事件按 episode_id 组成，预测事件按确认活动的连续区间组成；预测可桥接最多七日未知，不跨过明确预测的非活动日。IoU=交集日数/并集日数，仅在参考标签已知日上计算。

当前按 IoU≥0.3 做一对一最大匹配；匹配数为事件 TP，未匹配预测为 FP，未匹配参考事件为 FN。一个大预测区间最多匹配一个参考事件。完全位于参考未知日上的预测事件另计，不判为假事件。

0.3、七日桥接和参考 episode 定义不是统一行业标准。事件指标也不会逐日处罚已匹配区间中过长的平台：本轮局部定位事件 TP=10、FP=0、FN=2、事件 F1=0.909，却有 444 个逐日 FP。两者回答不同问题，事件 F1 不能独立代表边界准确。

### 端到端阶段 macro-F1

确定演化类别为 A 加速、S 近似匀速、D 减速。每类按一对其余类别计数，再对三类 F1 等权平均。参考非活动日输出任何确定阶段会成为该类 FP；第一层漏掉真实 A/S/D、阶段弃判或失败都会成为相应 FN。

本次 A/S/D 参考支持为 443/42/381 日，共 866 日；3793 个参考非活动日也用于处罚阶段 FP。其他 421 个确认活动日为弱位移、过渡或阶段未定，不进入 A/S/D 分类评分。低速强度与速度演化不是同一标签轴，81 日弱位移不自动视为 S。

视觉门控＋XGBoost 的 A/S/D F1=0.806630/0.552632/0.922426，因此 macro-F1=0.760562。其 A 类 TP=438、FP=205、FN=5；205 日虚假加速已计入 A 的 FP，没有从主分数中排除。另列它是因为阶段平均不能充分表达稳定期加速误报风险。807/866 的明确阶段正确日比例约 93.2%，它不是 macro-F1。

| --- | --- | --- |
| 弱位移召回 | 预测活动命中的 slow_displacement 日数 / 参考弱位移日数 | 当前 0/81，仅一个弱段，不能代表总体 |
| 活动覆盖率 | 1 − 参考已知日上的预测未知日数 / 参考已知日数 | 它是决定覆盖率，不是准确率 |

例如视觉门控组负日活动误报比例为 272/3793≈7.17%；视觉门控＋XGBoost 虚假加速为 205/3793≈5.40%，在本批参考负日上定义。数值门控＋XGBoost 为零，但其活动覆盖率约 88.3%，且漏检 199 个活动日，不能把弃判日期算为已证实无误报。下一轮同时报告完整参考负暴露、决定负暴露和覆盖；本批覆盖型仿真比例不能直接外推现场告警可靠性。

以下采用项目保存的原文及元数据缓存，核查范围限定为列出的版本及相关段落，不代表完整最新综述。

| 原论文 | 核查到的评价方式 | 与当前结果的关系 |
| --- | --- | --- |
| [TAMA v1](https://arxiv.org/html/2411.02465v1)，Table 1、§4.1、Appendix A.2/A.6 | 主表 point-adjusted F1、AUC-PR、AUC-ROC；另检验 PA 阈值，并在类型分析使用不做 PA 的 F1 | 当前逐日 F1 不做 PA，不能与主表 PA-F1 直接比较；可在共同数据和标签下统一重算 |
| [AnomaMind v2](https://arxiv.org/html/2602.13807v2)，Appendix D-B | F1、Best-F1、AUC-PR、Range-F1 | 标准 F1 公式相同；阈值、聚合和 Range-F1 实现需对齐。本项目不是它的 Best-F1 或 Range-F1 原实现 |
| [Tatbul et al., 2018](https://papers.nips.cc/paper/7462-precision-and-recall-for-time-series)，§4 | 带存在性、覆盖、位置和多段匹配设置的范围 precision/recall | 本项目的一对一 IoU 事件 F1 不等于该 Range-F1 |

| [Kim et al., 2022](https://doi.org/10.1609/aaai.v36i7.20680)，§1、§3 | 讨论 PA 会让单点命中变成整段成功，并导致随机分数获得虚高结果 | 支持当前不做 PA、保留逐日误报与漏检的选择 |

论文缓存为 `artifacts/fusion-research-2026-10-01/phase2_sources/{tama,anomamind}.txt/html/json` 与 `artifacts/literature-review-2026-09-30/phase2_evaluation/`。TAMA 官方固定版本评价源码也保存于 `artifacts/reproducibility-audit-2026-10-07/sources/file-tama-evaluation_py.raw`，其中同时存在调整与不调整路径；不能只按函数名称认定一次运行采用哪条路径。

P/R/F1 属于通用检测指标，macro-F1 属于常用多类别分类指标；具体滑坡长期活动和 A/S/D 阶段协议是任务适配。位移预测论文的 RMSE/MAE 和失稳时刻预报的时间误差属于其他任务，不能放在同一排行榜。

正式比较建议保留当前无 PA 的逐日 P/R/F1、逐类及 macro-F1，另报 IoU≥0.3/0.5/0.7 的事件敏感性和记录等权结果。是否增加 Affiliation 应先确定参考未知日处理和原实现语义；若需 AUC-PR 或 VUS，必须有可排序的连续分数及合适定义。当前视觉输出只有硬区间，不能伪造概率以凑 AUC。Best-F1 的阈值扫描若使用测试标签，只能作为标签辅助的诊断，不代替验证集冻结阈值的部署成绩。

## 下一轮改进：先定位瓶颈，再固定阶段头

当前两个最明确的问题是 81 日弱段全漏，以及活动后平台被门控接纳。下一轮优先比较“数值候选→数值确认”和“同一候选→视觉＋数值证据确认”。它能检验视觉在确认环节是否提供额外收益，不要求视觉第一步必优。

1. **补独立数据与标注。** 当前验证组没有弱位移，评价组只有一个弱段、42 日 S，不能可靠校准这些目标。按完整背景记录/场地分组，增加弱运动、真实匀速、平台、相关漂移、仪器跳变、季节波动与再活动；复核原始位移后才定活动，再标演化阶段。已有查看记录只做开发。
2. **增加长尺度累计候选，保持确认严格。** 在原数值候选之外检验较长窗口的累计位移、稳健斜率和分块持续变化。更长窗可能使弱运动累积可见，也可能吸收漂移；不把候选直接转为活动。窗口和门槛只在训练/验证上选择，不用本批唯一弱段挑最佳设置。相关 GNSS 误差下不套独立白噪声置信区间。
3. **针对候选窗口给可核查证据。** 提供未标注的原始位移局部图、全局上下文、分块中位数、首尾位移差和多尺度斜率，并要求返回确认/不确认/未知。图和数值来自同一观测，不称为独立传感证据。所有候选同样处理，不只选择已知错误窗；先按原始位移确认，再允许判阶段。
4. **阶段允许弃判并核对时序。** 暂时固定保存的 XGBoost 和规则阶段头。活动平台问题应由活动确认器处理，三类阶段头不能承担非活动拒绝。对低速、支撑不足或阶段冲突先保留未知；阶段置信门槛和时间一致性方法另在训练/验证上冻结。不强制 A→S→D 固定循环，也不把低速自动判为 S。

最小受控设计是固定同一候选、同一阶段头，对比“候选直接输出／数值确认／视觉确认／视觉＋同源数值确认”。再用固定的确认器比较原候选与长尺度扩展候选。分别检验确认证据和候选召回，避免同时改所有模块后无法归因。数值活动＋XGBoost 保留作强基线。

选择参数时采用共同的验证误报约束，再比较召回与阶段成绩；误报约束预先记录，不为得到本批高分后选。主表同时列逐日 P/R/F1、负日误报比例与暴露、弱段召回、端到端 macro-F1、虚假加速、覆盖、失败和成本。边界标签保守且有未知带，不能把确认内部起点当物理精确起变；在可确定边界上评价误差，对不确定带另报覆盖/距离定义。

上述为下一轮建议，没有执行新效果实验。在线预警另做时间前缀和尾随窗；当前全记录图及居中导数不支持无泄漏提前量结论。
