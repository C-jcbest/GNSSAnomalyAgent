# EXP04结果与EI论文使用建议

**GNSS-VLM-EXP04-v1：GNSS形态分工视觉数值融合异常识别实验**已完成。
论文主方法对应 `morphology_fusion`，主指标为**四类等权日F1**。
当前材料支持围绕GNSS多形态分工撰写方法、对比实验与消融章节，
无需把“所有模块、所有指标全面领先”作为本轮实验目标。

而是先汇总每类计数再四类等权。

本轮最清晰的新增收益是**尖峰精度恢复，同时保留视觉处理阶跃和暂态的收益**。
尖峰有13个可观测真事件：排名融合TP/FP/FN=9/24/4，新方法=6/0/7，
减少误报的同时漏检增加。阶跃有15个可观测真事件，新方法=4/6/11。
不把这一结果扩写为各类召回全面改善。

9个评价期无可观测真异常的站上，新方法0段误报；排名融合为1.3753段/站年，
数值为.2292。9站包含8个normal机制站和1个尖峰恰缺测的站。
这个结果可作为站点尺度自适应、质量异常分工的辅助论据，仍仅限模拟站点。

## 消融给出的简化方向

主种子24站：完整方法等权日F1=.4997；去局部图=.5834；
去显式数值建议=.4344（2次失败计入）；固定数值活动边界=.5316。
两个种子合并，固定数值活动边界变体等权日F1=.5816，高于完整方法.5681；
活动事件F1均为.6667。**本轮不支持局部放大图或视觉边界修正有稳定正增量**。

活动边界修正仍有特定作用：16个含活动站共1754个可观测活动日，
数值/固定边界/完整方法停止后的假活动日分别295/202/0；
活动漏日分别530/628/856，活动前假日分别8/8/37。
它适合说明停止后过标与漏检之间的取舍，不能写成活动总体F1全面改善。

EI论文可以围绕“形态分工”作为核心，并把固定边界、去局部图作为简化变体如实报告；
明确各自是哪些站、哪项指标、何种消融结果，无需硬说完整结构最佳。
尤其不能把24站去局部图的.5834与48站主方法.5681当成相同样本比较。
若论文选用某简化变体，应说明选择依据，保留这里冻结主方法的身份与完整表格。

## 多种F1如何用于论文

正式主指标在24验证站上比较后选定，已先于新测试冻结。
四类等权日F1最适合支撑多形态识别，四类等权事件F1为配套结果；
具体场景可突出尖峰、暂态等F1，保留完整四类矩阵。
通用日F1也可以报告，固定边界变体在该指标为.7734，但不可把变体分数写成完整方法分数。
±3日容差是辅助定位指标，不改变严格F1；本轮主方法两种点的容差分数与严格分数相同。
不使用PA或真值选阈值来放大得分，不将不同论文的不同数据/指标数字直接排成同一对照。

建议论文题目：**融合数值形态候选与视觉大模型的GNSS多类型异常识别方法**。
英文工作标题：*GNSS Multi-Type Anomaly Detection with Numerical Morphology Candidates and a Vision-Language Model*。
可以陈述：在简单日NEU模拟、站点内正常参考和多形态并存的条件下，
按形态分配数值与视觉判据，提高了相对数值及统一点候选视觉融合的四类等权F1。
VisualTimeAnomaly、VLM4TS和TAMA作为近期方法参考；按粒度分工已有先例，
GNSS细化与实验是当前贡献，不宣称通用机制首次提出或完整SOTA复现。
