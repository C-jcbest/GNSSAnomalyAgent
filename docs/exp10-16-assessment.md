## 机制诊断与来源边界

EXP10/13放大视觉对所有水平事件的改写权限，误删已有正确暂态/阶跃；
EXP11/12全站活动判别把背景漂移误认为新增活动，或漏掉已有真实活动；
EXP14局部曲线仍被读反；EXP15简单向量图降低了部分错误，但正式批仍有符号/候选ID推理错误。
模型响应和失败不能通过再次请求选择性覆盖。4次上下阶跃简单图输入诊断均正确，
只证明简单图像可读，不能据此认定复杂图形已正确理解，也无法独立验证代理后端权重。

实际实读论文、作者代码及不能访问的全文见[阅读笔记](exp10-reading-notes.md)。
VisualTimeAnomaly、AnomLLM、TAMA、VLM4TS为不同工作，不能混名或借用其成绩。
本轮没有完整执行其作者管线，因此没有任何“超过这些论文原法”的新实验结论。
VisualTimeAnomaly作者README年份与精确Crossref记录冲突已单列；不能继续无条件称WWW2025。

## EXP16第二开发批与最终决定

首批1505无主方法请求，保留0.8736零增量记录；在第二批生成前登记1508的
96训练/48验证方案，扩大观测机会，不按真值筛站，不读取测试分区。
第二批4站有可配自由边缘，主方法与两消融各4次，原SDR8次，共20次新请求。

| 同站48开发站方法 | 四类日F1 |
|---|---:|
| PSC-VLM / pair_overlap | 0.7866 |
| pair_text，相同起跳/取反返回数字文字 | 0.8123 |
| vector_nearest，未调参数值规则 | 0.8360 |
| 同模型原SDR / pair_focus_repair | 0.7942 |
| 原数值分解 / segment_numeric | 0.7644 |

视觉相对数值+0.0221，但相对原SDR-0.0076、文字-0.0257、近邻-0.0494，
未通过预设条件，取消集成；1506/1507未生成、未调用，不填正式结果。
这一批是开发，不与EXP15两批正式站拼成新主实验，也不能称独立验证了所有方向。
EXP16使用user-only提示组织，按Qwen官方建议作显式适配；主/消融一致，
但与EXP15差异不仅是图像，因此不能把跨实验差值全归因叠合图。

进一步4次简单三行条形图诊断：两张改变正确候选位置的图，在plain与json_schema
两种输出下均4/4选对；没有证据支持“结构化格式让模型完全不读图片”的解释。
这同样不是GNSS准确率样本，简单图全部正确不排除实际图像解释及候选关系推理失败。

本轮共267实际请求，其中8次简单输入诊断，5次失败保留、无重试；复用控制不重复计数。
52业务测试通过，Ruff通过；生产源码逐字节仍与4495ff0相同，论文稿保留。
完整本地归档与逐请求SHA见[证据清单](exp10-16-evidence.json)。

当前能支持的结论是局部三分量变化表示有用，尚不能支持视觉比文字或简单配对更优。
不将效果更好的vector_text/nearest换名为视觉创新。若继续研究，优先寻找视觉能使用
而现有单站数字规则尚未充分使用的任务上下文，例如有真实依据的邻站一致性和质量元数据；
这仍是未执行方向，需要实际数据与明确标注，不能从独立模拟站虚构空间关联。
在现有单站简单仿真上继续反复换提示，已缺少比新增领域证据更强的收益依据。
