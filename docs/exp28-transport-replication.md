# EXP28：传输故障后的显式独立技术复测

首个test运行visual-v1的前60站共51次请求全部ConnectError、无HTTP状态，已保存原始失败与回退评分。
随后同接口GET /models成功，两次不含异常数据的Flash/VL健康检查均HTTP200。
短时故障的具体网络根因未确认；不把这51次失败解释为方法没有识别能力。

采用visual-v2独立运行目录，逐字节复制同一冻结方案的请求，逐一验证SHA相等，
不修改提示、模型、图、候选、阈值、解析或后处理，不覆盖原始v1失败，不从多次成功响应挑分数。
v2是技术复测，不是新生成的未见测试数据；首60站已做过回退评分，这一事实必须披露。
后300站v1仅准备输入、不执行请求；v2对其执行一次模型推理。
最终主测试表来自完整v2，v1的51次连接失败与2次健康检查成本单列，全部保留。
不更换主方法或根据已见test回退分数改变实验设计。
