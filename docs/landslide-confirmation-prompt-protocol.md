## 问题与受控因素

上一轮两组29份成功非空回答全部沿用候选起点，且平台误报进入加速阶段。本轮检验两个因素：去掉“已发现候选、进行确认”的任务暗示是否改善内部起变定位；在中性说明下加入固定时间块的可见观察和首次活动位置是否进一步改善。

固定上一轮六条记录、全部17个候选、每次两张实际原始输入PNG、纵轴及上下文、模型参数、XGBoost阶段头和评价器。不重跑72次单窗定位，不使用信号数字、导数、参考标签或上一轮回答帮助确认。静稳case_0015无候选但仍完整评分。
