# GNSS-VLM-EXP04-v1：GNSS形态分工视觉数值融合异常识别实验

2026-10-13完成验证后、生成正式新测试前冻结。主方法：`morphology_fusion`。
沿用[开发方案](experiment-exp04-development.md)的模型、数据、参数和方法，未调整阈值或提示。

## 定位与冻结选择

面向EI论文的GNSS领域方法研究，检验特定异常和指标上的可解释收益。
不要求全面优于所有方法，不把现场数据设成本轮仿真完成的前置条件。
新方法为数值尖峰、排名视觉阶跃、原始位移视觉活动边界；具体实现不是论文原码。

先6验证站18请求，再互斥的18验证站18请求。完整24站验证：

| 方法 | 四类等权日F1 | 四类等权事件F1≥.5 |
|---|---:|---:|
| 数值 rf_split_temporal | .3897 | .4533 |
| 自由 guided_fusion | .5301 | .5348 |
| EXP03 ranked_boundary_fusion | .5477 | .5611 |
| 新 morphology_fusion | .5560 | .5694 |

正式主指标选择**四类等权日F1**：逐类汇总全站TP/FP/FN算F1，再四类等权平均。
它符合多形态识别目标，验证上也比事件macro给出更大的数值对照差值。
这项选择发生在验证之后，明确是开发选择；正式测试后不按更高分更换主指标。
事件macro、通用日F1、各类日F1与事件IoU≥.3/.5、点±3日容差全部报告。
失败零检测、缺测排除、不做PA、不根据测试真值挑概率阈值。

## 新测试与对照

两个新数据种子2026101302/2026101303，各96训练、24验证、24测试；
本阶段只用各自训练分区拟合、测试分区评价，不使用这两组验证标签选参数。
RF随机种子固定2026101301，候选数及窗口不变。
总共48独立模拟测试站，两个种子每种场景合计8站；每站730日，正常前缀365日。
开发用过的种子及EXP01–03所有已用测试均不进入正式新测试。

| 方法行 | 作用 | 实现身份 |
|---|---|---|
| random_forest / extra_trees | 常用监督对照 | sklearn默认分类器+本项目GNSS特征 |
| rf_balanced | 不平衡类别对照 | 显式class_weight=balanced适配 |
| isolation_forest | 通用异常对照，只报通用指标 | sklearn默认判决，正常前缀拟合 |
| rf_split_temporal | 无视觉对照 | 本项目48/30特征分工+训练侧Viterbi |
| visual_only | 无数值候选的纯视觉对照 | 本项目GNSS提示、相同qwen模型 |
| guided_fusion | 候选辅助的自由视觉判断 | 本项目EXP02输入协议 |
| ranked_boundary_fusion | 两类点都用排名视觉 | 本项目EXP03方法 |
| boundary_numeric_points | 两类点都用数值 | 点类型分工对照 |
| morphology_fixed_activity | 只取消活动边界修正 | 与主方法同响应，其余规则相同 |
| morphology_fusion | 数值尖峰、排名视觉阶跃、视觉活动边界 | 本轮主方法 |
| morphology_no_local / no_scores | 去局部图 / 去显式数值建议 | 主种子24站信息消融；后者仍数值选窗 |

主种子包含guided两项输入消融，共4组视觉输入×24站=96请求。
第二种子guided与visual_only两组×24站=48请求；相同响应派生不额外请求。
沿用qwen3.8-flash、temperature=0、单请求120秒且无自动重试。
两批并行时总网络并发至多3（主批2、次批1），按批保存全部响应和失败。

## 论文使用边界

当前正式对照为实际执行的库方法与本项目视觉方法，不借原论文表格分数声称SOTA领先。
VisualTimeAnomaly原作者prompt/API和原parser已在EXP03执行且适配失败较多，
历史[作者原码/适配对照](../results/exp03-main-v2/results.md)单列，未混用测试站。
完整VLM4TS、TAMA、GNSS TimesNet本轮未执行，不填成绩。
近期论文的结构/方法/评价实读依据见[literature](literature.md)的EXP04段。

普通库默认判决、balanced修改、训练转移Laplace+1、排名2/2/1/1与固定选窗规则均披露；
不设统一mm或mm/day物理告警阈值，不宣称“完全无阈值”。
允许位移活动和质量异常共存；平台不属于持续活动；不输出内部阶段。
成对bootstrap作为描述性补充，条件于已拟合模型，不作为本轮结果必须跨越的门槛。
