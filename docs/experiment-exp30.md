## 图像、提示与流程

粗筛使用三个重叠窗口[365,544]、[485,664]、[605,729]，每张1400×900、三轴垂直面板，
本站正常历史MAD归一化、原位移居中，原始缺测保留。原点线与3日中位辅助线同图。
同一请求给三张图，不按场景或真值选窗口。文字粗筛提供相同窗口的全部原始点。
粗筛最多两区域，要求可观察形态说明，允许只定位未确定的变化与返回疑点，不要求当场确立完整暂态。

每个区域向两侧各扩35日并裁到监测区间，局部图1800×1000、三轴原位移，不带候选ID、
真值着色、机制名或预期数量。模型允许重提任意裁剪窗口内的起止；结果区分confirmed/uncertain。
确认暂态须检查起点、持续内部、返回及受影响分量；不是对给定候选ID投票。
独立阶跃、连续形变和暂态可以叠加。不输出形变内部阶段。

数值证据仅为已有segment_numeric在窗口内的阶跃日期及三轴变化向量，明确可错，不显示数值最终暂态标签。
主方法使用数值证据，无数值消融删除此证据；不新增局部阈值或调参。
confirmed原日期与近邻作add-only融合，沿用EXP29 compose；重叠范围不覆盖原结果。
同时保留纯视觉暂态结果，报告融合遮蔽及候选重复；不暗中合并新范围或改变旧事件。

## 对照与方法键

| 方法键 | 流程与要隔离的因素 |
|---|---|
| `air_image`（主方法） | 图像粗筛→局部原图重新定界＋数值证据→近邻互补 |
| `air_image_pure` | 同一主方法局部confirmed范围，不加入近邻；只输出暂态，四类分数不用于评优 |
| `air_global` | 相同图像粗筛、相同区域元信息与数值证据，同轮数第二次查看原EXP29全局图；不提供局部图 |
| `air_text_final` | 相同图像粗筛、相同局部原始点及数值证据，第二轮用文字，隔离终轮图像作用 |
| `air_text_pipeline` | 两轮均文字，各自粗筛区域；隔离整条图像流程贡献 |
| `air_image_no_numeric` | 相同图像粗筛与局部图，删除数值阶跃证据；隔离数值取证贡献 |
| `vrc_image`、`vrc_text` | EXP29原图/文字、原提示、原流程在新数据重跑；不是历史分数跨集比较 |
| `vector_nearest`及六数值方法 | 原默认与GNSS适配身份沿用EXP28，无新增拟合或阈值调整 |

粗筛及局部均为qwen3-vl-plus，temperature0，enable_thinking=False，沿用既有接口配置，
不改.env。全局对照匹配调用轮数和区域，不能称精确匹配token预算；实报图像数、token与耗时。
最多两个区域即最多两次局部请求/站/变体，属于披露的GNSS适配资源参数，不是作者默认值。
粗筛失败/空则不请求局部；各局部失败保留其余成功结果，回退近邻而不算推理成功。
请求并发3、120秒、无自动重试；所有请求、原始响应、失败与来源SHA保留，登记运行不覆盖。
