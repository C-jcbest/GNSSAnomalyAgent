# GNSS-VLM-EXP04：GNSS形态分工视觉数值融合异常识别实验

开发协议：2026-10-13，development-v1。主方法报告行为 `morphology_fusion`。
目标是面向EI论文的GNSS方法研究：证明清楚定义的场景或指标上的改进，
不要求所有异常、所有指标全面领先，不把现场验证作为本轮仿真完成的前置条件。
所有新结果均保留，不以发表定位降低文献与结果的真实性要求。

## 方法与研究依据

EXP03暴露出排名视觉确认的尖峰误报多、数值阶跃漏检多。
本轮固定按形态分工：尖峰使用 `rf_split_temporal` 的数值分类票决；
阶跃使用其前两名间隔候选与视觉同日同类确认，不要求RF阳性；
持续形变使用与数值活动有可观测交集的视觉原始位移边界；
暂态使用数值所选局部窗内的视觉起止。允许多类共存，缺测不赋确定标签。
视觉失败时整个融合计失败及零检测，不选择性回退以掩盖失败。

不改EXP03的特征、RF参数、21日点窗、排名数量2、22日候选间距、
正常参考、提示、模型或单次调用协议。模型 `qwen3.8-flash`，temperature=0，
不自动重试。没有跨站点统一毫米/速率告警值；仍有公开的统计参数与排名预算。
训练96站、正常历史365日、总长730日，六场景与简单噪声保持既有生成器。

2026-10-13继续实读缓存全文：VisualTimeAnomaly §2、§6.2–6.3已经明确传统方法
处理细粒度点异常、视觉模型处理区间的互补分工。本项目不主张该通用思想首次提出；
贡献定位于GNSS尖峰与阶跃进一步分工、多类可共存、位移停止边界修正及其验证。
VLM4TS附录报告contextual F1与扫描阈值的F1-max；TAMA报告PA-F1。
这些指标与本项目逐日/一对一事件F1不是同一量，不能直接引用原论文分数作本表对照。

## 小批与开发流程

新数据种子2026101301，训练随机种子2026101301。
先首6个验证站，三组输入 `guided_fusion/no_local/no_scores` 共18次请求。
小批可执行且未暴露需要修改的方法问题后，继续其余18个验证站的
`guided_fusion`，共18次请求。两组是互斥验证站，合并为24站开发结果。
测试分区在本开发阶段不评分。不得把EXP01–03已用测试种子称作新测试。

同响应派生对照：`ranked_boundary_fusion`（上一轮）、`boundary_numeric_points`
（两种点都交给数值）、`morphology_fixed_activity`（仅取消视觉活动边界修正）。
小批信息消融为 `morphology_no_local/no_scores`；no_scores仍由数值选窗。
数值对照包含默认RF、balanced RF、ExtraTrees、时间解码RF与IsolationForest。
纯视觉 `visual_only` 在正式测试加入。上述库/自研对照不冒称完整SOTA源码复现。
VisualTimeAnomaly作者原码/适配的既有实验与失败记录保留，不混入EXP04新站样本。

## 指标选择与完整披露

候选主指标：四类等权日F1、四类等权事件F1（IoU≥0.5）。
先分别汇总每类全站TP/FP/FN，算每类F1，再对四类取算术平均；
不是站点macro，不让持续活动的天数淹没少量尖峰/阶跃。
在24验证站上比较后，结合形态识别目标选择主指标并在正式新测试前冻结。
这属于验证阶段的指标选择，不伪称最初已预设，不根据正式测试成绩再替换。

完整报告还包括：通用逐日micro-F1、各类逐日F1、事件IoU≥0.3/0.5、
尖峰/阶跃±3日容差F1（辅助定位指标）、precision/recall及正常站误报。
所有方法使用同一评分；不使用point adjustment或测试真值挑最优阈值。
正式测试不要求扩大到全面SOTA检验；优先完成两个新种子共48站及一批必要消融。
