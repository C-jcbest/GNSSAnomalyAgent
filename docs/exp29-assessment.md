# EXP29：视觉先行定位、复合流程与范围互补

本轮以视觉是否产生强数值以外的实际检出为目标。近期论文支持视觉粗定位、工具取证与再次视觉核验，但增加步骤或扩大视觉决策权不必然改善。原预选 VFN-GNSS、联合边界 S1、三阶段终审 S2 均未达到各自开发采纳条件；保留原负结果。原已列出的去硬否决变体有开发范围收益，另登记 S3 独立确认，不将补充结果改写为原主方法成功。

## 数据、来源与实验身份

新720站，三种子各120开发和120test，每站730日、365日正常历史，六场景均衡。原简单机制不改、无复杂新噪声。训练只复用 EXP28 的96站模型，没有重训或按test改参数。本站正常历史MAD用于相对缩放，不引入跨站毫米/速率阈值。模拟机制真值不是实测专家金标准。

主VL模型在开发前根据EXP28已知图像消融选定；Flash在60站小批作模型敏感性。图像1800×1080，原始三轴日序列分成两个重叠窗口，原点和3日中位辅助线同图；匹配文字给相同逐日原始点。首轮不给数值事件、候选ID、真值、场景名或异常数量。

实际读取的近邻为 AnomaMind、TimeRLM、DAST、SAGE、TimeEvo 及 VisualTime/TSAD-Agents，指定版本、作者代码读取范围和提交见[文献笔记](exp29-reading-notes.md)。这些论文支持流程设计，不能把agent本身称作本项目唯一新颖点；本轮未执行其完整作者框架，不填写其GNSS分数。[方法键与指标](exp29-methods-and-metrics.md)逐项标明适配身份。

### 实际新增检测与Aff变化分开核算

图像TP/FP/FN为3815/381/384，近邻为3805/227/394，文字为3805/432/394。图像相对近邻仅 **3站补回10个真实异常日**，同时27站增加154个FP日；无真暂态站的FP由0增加到73日，文字为92日。“无真暂态站”包含其他异常类型，不等于全正常站。阳性站空预测从8站减到3站，其中2站的新预测并未触及真异常日，也会提高Aff。

Aff主指标是有真暂态站的宏平均，不纳入无真暂态站的误报；其距离评分还能奖励邻近预测。因此它适合描述范围接近程度，须与日P/R/F1、真实恢复日和负站误报同时报告，不能将全部Aff差值解释为实际检出。逐站核算见[贡献审计](../results/exp29-s3-test-full-v1/contribution-audit.json)及[正反案例](../results/exp29-s3-test-full-v1/cases/cases.json)。

- [e0075](../results/exp29-s3-test-full-v1/cases/e0075.png)：真实暂态[539,577]，近邻漏检，图像补回7个TP日、增加6个FP日；仅覆盖起点附近，没有恢复完整范围。
- [e0011](../results/exp29-s3-test-full-v1/cases/e0011.png)：预测在真实起点旁边，TP不增加、FP增加1日，Aff却增加约0.8863。保留这个反例以说明指标语义。

长期形变没有新增视觉收益：图、文字、近邻均为形变Aff 0.9458、日F1 0.9146。范围联合Aff图0.9765、近邻0.9753、文字0.9723；一般异常日F1图0.9322、近邻0.9343、文字0.9285。不能将暂态的局部范围收益推广为所有GNSS异常类型的收益。

## 本轮决定与后续重点

本轮完成新720站开发/测试，复用独立96站训练模型；共1659次真实模型请求，全部HTTP200，1615次成功、44次输出失败，0隐式重试、0传输失败，失败按登记规则计入。全套81项测试通过，新增脚本Ruff通过；原始响应、负结果、协议、文献和数据均归档。此test现已使用，后续不能再称未见。

已有论文提供视觉先行和工具循环的依据，但本轮实测说明增加视觉权限、工具或轮次本身不是收益。当前最有证据的视觉作用是**数值之外的暂态范围补漏**，并伴随误报增加。下一轮优先研究“保留视觉自主候选，仅由局部数值证据表达不确定性”的轻量选择，重点解决新增FP，而非再次覆盖已有正确配对；可对局部放大后的原始曲线与独立阶跃解释做匹配消融。上述均是待验证方向，没有新成绩，不在本test选门槛。写论文时可围绕有限范围互补与多指标取舍展开，不能将智能体流程本身或本轮结果写成全面领先。
