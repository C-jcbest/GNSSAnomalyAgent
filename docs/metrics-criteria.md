# 指标定义与结果评判标准

检测目标是带N/E/U分量的异常观测点和时间段；数值与视觉可独立检出，合并后按日期×分量去重。注入形态及质量/形变分组是事后分析，不是检测器必须预测的成因类别；不以另一分支未检出否决候选。未知背景限制现场准确率的解释，但不阻止如实报告受控注入定位与全窗报告量。

计算版本 **observed-cells-v1.1**，运行诊断 **runtime-diagnostics-v1**。2026-09-23精简说明，公式、字段、网页和历史结果不变。当前仅每日15点、180日窗口，协议见[日预实验](daily-pilot-protocol.md)。

## 适用范围与论文比较条件

当前标签只覆盖额外注入，F1衡量**注入掩码一致度**。未注入位置未经独立正常认证，不能将掩码外预测都解释为现场误报。原集六窗的144派生输入及仅原生缺测集的36个子集案例，都不是相应数量的独立来源；开发两窗同组。AI背景审核并非独立密集真值；SCWM仅开发辅助，不算逐日P/R/F1。

正式方法比较须同时满足：可信背景/标签及来源哈希；同源派生隔离、参数在测试前冻结；各方法使用同一数据、案例、观测掩码和指标口径；预期案例×方法×重复全部落盘，保留失败与不足。纯合成demo、limit小试和未完成运行只作工程或临时描述。数据完整、记录齐全不等于科研验收通过。

质量异常、形变模拟、原因未定分开报告。当前日注入语义：尖峰/波动为质量，缓慢增长drift/加速为形变模拟，台阶未定；不追改历史小时manifest，不将形态直接解释为真实成因或滑坡事件。

## 计分单元与掩码

基本单元为一个采样位置×一个分量N/E/U。180日三轴完整时为540单元；sampling_hours决定时间单位，当前是日，历史小时结果分表。start/end均包含端点，channels决定分量，不做point adjustment。

令O为实际观测、Y为注入真值、P为预测掩码：

```text
TP = count(O AND Y AND P)
FP = count(O AND NOT Y AND P)
FN = count(O AND Y AND NOT P)
TN = count(O AND NOT Y AND NOT P)，仅对status=ok统计
```

在开发预实验中NOT Y仅表示未被注入标签覆盖；FP/TN保留计算定义，不作现场误报/正确阴性解释。

- 检错分量同时造成目标分量FN及错误分量FP。
- 缺测单元不计TP/FP/FN/TN，插值不能改变实际观测掩码。
- hidden_events记录完全无可观测阳性的事件，不当正常或成功检出。
- unobserved_positive_cells记录缺口内预测，另报而不混入定位分数。
- 数值scorable_mask仅作覆盖诊断，不能缩小主分母；未覆盖阳性仍计FN。
- drift/加速增长结束后保留偏移，原标签到窗末；这不表示全段一直加速。

例：N轴第10–14日异常，第12日缺测；预测10–12及15日，则TP=2、FP=1、FN=2，缺测第12日的预测另报。Precision=0.667、Recall=0.500、F1=0.571。

## P/R/F1与零分母

| 指标 | 公式 | 含义 |
| --- | --- | --- |
| Precision | TP/(TP+FP) | 预测阳性中与真值一致的比例 |
| Recall | TP/(TP+FN) | 可观测真阳性的检出比例 |
| F1 | 2TP/(2TP+FP+FN) | 主定位比较指标，兼顾P/R |

均为0–1，越大越好，但没有通用“F1≥0.8合格线”，不设置无依据的优良分档。

- 无预测阳性时Precision=0（含正常真值组），是计算约定。
- 可观测真阳性总数为0时Recall/F1=null，网页显示—、图显示N/A，即使有误报也不改成F1=0；正常窗主要看报警率。
- 有真阳性但未检出时Recall/F1=0。
- N/A不当0参与均值，也不作为优劣证据。v1.1的仅正常组口径不改历史有异常总体F1。

## 失败、完成与覆盖

| 指标 | 定义 |
| --- | --- |
| 正常窗口误报率 | 完成的正常窗口中至少一已观测单元误报的比例；开发集仅解释为未注入报警率 |
| 有效完成率 | status=ok已落盘记录/全部已落盘记录 |
| 记录覆盖率 | 已落盘记录/运行清单规定记录；完整比较要求100% |
| normal_failures | 正常窗error或insufficient数量，单独披露 |
| numerical_coverage | 真正计算的有效单元/实际有效单元，聚合先求分子分母和 |
| first_attempt_completion_rate | 当前visual/fixed每例一次逻辑调用，首HTTP尝试合法且status=ok的比例 |
| mean_logical_model_calls | 每例逻辑调用数，重试不增此数 |
| mean_model_requests | 每例实际HTTP尝试数，含连接失败、超时和结构纠正 |

error/insufficient没有预测：异常窗的可观测阳性计FN；正常窗不计正确阴性、不入完成正常窗误报率分母。完成正常窗数为0时误报率null。完成率低不能仅凭报警率低认为更安全，Accuracy及TN数不作为主指标。

固定组合numerical_coverage只表示其数值工具，不代表视觉覆盖；数值方法首尝试率、纯视觉数值覆盖和未记录诊断的旧运行均为N/A。合法insufficient不算完成。

v2每逻辑调用最多两次尝试，网络/结构重试共用额度，首个合法输出即停止。首尝试F1按同一真值/掩码另算描述性结果，失败信息保留，不增加调用。最终完成率不能替代首尝试率，覆盖提高不等于现场准确率提高。

## 聚合、重复和效率

先在同方法、同重复、同分组求TP/FP/FN总和，再算P/R/F1（微平均，不平均逐窗F1）。再对模型各重复分数求均值及总体标准差ddof=0。确定性方法只跑一次；当前模型也只有一次，无稳定性估计证据。

重复标准差不是95%置信区间，数值方法标准差0不表示没有泛化误差。不把共享背景、缺测派生或重复调用视为独立样本。总体微平均偏重长区间，必须并列类型、语义和缺测分组。

| 效率项 | 口径 |
| --- | --- |
| 每例耗时 | 开始到最终输出的墙钟时间，含绘图/API等待；同机器及并发比较 |
| 工具/请求数 | 实际调用，含中途失败与重试 |
| tokens | API返回usage；缺失不虚构，不同供应商图像计量不直接等价 |
| 费用 | QWEN_PRICE_MODEL与请求型号匹配且配置输入/输出单价后估算；不匹配或未知为null，不写0元，不覆盖历史费用 |

网页和导出从逐条计数重新聚合，不改原始预测或旧summary。图表用0–1完整量程；缺测条件是离散场景，不当连续严重度曲线。PNG300dpi、SVG/PDF矢量，图包附CSV和来源信息；不裁掉预实验/未完成标记。操作见[运行手册](implementation.md)。

## 当前结论边界

仅把同一来源组划分、同一输入和观测掩码的五方法并列描述；单个测试来源组不能支持跨场地显著性结论，视觉一次运行也没有随机性区间。新`daily_union`直接复用同例的Hampel与视觉输出，组合行记录的请求与耗时是**额外计算增量**；端到端成本应加上两组成分。测试组完成后的注入掩码P/R/F1只适用于这些受控目标，不是现场准确率或真实滑坡预警验证。原生变化及AI审核未覆盖范围不自动成为正常；未来获得部分现场审核时须先立共同未知范围协议，对所有方法统一评分，不得按单方法缩分母。旧配对背景诊断和Agent评价要求仅作为历史协议保存，不参与当前排名。
