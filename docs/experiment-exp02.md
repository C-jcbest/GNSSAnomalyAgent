# GNSS-VLM-EXP02：时间解码与局部视觉复核

名称：**GNSS活动与质量异常分离的时间解码及局部视觉复核实验**。版本v3。
主方法在结果表中为 `anchored_fusion`，数值改进为 `rf_split_temporal`。
EXP01 的 `fusion` 保留为原方案对照；两个实验的名字和结果不可混用。

## 问题与设计

EXP01暴露了全局视图精确定位弱、块中位数抹掉单日质量异常、持续形变结束后平台被延长为活动的问题。
本轮不再围绕输出格式优化，而检验以下两个实质改变：

1. 平衡RF逐日概率加训练侧时间连续性解码。瞬时尖峰/阶跃仍用原库分类；暂态/形变采用二状态Viterbi路径。转移频率与初始状态频率仅从训练站后缀的有效标签学习，各计数单元加1。概率是未校准的RF后验，将其当作启发式发射证据，不能称为完整生成式HMM。缺测发射项为0，不补位移，最终图、CSV和评分仍屏蔽缺测。
2. 用同一数值模型选少量复核窗口，让视觉模型同时查看全局NEU和局部原始位移，分别检查活动与质量异常、活动停止后的平台。模型可以拒绝、改边界和增加事件，不强制候选等于异常。每站一次请求，无递归代理。

不设跨站点毫米/速率物理阈值，也不依据验证/测试真值搜索概率截点。
统计规则和窗口长度仍是超参数，必须披露，不能笼统称为“无参数/无阈值”。

## 数值及候选细节

所有RF使用既有30个站点背景归一化特征、训练侧中位插补、100棵树库默认参数和固定种子。
`rf_balanced` 明确使用 `class_weight=balanced`，不能冒称默认RF或作者源码。
`rf_gap` 只在两侧均检测的缺测区间内连接事件，不跨过已观测负例；日掩码与平衡RF相同，是缺测事件表示对照。
`rf_temporal` 在后缀解码暂态/形变，尖峰/阶跃不平滑；时间先验来自训练站，不使用测试真值。

v2增加 `rf_morphology`：原30特征加18个邻日/短窗形态特征，各NEU分量6个：
向后一个增量、当前相对前后邻日均值的偏离、前后增量乘积、两侧5日中位数之差、
当前相对前侧/后侧5日中位数之差。全部在背景尺度归一化残差上计算；
缺测邻日保持NaN并仅在分类器内训练侧插补。`rf_morphology_temporal`为相同48特征RF加相同时间解码。
这两个单列方法明确是特征适配，不属于默认基线，也不是作者源码。
`rf_independent` / `rf_independent_temporal`为开发中尝试的四个独立二元平衡RF，
保持30特征/默认判定，后一列加时间解码。它在验证侧表现更差，保留为负结果对照，不升为主方法。

局部窗口：尖峰和阶跃各按概率排名取2个检查中心、相距至少22日，中心两侧各21日；
暂态和形变各1个窗口，优先选该类型累计概率最大的已预测事件并在两端各延伸45日；
没有该类事件则取最高概率日两侧各60日。窗口截断于后缀和记录边界。
这是复核预算分配，不是要求每站有6个异常；正常站也执行完全相同的选择。
局部图保留原始NEU各轴毫米刻度、缺测和原日索引，无去趋势后的曲线替代原始活动确认。
v2候选选择器为 `rf_split_temporal`。所有引导视觉变体的全局图与局部图额外显示
仅由正常前缀拟合的线性+年周期参考虚线。虚线是背景外推而非真值，不能单凭残差大判活动。
有局部图的变体额外看正常历史最后121日的原始局部图，对比正常噪声形态；
共1张全局图+1张历史参考局部图+6张候选局部图。`guided_no_local`仅全局图，
因此其消融对象包含历史局部图与候选局部图这一组。

## 对照与消融

| 方法列 | 实际内容与来源 |
|---|---|
| random_forest / extra_trees / isolation_forest | sklearn库默认判定+已披露GNSS特征适配，不是论文源码复现 |
| rf_balanced | 上述RF的类别权重调整，独立标记 |
| rf_gap | 相同平衡RF，仅改变缺测区间事件表示 |
| rf_temporal | 相同平衡RF+训练侧时间解码，本项目实现 |
| rf_independent / rf_independent_temporal | 独立二元训练方式及其时间解码，验证负结果保留 |
| rf_morphology / rf_morphology_temporal | 48特征平衡RF及其时间解码，用于拆分特征与时间解码收益 |
| visual_only | EXP01全局原始NEU视觉方法，无RF监督信息 |
| fusion | EXP01全局图+21日块统计融合，原提示不改 |
| guided_fusion | 全局+历史及6个候选局部原始视图+分任务RF时间解码建议及峰值邻日原始数值，自由视觉改写对照 |
| guided_no_local | 相同建议/数值，只去掉局部图片 |
| guided_no_scores | 相同数值选择的局部视图，去掉建议、分数、峰值索引和邻日数值文本；不是纯视觉零样本 |
| anchored_fusion | 同一guided_fusion响应，按下述任务归属规则融合；主方法，无新模型请求 |
| anchored_no_local / anchored_no_scores | 相应guided消融的同一响应，使用相同融合规则 |
| visualtime_gnss | 锁定VisualTime作者提示/请求函数的GNSS适配，另提供作者原解析重放；不是完整TSAD-Agents |

`guided_no_local` 保留数字峰值邻日，因此它检验局部图的增量价值。
`guided_no_scores` 同时去掉一组显式数值提示，仅能归因于这个信息组，不能单独归因于概率分数。
二者仍有相同RF监督选择信息，不能宣称主方法对完全零样本方法是等信息公平比较。
与 `rf_split_temporal` 的对比才能检验视觉复核是否增加实用价值。

## 新数据与开发边界

沿用简单730日六场景NEU仿真，正常前缀365日，独立白噪声和缺测；不增加复杂噪声。
新种子2026101203，训练/验证/测试各24站；各场景各4站。EXP01测试已用，不再调其数据。
先在本轮24个验证站做数值诊断，小批视觉仅用固定首6个验证站（按清单顺序，六场景各1），
再开展验证/冻结后的新测试。不得按真值为单站选择提示、候选或参数，不挑高分案例。
主测试前保存具体版本、源码、数据哈希、模型标识、预算、消融与所有开发修改。
小批不通过时先在验证侧修订，记录失败与修改；最终测试后不再调方法并把同一测试称为未见。

## 指标与结论约束

主指标沿用无point adjustment的形变日micro-F1及一对一事件F1（IoU≥0.5），
同时报告通用日F1、四类型精确日指标、点事件±3日辅助指标、正常站误报段/站年和成对站点bootstrap。
报告未匹配事件，不能只列成功匹配的边界误差；边界误差为匹配条件下指标。
缺测掩码、观察活动和机制真值不同：低信噪比起止不一定能由位移辨认，不能以模拟机制标签推定视觉可见。
所有调用失败在无条件指标中按零检测计入，单列失败率；不自动重试、不覆盖原始批次。

视觉沿用现有 `qwen3.8-flash` 配置，temperature=0、enable_thinking=False，并发3；先小批再大批。
它不是原论文相同模型。本轮形变仅定位活动，不宣称阶段分类成绩。
结果只支持当前仿真、当前训练分布和模型服务；尚无现场有效性或首次创新结论。

### v2的分任务数值定位

48特征验证将尖峰日F1从.2222提升到.6667，但形变日F1从30特征时间解码的.6964降到.6533，阶跃仍0。
因此固定按任务粒度分配特征：`rf_split`的尖峰/阶跃取48特征平衡RF，暂态/形变取30特征平衡RF；
`rf_split_temporal`仅给区间类型加同样的训练侧时间解码。两个已有模型共用，不新增模型投票或概率阈值。
这些选择仅基于验证侧，在测试前披露；主测试同时列rf_balanced、rf_temporal、rf_morphology、rf_morphology_temporal、rf_split、rf_split_temporal分辨各自收益。
候选与全部引导视觉消融均使用同一个rf_split_temporal，视觉模型仍可修改最终事件，检验增量而非强制获得优势。

## v3：按任务归属融合（主测试前冻结）

v2固定首6站小批18次请求，自由guided_fusion形变日F1=.2749，数值=.8467。
视觉把正常趋势延长为365日至记录末尾的假活动，说明更多局部图/正常参考并不能替代定位约束。
因此不再让自由视觉输出成为最终唯一边界，改为以下预先声明的确定性规则：

1. 形变：仅保留数值定位区间中被视觉同类型confirmed区间覆盖至少1个有效观测日的事件，
   保留数值起止。视觉不能增加没有数值候选的形变，也不能延长数值活动到平台。
   数值边界自身仍可能错误；不能声称这就证明原始活动边界正确。
2. 尖峰/阶跃：数值默认判定为阳性且视觉同类在**完全相同日索引**confirmed才保留。
   没有±3日对齐或分数截点；这一精度优先交集规则可能损失召回，必须报告。
3. 暂态：采用视觉confirmed的进入/返回区间，要求完整位于数值选择的暂态复核窗口内。
   不直接复制数值暂态边界，也不额外保留视觉未确认的数值暂态。
4. 任一视觉依赖失败则该融合列失败、零检测，不自动回退为RF；缺测掩码一致。

同一响应同时计算自由输出和锚定输出，避免模型随机差异混淆融合规则。
锚定三列为依赖派生结果，request_count=0；实际调用只计入对应guided列，不能把派生行视为新增独立样本。
开发阶段对已保存v2验证响应离线检验新规则，保留原响应和独立分析目录：
6站锚定融合通用日F1=.8757、形变日F1=.8467；数值通用=.8416、形变=.8467。
这仅支持进入独立测试，不代表已证明视觉增量；阶跃小批仍0。
v3未更改提示/候选参数，只有最终任务归属融合新增；测试侧不再依据结果调方法。

主测试预先指定24个新测试站，10个数值列、5个视觉列及作者源码适配，实际264次请求；
另产生锚定三列。比较EXP01原fusion/visual_only时在相同本轮测试站重新调用，不能跨旧数据直接比较。
主批完成后anchored_fusion对应guided_fusion独立复测24次请求，RF重算为确定性检查；重复站不扩充样本量。
