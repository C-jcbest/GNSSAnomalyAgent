# 项目状态与关键决定

## 2026-09-24 · P1 生成基准破坏性冻结

- 类型：决定、纠正。原 P1 的 180 日可配置背景与 AR(1) 被固定的 365 日 `normal-v1` 取代。
- 范围：后端生成器、API、前端与四章实验文档。公开生成请求只含 seed 和数量；旧 180 日 manifest/请求不兼容，也不提供迁移。
- 数值：固定 annual 2/2/3 mm、semiannual 1/1/2 mm、白噪声标准差 1.5/1.5/3.0 mm，按 N/E/U；相位由独立 seed 派生。数值来源与未采用的线性速度/flicker noise 见 [P1 模型](02-p1-normal-model.md)。
- 边界：P1 不含异常、secular deformation、相关噪声或检测结果。P2 才定义注入形变和观测伪差；P5 后才比较检测方法。
- 后续规则：修改固定背景、窗口或噪声类别应建立新实验版本，并同步代码、测试、网页与文档；不在 `normal-v1` 中增加隐式兼容开关。
