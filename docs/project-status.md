## 尚未解决的研究问题

目前仅合成数据，4个正常测试站、8个形变站，机制标签未独立专家复核；背景正常前缀是实验提供的条件。21日居中统计只支持离线分析。提示未稳定约束活动终止与质量形态分类，网络/格式失败也影响无条件指标。

投稿需要独立现场数据、更多独立站点/种子、更稳定接口和针对错误的独立新验证协议；新方法不得继续以当前已用测试集声称未见测试。本轮负结果和近邻证据不构成发表保证。
