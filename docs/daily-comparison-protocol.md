# 每日15点三路同期比较 v1

冻结日期：2026-09-23。该协议是**受控注入定位实验**，不是现场密集真值实验，也不把未注入位置认定为正常。来源为本地只读`daily15-v2`，仅固定北京时间15:00的180日日网格，要求原背景至少144个三轴完整日；不插值、不压缩缺测。测试窗口只按先前固定的来源组进入测试，绝不依据其曲线或分数筛选。

## 数据和评价

构建种子20260923，沿用日注入器的六类（含无新增注入）与四种缺测状态；共六个来源窗×24派生=144例（开发48、验证24、测试72）。同来源所有派生只在原划分；派生例不是独立来源。输入文件只含时间、三轴、缺测与不含标签的case ID；manifest与labels仅在评价侧读取。无新增注入不表示背景正常；背景原生变化范围未知，所有注入外报告为**标签外报告量**，不是已证实的现场误报。

主指标沿用[observed-cells-v1.1](metrics-criteria.md)：实际观测日×分量的微平均P/R/F1，异常目标缺失仍计FN；无注入目标的F1为N/A。并列尖峰、台阶、缓慢增长、加速增长、波动增大及缺测状态的分组、未注入窗报告量、完成率、首次合法率、请求数和耗时。持续偏移的注入标签延伸至窗末，不将其解释为真实滑坡或在线检出。分组比较不把派生例当独立统计重复；当前来源仅三组，不声称显著性。

## 方法和冻结

- 数值：缺测感知的Hampel局部残差、CUSUM相邻日增量累积、Isolation Forest局部统计特征。参数、种子、阈值和覆盖诊断固定在`configs/daily-comparison-v1.json`，不从测试或未知正常背景调阈值。
- 视觉：对每例同一全局三轴图及逐日缺测元数据独立输出含端点的分量区间；模型默认`qwen3.8-flash`、关闭思考、两次尝试共享网络/结构纠正上限。图和提示不含注入类型或目标。
- 组合`daily_union`：同例、同一重复的Hampel结果与**本轮纯视觉的同一份响应**按日期×分量取并集。两路原始结果与来源写在组合工具轨迹；任一路失败则组合失败，不把失败当空预测。组合不额外调用模型，效率比较须计入它复用的数值与视觉分支成本，不能将派生行的零请求解释为零成本。

固定五种方法顺序：`hampel cusum iforest visual daily_union`，一次视觉重复、每例一次完整图，最多4例并发。数值与视觉同步在同一运行生成，不复用旧实验响应。开发运行用于核对实现；验证完整且全部方法合法后用`freeze-daily`保存未改阈值的配置凭据；测试必须使用同一数据集和全配置哈希，无`--limit`，最后一次独立评价。验证不是现场正常校准；此门控不提高标签真实性。视觉实际响应型号、请求ID、用量与失败逐条保留，不假定底层版本不变。

方法选择参考[TSAD-Agents视觉时序任务与数值/视觉路线](literature-review.md)及[TSB-AD评价可靠性讨论](literature-review.md)，只借鉴任务形式，不宣称论文官方Agent复现或原基准性能可迁移到GNSS。本协议不启动Agent比较；任何后续方法或指标改变须新版本及新输出目录。
