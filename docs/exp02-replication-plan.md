# EXP02-v3独立种子复核计划

2026-10-12，在主批exp02-main-v3尚准备输入（15/24站、无视觉结果）时声明两个独立数据种子：2026101204与2026101205。
每种子训练/验证/测试各24站；测试每场景各4站。方法和参数沿用已冻结v3，不依据主测试成绩修改。
各种子复核random_forest、rf_balanced、rf_split_temporal、原fusion、自由guided_fusion及同响应anchored_fusion；每种子48次请求。
分类器种子仍固定2026101203，转移先验分别仅从各自训练站学习。数据种子与分类器种子分开记录。
每个种子单列结果；汇总时以(数据种子,站点ID)区分72个独立测试站，不能把相同ID误认成相同模拟站。
另外主种子同测试集24次独立guided_fusion调用及派生锚定结果仅描述响应波动，不计入独立站点汇总。
