# EXP22：原暂态修复路径的配对图像消融

2026-10-15登记，EXP20已有暂态区间增益，但缺少同轮去图控制。EXP21直接区间定位小批失败，不扩量。本实验以已有正向路径验证图像信息，而非继续更换指标或提高图像分辨率。

实验名：**SDR-ImageCheck（SDR暂态修复图像贡献复核）**。原EXP06的48站已经见过，所有新结果均是事后诊断，不是新的未见正式试验。

- 固定EXP06两批48站、原冻结数值候选、原提示、原图和修复规则；不重新生成候选、不修改边界或置信阈值。
- 2×2输入：`flash_image`/`flash_noimage`使用原qwen3.8-flash；`vl_image`/`vl_noimage`使用已授权qwen3-vl-plus。各模型有图/无图在同轮新调用，不把历史响应直接当作控制。无图只移除消息中的image项，数值候选、日期、缺测、其余提示文字逐字相同。无图仍含候选信息，因此不等于没有任何证据。
- 只有原方法实际触发的7站请求，41站不请求、保留独立数值决策。首批按(seed,station)排序前2触发站×4输入=8请求。保留每次失败，无重试。若同模型有图比去图恢复更多正确暂态或提高暂态Affiliation F1/事件IoU .5 F1，则完成其余5站的四输入20请求；否则停止，不能用模型名字或解释文字声称视觉贡献。
- 小批只报2个实际完成站的诊断，不以41未请求/5未运行站稀释对照。扩量完成后才报同48站完整方法。
- 沿用EXP20所有区间指标、缺测适配及空集规则。主看暂态（原修复的实际职责），长期活动应与独立数值相同；同时核查点型阶跃的误删及正常/其他类型负站的暂态误报。
- 图像因果比较在同模型、同轮有图/去图之间做。跨模型比较只能说明此任务的模型差异。两种模态若预测相同则明确无图像增益；不把原数值定位本身或候选区间先验算成图像作用。

参考依据：AnomLLM§4.2及图像/文字控制设计、Huet等Affiliation原代码；具体书目与作者实现边界见EXP20实读笔记。即便本实验有收益，仍需冻结新开发/正式数据以支持新方法的泛化声明。
