# EXP18：局部分布与对照示例视觉核验（DCV-VLM）

2026-10-15，请求及新数据生成前登记。EXP17已完成64新请求，未通过集成条件。
原因假设：模型将带观测噪声的三轴估计当作必须精确相等，弱轴差异会错误否决配对。
另一问题是条形仅显示单点统计，不能展示局部观测散布。

文献依据：TAMA的参考学习与局部放大；ChartGemma对真实图像趋势/视觉信息的强调；
AnomLLM控制表示与提示的研究方法。以下带异常标签对照、箱线/散点绘图均为本项目
适配，不是论文作者默认方法，也不以其论文分数代替本实验。无新模型/复杂噪声。

保持EXP17数值候选、活动/尖峰/已有暂态和固定端点，VLM仍只从free_graph选P ID。
对每候选取与EXP15相同的前/后至多7个实际观测，邻候选截断。按各边前段中位数
居中、返回取反、本站历史MAD缩放。绘制before/after分组散点与箱线，三轴分别共用
所有候选的纵轴范围；各点均实际观测，缺测不插补，不添加幅度/速度告警阈值。
新提示允许弱而噪声占优的轴不精确匹配，强调可信分量与观测散布，不强迫固定pair数。

模式固定：

- distribution：仅目标局部分布图，新提示；
- reference_distribution：相同目标图，加一份训练站对照，含一个匹配返回与一个独立
  永久阶跃的错误配对；示例由训练真值构建，明确示例日期/幅度/计数不迁移；
- distribution_text：完全相同目标与训练示例的原始局部样本JSON和示例标签，无图；
- no_evidence：相同候选和新提示，无目标观测/图片。

训练示例选择规则：在每数据集train分区按station_id排序，取首个真值中永久阶跃
严格位于一个暂态内部、边缘两侧均有有效观测的站；正例为暂态起止边，负例为
暂态起边与内部永久阶跃。只选训练分区，不按目标真值或模型表现换示例。
示例用真值边缘而目标用数值边缘，作为训练/推断差异披露，不能当专家现场验证。
示例配对ID加R前缀，不能被选择为目标P ID。此为单个对照，不搜索示例数。

先在已见1508全部48验证站作开发诊断，复用旧原SDR/数值/近邻；
两视觉模式均先首个触发站再全部，无标签筛选。无论旧站结果，固定候选
reference_distribution进入新开发2026101512：144训练/144验证，48站版本不再
适合稀疏干预机会，故扩大验证样本，保持原生成器、各场景比例和原噪声不变。
生成器要求训练数不少于每分区站数，原拟96训练的生成命令在生成数据前被拒绝，
因此统一144训练；所有同站方法共享这些训练数据，不将跨批数值变化归于视觉。
新测试分区不用；1510/1511未使用，保留旧协议的预留状态，不更换名字借用。

144验证站同组完整运行四模式、同模型原SDR、数值、反向近邻。每模式一站至多1次
请求，temperature=0，不重试、不投票。先小批确认图像和参考可读再跑剩余。
四类等权日F1主指标；全部类别、事件IoU≥.3/.5及通用F1保留。
多跳变子集预定义为free_graph≥3jump，仅据观测候选，至少6站才考虑限定场景主张。
采纳门槛沿用EXP17：原SDR及数值至少+.01，文字/近邻中至少一项+.005且另一项
不低于-.005，类型对原SDR不下降>.03。全组或预定多跳变范围通过才另登记新正式
1513/1514两批各48测试站；正式两批同条件、对原SDR差值均非负才集成。
不通过则停止本轮扩量，保留负结果，不据好看指标取消文字对照或改称正式成绩。
