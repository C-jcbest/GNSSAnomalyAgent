# 冻结活动范围下的三阶段头开发比较 v1

- workflow：academic-research-suite / experiment-agent；继续已授权阶段头比较
- version：landslide-frozen-stage-heads-v1，2026-10-08；在新预测前保存
- inputs：作者复核v3全部12条，21个名义活动区间、2,126个有观测活动日
- provenance：活动来自已见旧回答的同会话AI作者；没有独立阶段参考
- outputs：开发预测与分歧/支撑诊断，不是准确率或正式方法排名

先只读核对全部活动冻结哈希、原始观测与31/61/91日辅助图，再在同一活动范围执行规则、保存的XGBoost及视觉模型阶段头。不改变活动、不迁移历史阶段、不重训、不调阈值、不读新机制真值或封存测试。全组12条，3条无确认活动时确定性跳过视觉调用；不能视为视觉辨别正常的成绩。

规则复用 `rule_stages`，旧验证选择的60日相对速率变化阈值0.25。XGBoost加载原 `stage-xgboost.json`，核对12特征名称/顺序及旧训练记录；缺失特征继续使用XGBoost原生处理，不补零。二者是本项目阶段头，不冒充某篇滑坡论文的原方法。预测按旧原生规则先保存，再应用本轮共同观测支撑契约，不能只展示处理后的标签。

视觉模型沿用qwen3.8-flash、temperature=0.1、top_p=0.3、max_tokens=2048、关闭thinking、JSON输出。每条有活动记录一次，共最多9次，无重试。每次实际发送同一条记录的4张冻结原图与3张冻结辅助图、活动内部半开范围和活动内容哈希，不发送作者证据/块统计、数值预测或旧阶段回答。这是离线全记录判断，居中图含未来信息；不能称预警或公平的等信息训练比较。

统一主要阶段A/S/D：加速为非零运动速率增大，减速为速率减小，S为近似恒定的非零速率；负向位移不等于减速，小幅运动不自动等于匀速。强度和阶段是不同维度，低速不是本轮第四互斥类别。无法可靠区分的弱段或转折允许unknown，不强行填满。

稀疏阶段半开区间允许省略日期；所有区间必须有原图/辅助证据文本、排序、不重叠、位于同一名义确认活动范围。跨内部缺测可描述趋势，但缺测日最终未知；区间不能跨活动间的未知边界/平台。越界、错误类别、重复字段或端点错误按整条阶段输出失败保留，不修补/裁剪/重跑。活动层保持冻结；阶段失败时所有确认活动日未知，明确静稳日仍none。

共同支撑：确定阶段需原始有观测、冻结activity=1及有效61日速度向量；A/D还需有效61日切向加速度。无支撑日期保留活动标签、阶段置unknown，并独立统计模型原回答被支撑掩码排除多少日。不把缺测和活动外日期算阶段支撑弃判。规则仍保留其旧特征支撑限制，XGBoost仍保留其旧原生支撑限制；不能声称三个头实际具有相同覆盖。非零及近似恒定仍需内容复核，支撑掩码不证明语义正确。

保存完整真实提示、原始回答、请求体/图像哈希、服务模型、token、耗时、失败、原生预测、最终逐日CSV/JSON和原图同轴三行色带。报告各类日数、活动内弃判、缺测/速度支撑/切向支撑、配对A/S/D共同赋值日及分歧矩阵。不得把一致率、覆盖或标签数解释为准确率，不计算F1、p值或模型优胜。

全部推理完成并冻结后才进行作者辅助图内容审查，记录实际看的例/图、观察到的矛盾和未裁决日期；不将事后审查作为预测前独立真值。弱尾段、长缺口和记录截尾是优先核查项，不借机制类目作为参考标签。
