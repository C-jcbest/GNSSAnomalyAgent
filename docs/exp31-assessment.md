# EXP31：全局—局部联合视觉复核（JCV-GNSS）评估

2026-10-16。主方法未通过预登记的开发扩量条件，不替换稳定方案。
联合图像改善了部分模型独立输出，但未改善完整融合系统。两者必须分开解释。

## 数据、方法和证据身份

使用三种子各12站，共36个此前未预测的开发站，六场景各6站；其中12站有真暂态，
24站无真暂态。旧72开发站只用于问题诊断，不进入新分数。其余252开发站和全部360个
test站未预测。本轮没有独立测试成绩，也未训练新数值模型。

[预登记](experiment-exp31.md)在新请求前冻结。沿用EXP30-S1图像/文字粗筛，
候选两侧各扩35日、合并相接或重叠上下文，再让模型在一次终轮联合读取全局图和全部合并局部图。
各站最多两处上下文；数值阶跃日期和向量是可错的软证据，不设跨站统一毫米或速率阈值。
confirmed提议与原近邻按add-only规则融合，不用视觉覆盖已有近邻暂态。

模型为`qwen3-vl-plus`，temperature=0、thinking关闭。共25种方法/消融读出，
包含6种JCV融合及其独立读出、原AIR局部/全局及其独立读出、原VRC图/文字、近邻与六个数值方法。
`_pure`表示不融合近邻最终预测，**仍输入数值软证据**，只有`no_numeric`删除该证据；
不能将它们称为完全纯视觉。独立读出只输出暂态，不能拿其四类F1与完整系统评优。

本轮取回并阅读时序智能体综述、TimeEvo相关方法段落，复读AnomaMind和TimeRLM的指定部分。
联合输入是本项目的GNSS适配；没有执行这些论文完整作者框架，不能把本轮分数署为其复现成绩。
[来源、版本、读取范围和检索边界](exp31-reading-notes.md)另列。

## 其他指标和Affiliation的解释

沿用原作者Affiliation源码及项目已披露的聚合规则，无point adjustment。
主表Aff-F1是**有真值暂态站的逐站F1均值**，不纳入24个无暂态站。
因此主方法在负站误报52日仍能得到Aff=1；不能将该满分解释为整体检测完美。
空预测、作者precision未定义及项目聚合规则见原方法说明和导出的`range-metrics.csv`，
日级计数使用缺测掩码。另有harmonic-of-macro-P/R读出，不能与station-macro-F1混称。

|---|---:|---:|

形变分数相同是因为沿用近邻输出，不能宣称本轮视觉改善了长期形变。
全部25方法的暂态、形变与范围联合P/R/F1、一般异常指标、种子/场景分层和失败敏感性保留在
[结果目录](../results/exp31-validation-pilot-v1/)；Isolation Forest只输出一般异常，类型指标不适用，留空不填0。
数值对照保持原实现和参数；本轮没有新的作者论文完整框架比较。

- **v0267（真实恢复）**：真暂态[612,646]，联合独立输出[610,646]，35TP/2FP；
  同首轮文字、仅全局和仅局部均不确认。近邻原已完整识别，因此该案例不贡献融合新增TP。

## 下一轮优先方向

下一轮应先另行登记“视觉模型独立输出的联合上下文收益”，在未使用的开发站比较图文、全局和局部，
先确认本轮32个新增TP日是否可重复，再决定是否扩大。不能直接在本36站继续挑提示或把独立读出改为本轮成功终点。
该检验应报告全部站点而非只选数值失败站，同时按数值是否原已检出分层，避免上限效应掩盖互补性。

若独立输出收益可重复，再研究数值如何帮助视觉分离“暂态偏置叠加永久阶跃/形变”，
重点解决v0035一类跨事件叠加，而不是继续增加自由形式终审轮次。
现有负结果表明单纯add-only把部分模型识别收益遮蔽、把负站误报直接加入系统；
新融合规则需要独立登记和反例验证，不能依据本批标签临时裁剪或引入站间物理阈值。
以上均是待验证方向，本轮未执行、没有新成绩。
